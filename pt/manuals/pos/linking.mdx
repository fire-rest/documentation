---
title: "Vinculação"
description: "Como vincular um terminal POS a uma loja pelo backoffice do Fire."
---

Este guia descreve como cadastrar um terminal POS em uma loja. O cadastro é uma operação única por dispositivo: o administrador gera um código de uso único pelo backoffice e o operador o digita no app do POS. Uma vez vinculado, o terminal fica associado à loja e os caixas podem entrar com o PIN deles.

## Pré-requisitos

- Acesso ao backoffice do Fire em **[app.fire.rest](https://app.fire.rest)**, com permissões sobre a loja e a função **Fire POS Admin**.
- O dispositivo ligado, com conexão com a internet e um navegador compatível. Consulte os [requisitos do terminal](/pt/manuals/pos/hardware-requirements) para as especificações completas de hardware, sistema operacional, navegador e rede.

<Info>
  **O FIRE POS não se instala.** É uma aplicação web aberta no navegador do terminal em **[pos.fire.rest](https://pos.fire.rest)** — não há executável nem instalador. Opcionalmente, pode ser instalado como PWA pelo próprio navegador para abrir em tela cheia.

  São dois endereços distintos: `app.fire.rest` é o backoffice (onde você gera o código) e `pos.fire.rest` é o terminal (onde você o digita).
</Info>

Para terminais que imprimem comprovantes e vouchers, instale também o **Agente Fire** no dispositivo. Consulte a [guia do Agente Fire](/pt/manuals/fire-agent/installation) para a instalação completa.

  Instalador do Windows para impressão térmica local.
</Card>

## 1. Selecione país e vendor

Entre no backoffice em **[app.fire.rest](https://app.fire.rest)**. No canto superior direito, abra o seletor e escolha o país e o vendor em que você vai operar. Todas as ações deste guia acontecem dentro desse contexto.

<Frame>
  <img src="/images/manuals/pos/linking/01-select-country-vendor.png" alt="Seletor de país e vendor no backoffice" />
</Frame>

## 2. Confirme o canal Fire POS

No menu lateral, certifique-se de que o canal **Fire POS** está selecionado. A seção de Terminais só está disponível dentro desse canal.

<Frame>
  <img src="/images/manuals/pos/linking/02-confirm-channel.png" alt="Seletor de canal com o Fire POS selecionado" />
</Frame>

## 3. Escolha a loja de destino

No seletor de loja do cabeçalho, escolha a loja em que o terminal será cadastrado. O slot que você gerar no próximo passo fica preso a essa loja — não é possível reatribuí-lo depois.

<Frame>
  <img src="/images/manuals/pos/linking/03-pick-store.png" alt="Seletor de loja no cabeçalho do backoffice" />
</Frame>

## 4. Abra a seção de Terminais

No menu lateral abra **POS → Terminais**. Você verá uma lista com os terminais já cadastrados, agrupados por status (Ativos, Slots pendentes, Suspensos, Revogados).

<Frame>
  <img src="/images/manuals/pos/linking/04-terminals-section.png" alt="Submenu POS com a opção Terminais" />
</Frame>

## 5. Crie um slot de vinculação

1. No canto superior direito clique em **+ Criar slot**.

   <Frame>
     <img src="/images/manuals/pos/linking/05-create-slot-button.png" alt="Página de Terminais com o botão Criar slot" />
   </Frame>

2. **Modal Criar slot de vinculação.** Confira a loja de destino e escolha a validade do código (padrão **30 minutos**). Clique em **Gerar código**.

   <Frame>
     <img src="/images/manuals/pos/linking/06-create-slot-modal.png" alt="Modal Criar slot com a loja de destino e o campo de validade" />
   </Frame>

3. O backoffice mostra um **código de 6 dígitos** com a hora de expiração. Use o botão **Copiar** ou anote-o. O código é mostrado uma única vez e só pode ser usado para vincular um dispositivo.

   <Frame>
     <img src="/images/manuals/pos/linking/07-slot-code.png" alt="Código de 6 dígitos gerado com o botão de copiar e a hora de expiração" />
   </Frame>

<Note>
  Se o código expirar antes de ser usado, o slot fica inválido. Refaça este passo para gerar um novo.
</Note>

## 6. Abra o app do POS

No navegador do dispositivo, abra **[pos.fire.rest](https://pos.fire.rest)**. Se o terminal nunca foi vinculado, a tela inicial exibe o título **Vincular terminal** e um teclado numérico de 6 posições.

<Frame>
  <img src="/images/manuals/pos/linking/08-open-pos-app.png" alt="Tela do POS com o título Vincular terminal e o teclado numérico" />
</Frame>

## 7. Digite o código

Digite os 6 dígitos no teclado. Assim que o sexto dígito é digitado, o app valida o código automaticamente — não é necessário confirmar.

<Frame>
  <img src="/images/manuals/pos/linking/09-type-code.png" alt="Teclado numérico com os 6 dígitos digitados" />
</Frame>

Enquanto o código é validado, a tela mostra um indicador de carregamento. Se o código for inválido ou tiver expirado, uma mensagem de erro aparece e o teclado é limpo para você tentar de novo.

## 8. O terminal fica vinculado

Quando a validação termina, o terminal recebe o nome, a loja e as credenciais internas, e redireciona automaticamente para a tela de **login do caixa**. A partir desse momento, o dispositivo opera de forma autônoma — os caixas podem entrar com o PIN sem usar o código novamente.

<Frame>
  <img src="/images/manuals/pos/linking/10-cashier-signin.png" alt="Tela de login do caixa depois de vincular o terminal" />
</Frame>

<Check>
  O terminal está vinculado à loja e pronto para operar.
</Check>

## Verificação pelo backoffice

Volte para **POS → Terminais** e abra a aba **Ativos**. O terminal recém-cadastrado aparece na lista com o nome, a hora da última conexão e o status **ATIVO**.

<Frame>
  <img src="/images/manuals/pos/linking/11-terminal-active.png" alt="Lista de terminais com o novo dispositivo no status ATIVO" />
</Frame>

Na aba **Slots pendentes**, o slot que você gerou já não deve aparecer — passou para **CLAIMED** e é consumido automaticamente.
