<Warning>

</Warning>

Quando algo falha, o quiosque mostra uma mensagem curta para o cliente, uma referência e um botão **Ver detalhes** com o texto técnico. Embaixo vai uma linha com a versão do app, a loja, o quiosque e o horário do erro, e o pedido se já foi enviado: uma captura de tela basta para encontrar o caso nos logs.

```text
              Este produto não está disponível
   Não conseguimos carregar este produto. Tente novamente em alguns minutos.

            Ref.: T153 · T102 · 500        Ver detalhes ▾

        P 1.2.12-fire · K066 · 98051774 · 05/10 15:58:56
```

## Como ler o código

A letra diz de quem é o erro, ou seja, a quem avisar. Quando dois responsáveis têm a mesma inicial, o prefixo leva duas letras.

| Prefixo | Responsável | A quem avisar |
|---|---|---|
| **T** | TRD | Equipe da TRD (quiosque, Fire, Firebase, PayBridge, Masivo) |
| **K** | KFC | KFC: Maxpoint e a infraestrutura da loja |
| **B** | CliSiTef | Software Express / Fiserv (SiTef Brasil) |
| **D** | DeUna | DeUna |
| **DF** | Datafast | Datafast (pinpad Equador) |
| **M** | Medianet | Medianet (pinpad Equador) |
| **R** | Redeban | Redeban (maquininha Colômbia) |
| **PC** | Pinpad Colombia | Fornecedor do pinpad da Colômbia |
| **TB** | Transbank | Transbank (Chile) |
| **H** | Hasar | Hasar (Chile) |
| **PN** | POSNET | POSNET (Argentina) |
| **S** | Sitef | Sitef Venezuela (pagamento móvel) |
| **I** | Impresora | Equipe da loja: verificar a impressora |

Na TRD o número diz também em que parte do fluxo aconteceu:

| Faixa | Parte do fluxo |
|---|---|
| T001–T049 | Vinculação e Firebase |
| T050–T099 | Dispositivo e configuração |
| T100–T149 | Conexão |
| T150–T199 | Menu e produtos |
| T200–T249 | Carrinho, cupons e fidelidade |
| T250–T299 | Pagamentos |
| T300–T349 | Pedido |
| T350–T399 | Cancelamentos |
| T900–T999 | Só nos logs |

## Como ler a referência e a linha técnica

- **Primeiro código:** o erro do serviço, por exemplo `T153` (não foi possível carregar o produto).
- **Segundo código:** o que aconteceu com a conexão, por exemplo `T102` (o servidor respondeu com erro).
- **Número final:** o status HTTP que o servidor devolveu, por exemplo `500`.
- **No CliSiTef:** o código de retorno da biblioteca e o cupom fiscal, por exemplo `Ref.: B006 rc=-5 · cp=1790342446698`.
- **Linha técnica:** versão do app · loja · quiosque (8 caracteres do deviceId, igual aos logs) · data e hora do quiosque · pedido.
