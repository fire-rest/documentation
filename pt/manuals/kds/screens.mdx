Uma **tela** é um dispositivo KDS (monitor + app fire-kds). Cada tela tem um **Device ID** único dentro da loja.

## Campos importantes

| Campo | Para que serve |
|---|---|
| **Store** | A loja. |
| **Name** | Nome admin (ex. "Tela Grelha"). |
| **Device identifier** | O ID que o app fire-kds usa para se registrar. **Não pode ser alterado** depois de criar. Deve coincidir exatamente com o dispositivo. |
| **Location** | Localização física opcional (referência operacional). |
| **Active** | Se desabilitada, não deve ser usada em produção. |
| **Dark mode** | Tema claro/escuro padrão no fire-kds. |

<Warning>
  O **device identifier** não pode ser alterado depois que a tela é criada. Combine-o com o time de hardware antes de salvar.
</Warning>

## Criar uma tela

<Steps>
  <Step title="Abra o formulário de tela">
    **KDS → Screens → Create** (`/kds/admin/screens/new`).
  </Step>
  <Step title="Preencha loja, nome e device identifier">
    Por exemplo, device identifier `KDS-GRILL-01`.
  </Step>
  <Step title="Salve">
    O sistema redireciona para **Assign stations**.
  </Step>
  <Step title="Atribua estações">
    - Adicione as estações que esta tela deve mostrar (ex. `GRILL` e `FRY`).
    - Defina o **sort order** (ordem das colunas na UI).

    <Frame>
      <img src="/images/manuals/kds/screens/02-assign-stations.png" alt="Tela Assign stations com sort order" />
    </Frame>
  </Step>
  <Step title="Salve a atribuição" />
</Steps>

<Note>
  Relação chave: uma tela pode mostrar **várias estações**, e uma estação pode aparecer em **várias telas** (ex. montagem visível tanto no monitor de expo quanto no de despacho).
</Note>
