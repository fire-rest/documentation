---
title: "Login"
api: "POST https://api.fire.rest/v1/auth/login"
description: "Troque suas credenciais por um token de acesso. Use o token retornado como Bearer token em todas as requisições subsequentes à API."
---

<ParamField header="x-api-key" type="string" required>
  Sua API key do Fire. Emitida pelo dashboard do Fire em **Settings → API Keys**.
</ParamField>

<ParamField body="username" type="string" required>
  Seu nome de usuário do Fire.
</ParamField>

<ParamField body="password" type="string" required>
  Sua senha do Fire.
</ParamField>

<ResponseField name="token" type="string">
  Token de acesso. Inclua-o no cabeçalho `Authorization: Bearer <token>` em todas as requisições à API.
</ResponseField>

<ResponseField name="expiresIn" type="number">
  Tempo de vida do token em segundos.
</ResponseField>

<ResponseExample>
```json 200
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expiresIn": 3600
}
```

```json 401
{
  "error": {
    "code": "unauthorized",
    "message": "Invalid credentials"
  }
}
```
</ResponseExample>
