---
title: "Configuração de métodos de pagamento"
api: "GET https://api.fire.rest/api/v1/external/payment-methods/config"
description: "Leia os métodos de pagamento configurados (habilitados e desabilitados) para o vendor vinculado à sua API key. Use para saber quais métodos de pagamento sua integração pode oferecer."
authMethod: "bearer"
---

Retorna a configuração completa de métodos de pagamento para o vendor vinculado à sua API key, enriquecida com dados do catálogo global (`uuid`, `name`, `description`).

O endpoint não aceita query params — `accountId` e `vendorId` são derivados da API key. **Retorna todos os métodos** (habilitados e desabilitados) para que o cliente decida o que mostrar. Métodos do JSONB sem match no catálogo são excluídos.

<Info>
  Já existe uma [v2 deste endpoint](/pt/api-reference/payment-methods-config-v2) que resolve a
  configuração **por loja**, com níveis de canal, fulfillment e terminal, e devolve os valores de
  configuração. **Esta v1 continua disponível e não tem data de desativação** — migre quando fizer
  sentido para você.
</Info>

## Autenticação

<ParamField header="x-api-key" type="string" required>
  Sua API key do Fire com scope `payment-methods:read`. A key **deve ser vendor-scoped** (binding account + vendor) — keys sem `vendorId` são rejeitadas com `403`.
</ParamField>

## Requisição

<RequestExample>
```http
GET https://api.fire.rest/api/v1/external/payment-methods/config
x-api-key: <sua_api_key>
```
</RequestExample>

## Resposta

<ResponseField name="accountId" type="string">UUID do account ao qual a API key pertence.</ResponseField>

<ResponseField name="countries" type="object[]">
  <Expandable title="country">
    <ResponseField name="countryCode" type="string">ISO 3166-1 alpha-2 (ex. `BR`, `EC`, `CO`).</ResponseField>
    <ResponseField name="vendors" type="object[]">
      <Expandable title="vendor">
        <ResponseField name="vendorId" type="string">Identificador do vendor.</ResponseField>
        <ResponseField name="vendorName" type="string">Nome legível do vendor.</ResponseField>
        <ResponseField name="paymentMethods" type="object[]">
          <Expandable title="paymentMethod">
            <ResponseField name="uuid" type="string">UUID do catálogo global de `payment_methods`.</ResponseField>
            <ResponseField name="code" type="string">Código do método (ex. `CASH`, `CREDIT_CARD`).</ResponseField>
            <ResponseField name="name" type="string">Nome de exibição.</ResponseField>
            <ResponseField name="description" type="string | null">Descrição opcional.</ResponseField>
            <ResponseField name="enabled" type="boolean">Se o método está ativo para este vendor.</ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Notas

- `uuid` vem do catálogo global de `payment_methods`, não do JSONB por account.
- Métodos desabilitados são incluídos para que você possa renderizá-los com estado "indisponível" ou escondê-los — é sua decisão.
- `countries` agrupa pelo código de país do JSONB.
