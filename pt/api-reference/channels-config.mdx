---
title: "Configuração de canais"
api: "GET https://api.fire.rest/api/v1/fire/external/channels/config"
description: "Leia a configuração ativa de canais de venda (com tipos de fulfillment) para o seu vendor. Use para saber quais canais e combinações de fulfillment sua integração pode usar."
authMethod: "bearer"
---

Retorna a configuração completa de canais de venda para o seu vendor, enriquecida com dados do catálogo global (`uuid`, `name`, `description`) e os tipos de fulfillment configurados para cada canal.

O endpoint não aceita query params. Apenas canais com `enabled !== false` são retornados. Canais sem match no catálogo são excluídos da resposta.

## Autenticação

<ParamField header="x-api-key" type="string" required>
  Sua API key do Fire com o scope `channels:read`. A key **deve ser vendor-scoped** (account + vendor binding) — keys sem `vendorId` são rejeitadas com `403`. O account e o vendor são resolvidos a partir da key, então não é necessário header `account` nem query param.
</ParamField>

## Requisição

<RequestExample>
```http
GET https://api.fire.rest/api/v1/fire/external/channels/config
x-api-key: <your_api_key>
```
</RequestExample>

## Notas

- `uuid` vem do catálogo global de `channels`, não do JSONB por account.
- `fulfillmentTypes` inclui apenas os tipos configurados para esse canal no vendor. Tipos sem match no catálogo são excluídos.
- `countries` agrupa pelo código de país do JSONB. Um vendor pode aparecer em múltiplos países se tiver configuração por país.
