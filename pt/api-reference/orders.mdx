## Objeto price

Os campos a seguir aparecem nos objetos price ao longo do payload (`unitPrice`, `totalPrice`):

| Campo | Tipo | Descrição |
|---|---|---|
| `currencyCode` | string | Código de moeda ISO 4217 (ex.: `USD`) |
| `totalBeforeSale` | string | Preço antes de qualquer preço promocional |
| `subtotalWithoutTaxes` | string | Subtotal sem impostos |
| `discountPercentage` | string | Percentual de desconto aplicado |
| `discountsValue` | string | Valor do desconto |
| `subtotalIncludeDiscounts` | string | Subtotal após descontos, antes dos impostos |
| `taxesPercentage` | string | Percentual de imposto |
| `taxValue` | string | Valor do imposto |
| `total` | string | Total final |
| `suggestedPrice` | string | Preço sugerido original |
