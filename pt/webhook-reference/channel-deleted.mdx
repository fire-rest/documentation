---
title: "channel.deleted"
description: "Disparado quando um canal de venda é removido do Fire."
---

O Fire emite este evento quando um canal é removido permanentemente. Seu sistema deve desativar ou remover o canal do seu mapeamento local e parar de rotear eventos ou pedidos para ele.

## Payload

```json
{
  "event": "channel.deleted",
  "id": "evt_abc201",
  "createdAt": "2025-01-21T09:00:00Z",
  "data": {
    "account": "1",
    "country": "6",
    "vendorId": 16,
    "channelId": "CH-IFOOD-001",
    "code": "IFOOD"
  }
}
```

## Campos

### `data`

| Campo | Tipo | Descrição |
|---|---|---|
| `account` | string | Identificador da conta — exigido por sistemas downstream |
| `country` | string | Identificador do país — exigido por sistemas downstream |
| `vendorId` | integer | Identificador da marca |
| `channelId` | string | ID do canal removido |
| `code` | string | Código curto do canal removido |

## Uso

Quando seu sistema receber este evento, remova o canal do seu mapeamento local e pare de rotear eventos de publicação ou injeções de pedido para ele. Pedidos em andamento associados a este canal devem ser concluídos, mas nenhum novo pedido deve ser injetado.

Diferente de [`channel.updated`](/pt/webhook-reference/channel-updated) com `active: "INACTIVE"`, este evento é explícito — o canal não existe mais no Fire.
