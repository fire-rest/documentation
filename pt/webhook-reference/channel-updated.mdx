---
title: "channel.updated"
description: "Disparado quando um canal de venda é criado ou atualizado no Fire."
---

O Fire emite este evento quando a configuração de um canal muda — nome, status, tipo de autenticação ou URL base. Seu sistema deve atualizar seu mapeamento local de canais e re-obter a lista de canais se ela estiver em cache.

## Payload

```json
{
  "event": "channel.updated",
  "id": "evt_abc200",
  "createdAt": "2025-01-20T15:30:00Z",
  "data": {
    "account": "1",
    "country": "6",
    "vendorId": 16,
    "channel": {
      "channelId": "CH-IFOOD-001",
      "code": "IFOOD",
      "name": "iFood",
      "description": "Orders received via iFood marketplace",
      "active": "ACTIVE",
      "authType": "API_KEY",
      "baseUrl": "https://api.ifood.com.br",
      "services": [
        {
          "code": "DELIVERY",
          "serviceId": "3",
          "referenceName": "Domicilios iFood"
        },
        {
          "code": "TAKEAWAY",
          "serviceId": "1",
          "referenceName": "Retiro en tienda"
        }
      ],
      "createdAt": "2025-01-15T10:00:00.000Z",
      "updatedAt": "2025-01-20T15:30:00.000Z"
    }
  }
}
```

## Campos

### `data`

| Campo | Tipo | Descrição |
|---|---|---|
| `account` | string | Identificador da conta — exigido por sistemas downstream |
| `country` | string | Identificador do país — exigido por sistemas downstream |
| `vendorId` | integer | Identificador da marca |
| `channel` | object | Objeto do canal atualizado — veja abaixo |

### `data.channel`

| Campo | Tipo | Descrição |
|---|---|---|
| `channelId` | string | Identificador único do canal |
| `code` | string | Código curto do canal (ex.: `IFOOD`, `RAPPI`, `KIOSK`) |
| `name` | string | Nome de exibição |
| `description` | string \| null | Descrição opcional |
| `active` | string | Status do canal: `ACTIVE` ou `INACTIVE` |
| `authType` | string | Mecanismo de autenticação: `API_KEY`, `OAUTH2`, `BASIC_AUTH`, `XMART_LOGIN` ou `NONE` |
| `baseUrl` | string \| null | URL base do endpoint de integração do canal |
| `services` | object[] | Serviços disponíveis através deste canal |
| `createdAt` | string | Timestamp ISO 8601 de criação |
| `updatedAt` | string | Timestamp ISO 8601 da última atualização |

### `data.channel.services[n]`

| Campo | Tipo | Descrição |
|---|---|---|
| `code` | string | Código do tipo de serviço (ex.: `DELIVERY`, `TAKEAWAY`) |
| `serviceId` | string | Identificador único do serviço |
| `referenceName` | string | Nome legível do serviço para este canal |

## Uso

<Steps>
  <Step title="Verifique a assinatura">
    Valide `X-Fire-Signature`. Veja [Autenticação](/pt/authentication).
  </Step>
  <Step title="Confirme imediatamente">
    Retorne `200 OK` antes de processar.
  </Step>
  <Step title="Atualize seu mapeamento de canais">
    Faça upsert do canal no seu store local usando `channelId` como chave. Se o canal passar para `INACTIVE`, pare de rotear eventos ou pedidos para ele.
  </Step>
</Steps>
