---
title: "store.deleted"
description: "Disparado quando uma loja é removida do Fire."
---

## Payload

```json
{
  "event": "store.deleted",
  "id": "evt_abc124",
  "createdAt": "2025-01-15T15:00:00Z",
  "data": {
    "account": "1",
    "country": "6",
    "storeId": 805,
    "vendorId": 16,
    "storeChannels": [
      "0F049503-85CF-E511-80C6-000D3A3261F3"
    ]
  }
}
```

## Campos

### `data`

| Campo | Tipo | Descrição |
|---|---|---|
| `account` | string | Identificador da conta — exigido por sistemas downstream |
| `country` | string | Identificador do país — exigido por sistemas downstream |
| `storeId` | integer | ID da loja excluída |
| `vendorId` | integer | Identificador da marca |
| `storeChannels` | string[] | UUIDs de canal com os quais a loja estava associada |

## Uso

Quando seu sistema receber este evento, remova ou desative a loja em seus sistemas downstream para cada canal listado em `storeChannels`.

Diferente de [`store.updated`](/pt/webhook-reference/store-updated), este evento é explícito — não há ambiguidade sobre se a loja deve existir downstream.
