---
title: "product.price_updated"
description: "Disparado quando o preço de um ou mais produtos é alterado. Aplica-se a todos os menus e lojas onde os produtos afetados aparecem."
---

`product.price_updated` é um evento **restrito** — diferente de [`product.updated`](/pt/webhook-reference/product-updated), ele transmite apenas o `priceInfo` de cada produto. Os demais atributos do produto (nome, descrição, imagens, modificadores, etc.) permanecem sem alteração.

Suporta múltiplos produtos em um único evento. Quando a alteração afeta várias lojas, o Fire emite um **único evento** com todas as lojas afetadas listadas em `targets`.

## Campos

### `data`

| Campo | Tipo | Descrição |
|---|---|---|
| `account` | string | Identificador da conta — necessário para sistemas externos |
| `country` | string | Código do país ISO 3166-1 alpha-2 (ex.: `EC`, `BR`, `CO`) — necessário para sistemas externos |
| `groupId` | string | UUID que correlaciona eventos do mesmo batch de publicação ou sincronização |
| `targets` | object[] | Lojas onde a alteração de preço deve ser aplicada |
| `products` | object[] | Produtos cujo preço foi alterado |

### `data.targets[n]`

Mesma estrutura que em [`product.updated`](/pt/webhook-reference/product-updated#datatargetsn) — inclui `vendorId` e `timezone`.

### `data.products[n]`

| Campo | Tipo | Descrição |
|---|---|---|
| `productId` | string | Identificador do produto |
| `priceInfo` | object | Informações de preço — substitui totalmente o `priceInfo` existente |
| `priceInfo.price` | number | Preço regular |
| `priceInfo.salePrice` | number | Preço com desconto |
| `priceInfo.suggestedPrice` | number | Preço regular sugerido |
| `priceInfo.suggestedPointPrice` | number | Preço em pontos sugerido |

## Comportamento

Este evento altera apenas o `priceInfo`. Nome, descrição, imagens, modificadores, impostos e demais atributos do produto permanecem sem alteração. O objeto `priceInfo` recebido substitui totalmente o existente para aquele `productId` — não é um merge campo a campo.
