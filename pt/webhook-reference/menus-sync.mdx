---
title: "menus.sync"
description: "Disparado quando o Fire precisa propagar cardápios de várias lojas de uma vez."
---

`menus.sync` é a contraparte em lote de [`menu.updated`](/pt/webhook-reference/menu-updated). O Fire o emite quando cardápios de várias lojas precisam ser propagados de uma vez — por exemplo, durante o onboarding inicial ou após uma mudança global de cardápio que afeta muitas lojas.

O Fire divide automaticamente sincronizações grandes e emite vários eventos `menus.sync`. Cada evento traz um único cardápio em `data.menu`. Use `batchIndex` e `batchTotal` para acompanhar o progresso da sincronização. Cada evento é entregue e reprocessado de forma independente.

## Campos

### `data`

| Campo | Tipo | Descrição |
|---|---|---|
| `account` | string | Identificador da conta — obrigatório para sistemas downstream |
| `country` | string | Código de país ISO 3166-1 alpha-2 (ex.: `EC`, `BR`, `CO`) — obrigatório para sistemas downstream |
| `batchIndex` | integer | Posição deste lote (1-based) |
| `batchTotal` | integer | Número total de lotes nesta sincronização |
| `menu` | object | Payload de cardápio completo — mesma estrutura que `data.menu` em [`menu.updated`](/pt/webhook-reference/menu-updated) |

### `data.menu`

| Campo | Tipo | Descrição |
|---|---|---|
| `list` | object | Metadados do cardápio e associação canal/loja |
| `categories` | object[] | Árvore de categorias |
| `products` | object[] | Catálogo de produtos |
| `modifierGroups` | object[] | Grupos de modificadores e opções |
| `scheduledActivities` | object[] | Janelas futuras de ativação/desativação |

Objetos aninhados usam as mesmas definições de campo que [`menu.updated`](/pt/webhook-reference/menu-updated#datamenu).

## Processamento

Processe cada evento `menus.sync` de forma independente. Aplique `data.menu` ao sistema downstream identificado por `menu.list.storeId` e `menu.list.channelId`.

O cardápio é uma **substituição completa** — mesma semântica de substituição total que [`menu.updated`](/pt/webhook-reference/menu-updated).

Use `batchIndex` e `batchTotal` para acompanhar o progresso se o seu sistema precisar saber quando uma sincronização completa termina.

<Note>
  Cada evento de lote é reprocessado de forma independente em caso de falha — não toda a sincronização.
</Note>

## Quando o Fire emite este evento?

- Durante o onboarding inicial do cliente
- Após uma mudança global de cardápio que afeta muitas lojas
- Em solicitações de sync explícitas pelo painel do Fire

Para mudanças individuais de cardápio em operação normal, o Fire emite [`menu.updated`](/pt/webhook-reference/menu-updated).
