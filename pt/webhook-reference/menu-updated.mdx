---
title: "menu.updated"
description: "Disparado quando um menu é criado ou atualizado e deve ser propagado para sistemas externos."
---

Um menu no Fire é a definição completa do catálogo para uma combinação específica de loja e canal — incluindo categorias, produtos, grupos de modificadores e horários. O payload é autocontido e pronto para ser encaminhado a sistemas externos. Trate-o como um upsert: crie o menu se não existir ou substitua-o inteiramente se já existir.

## Campos

### `data`

| Campo | Tipo | Descrição |
|---|---|---|
| `account` | string | Identificador da conta — necessário para sistemas externos |
| `country` | string | Código do país ISO 3166-1 alpha-2 (ex.: `EC`, `BR`, `CO`) — necessário para sistemas externos |
| `groupId` | string | UUID que identifica o grupo de sincronização. Vários eventos `menu.updated` emitidos no mesmo batch compartilham o mesmo `groupId`, permitindo que sistemas externos correlacionem todos os eventos que pertencem à mesma sincronização. |
| `menu` | object | Definição completa do menu |

### `data.menu`

| Campo | Tipo | Descrição |
|---|---|---|
| `list` | object | Metadados do menu e associação canal/loja |
| `categories` | object[] | Árvore de categorias |
| `products` | object[] | Catálogo de produtos |
| `modifierGroups` | object[] | Grupos de modificadores e opções |
| `scheduledActivities` | object[] | Janelas futuras de ativação/desativação |

### `data.menu.list`

| Campo | Tipo | Descrição |
|---|---|---|
| `ecommerceChannelId` | integer | Identificador padronizado do canal |
| `vendorId` | string | Identificador da marca |
| `storeId` | string | Identificador da loja |
| `channelId` | string | UUID do canal de vendas |
| `serviceId` | string | Identificador do serviço — o tipo de entrega coberto por este menu |
| `schedules` | object[] | Janelas de tempo em que este menu está ativo |

### `data.menu.list.schedules[n]`

| Campo | Tipo | Descrição |
|---|---|---|
| `day` | string | Dia da semana: `MONDAY`, `TUESDAY`, `WEDNESDAY`, `THURSDAY`, `FRIDAY`, `SATURDAY`, `SUNDAY` |
| `startTime` | string | Horário de abertura no formato `HH:mm` |
| `endTime` | string | Horário de fechamento no formato `HH:mm` |

### `data.menu.categories[n]`

| Campo | Tipo | Descrição |
|---|---|---|
| `categoryId` | string | Identificador da categoria |
| `categoryName` | string | Nome de exibição |
| `displayInList` | boolean | Se a categoria está visível |
| `featured` | boolean | Se a categoria está em destaque |
| `crossSellingCategory` | boolean | Se é uma categoria de venda cruzada |
| `position` | integer | Ordem de exibição |
| `images` | object[] | Imagens da categoria |
| `childCategories` | object[] | Subcategorias aninhadas |
| `productListing` | object[] | Produtos desta categoria com suas posições |
| `schedules` | object[] | Janelas de disponibilidade da categoria. Mesma estrutura que `list.schedules`. Array vazio indica sem restrição de horário. |

### `data.menu.products[n]`

| Campo | Tipo | Descrição |
|---|---|---|
| `productId` | string | Identificador do produto |
| `name` | string | Nome do produto |
| `description` | string | Descrição do produto |
| `standardTime` | boolean | `true` se o produto segue o horário geral do menu; `false` se tem seu próprio array `schedules` |
| `featured` | boolean | Se o produto está em destaque |
| `priceInfo` | object | Preço e preço promocional |
| `priceInfo.price` | number | Preço regular |
| `priceInfo.salePrice` | number | Preço com desconto |
| `productModifiers` | object[] | Referências de grupos de modificadores com posições |
| `schedules` | object[] | Janelas de disponibilidade do produto. Mesma estrutura que `list.schedules`. Avaliado apenas quando `standardTime` é `false`. |
| `images` | object[] | Imagens do produto |

### `data.menu.modifierGroups[n]`

| Campo | Tipo | Descrição |
|---|---|---|
| `modifierId` | string | Identificador do grupo de modificadores |
| `modifier` | string | Nome de exibição do grupo |
| `minOptions` | integer | Número mínimo de seleções obrigatórias |
| `maxOptions` | integer | Número máximo de seleções permitidas |
| `visible` | boolean | Se o grupo de modificadores está visível |
| `position` | integer | Ordem de exibição |
| `type` | string | Tipo de modificador |
| `modifierOptions` | object[] | Opções individuais do grupo — cada `productId` deve existir em `products` |

### `data.menu.modifierGroups[n].modifierOptions[n]`

| Campo | Tipo | Descrição |
|---|---|---|
| `optionId` | string | Identificador da opção |
| `productId` | string | Produto usado como esta opção |
| `default` | boolean | Se esta opção está selecionada por padrão |
| `position` | integer | Ordem de exibição |

### `data.menu.scheduledActivities[n]`

| Campo | Tipo | Descrição |
|---|---|---|
| `productId` | string | Identificador do produto |
| `scheduledActiveStatus` | string | Timestamp ISO 8601 de quando o produto é ativado |
| `scheduledInactiveStatus` | string | Timestamp ISO 8601 de quando o produto é desativado |

## Notas

- O payload é um **menu completo** — não um diff. Substitua o menu inteiro no sistema externo.
- Cada `menu.modifierGroups[n].modifierOptions[n].productId` deve referenciar um produto definido em `menu.products`.
- `scheduledActivities` define janelas futuras de ativação/desativação para produtos específicos.
- Quando `standardTime` é `true` em um produto, use os `list.schedules` do menu; quando é `false`, use o array `schedules` próprio do produto.
- Os arrays `schedules` de categorias e produtos têm a mesma forma que `list.schedules` — uma entrada por dia da semana.

## Remover um menu externamente

O Fire não emite um evento de exclusão separado para menus. Para remover um menu de um sistema externo, o Fire envia um evento `menu.updated` com `menu.categories`, `menu.products`, `menu.modifierGroups` e `menu.scheduledActivities` como arrays vazios. Seu sistema deve interpretar um menu vazio como sinal para desativar ou remover o menu externamente.

```json
{
  "event": {
    "id": "evt_def459",
    "type": "menu.updated",
    "createdAt": "2025-01-15T14:31:00Z"
  },
  "data": {
    "account": "1",
    "country": "BR",
    "groupId": "a3f7c2d1-84be-4e10-9b3a-2c5d6e7f8091",
    "menu": {
      "list": { "..." : "..." },
      "categories": [],
      "products": [],
      "modifierGroups": [],
      "scheduledActivities": []
    }
  }
}
```
