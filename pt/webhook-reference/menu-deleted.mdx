---
title: "menu.deleted"
description: "Disparado quando um menu (list) é removido do Fire."
---

<Warning>
  **Ainda não emitido.** O Fire não envia este evento hoje. Atualmente, remover um
  menu em um sistema externo é sinalizado por meio de
  [`menu.updated`](/pt/webhook-reference/menu-updated) com `categories`, `products` e
  `modifierGroups` como arrays vazios — veja
  [Remover um menu externamente](/pt/webhook-reference/menu-updated#remover-um-menu-externamente).
  Esta página documenta um evento de exclusão dedicado planejado, como referência
  futura; não está no índice de eventos e você não deve construir contra ele ainda.
</Warning>

## Payload

```json
{
  "event": {
    "id": "evt_def457",
    "type": "menu.deleted",
    "createdAt": "2025-01-15T15:10:00Z",
    "timezone": "America/Guayaquil"
  },
  "data": {
    "listId": "pickup-menu-t005",
    "vendorId": "16",
    "storeId": "805",
    "channelId": "0E049503-85CF-E511-80C6-000D3A3261F3"
  }
}
```

## Campos

### `data`

| Campo | Tipo | Descrição |
|---|---|---|
| `listId` | string | Identificador do menu excluído |
| `vendorId` | string | Identificador da marca |
| `storeId` | string | Loja à qual o menu pertencia |
| `channelId` | string | UUID do canal ao qual o menu estava atribuído |

## Uso

Quando seu sistema recebe este evento, remova ou desative o menu nos seus sistemas externos para a loja e canal identificados.

Diferente de [`menu.updated`](/pt/webhook-reference/menu-updated), este evento é explícito — não há ambiguidade sobre se o menu deveria continuar existindo externamente.
