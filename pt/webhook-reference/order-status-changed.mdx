---
title: "order.status_changed"
description: "Disparado quando o status de um pedido muda dentro do Fire."
---

## Payload

```json
{
  "event": {
    "id": "evt_jkl012",
    "type": "order.status_changed",
    "createdAt": "2025-01-15T14:35:00Z",
    "timezone": "America/Guayaquil"
  },
  "data": {
    "account": "1",
    "country": "6",
    "fire_order_id": "fire_order_abc",
    "external_order_id": "uber_order_9876",
    "channel_id": "channel_abc123",
    "status": "in_preparation",
    "previous_status": "accepted",
    "updated_at": "2025-01-15T14:35:00Z"
  }
}
```

## Campos

### `data`

| Campo | Tipo | Descrição |
|---|---|---|
| `account` | string | Identificador da conta |
| `country` | string | Identificador do país |
| `fire_order_id` | string | ID interno do pedido no Fire |
| `external_order_id` | string | ID do pedido no agregador (o que você enviou ao injetá-lo) |
| `channel_id` | string | ID do canal do Fire ao qual o pedido pertence |
| `status` | string | Novo status do pedido |
| `previous_status` | string | Status anterior do pedido |
| `updated_at` | string | Marca de tempo ISO 8601 da mudança de status |

## Valores de status

| Status | Descrição |
|---|---|
| `received` | O Fire recebeu o pedido |
| `accepted` | O restaurante aceitou o pedido |
| `in_preparation` | A cozinha começou a prepará-lo |
| `ready` | O pedido está pronto para retirada ou despacho |
| `dispatched` | Entregue ao entregador |
| `delivered` | Entregue ao cliente |
| `cancelled` | O pedido foi cancelado |
