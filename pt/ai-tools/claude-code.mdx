Configure o Claude Code para escrever e manter sua documentação Mintlify.

## Pré-requisitos

- Assinatura ativa do Claude (Pro, Max ou acesso à API)

## Configuração

<Steps>
<Step title="Instale o Claude Code">
  ```bash
  npm install -g @anthropic-ai/claude-code
  ```
</Step>

<Step title="Instale a skill do Mintlify">
  No diretório da documentação, execute:

  ```bash
  npx skills add https://mintlify.com/docs
  ```

  Isso fornece a referência de componentes, padrões de escrita
  e orientações de fluxo do Mintlify.
</Step>

<Step title="Personalize as instruções do projeto">
  Edite o `AGENTS.md` na raiz para adicionar terminologia,
  estilo e limites de conteúdo.
</Step>

<Step title="Comece a escrever com o Claude Code">
  ```bash
  claude
  ```
</Step>
</Steps>
