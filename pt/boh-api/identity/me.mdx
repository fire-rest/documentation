---
title: "Obter contexto da conta"
api: "GET https://boh.api.fire.rest/api/v1/public/identity/me"
description: "Retorna a conta e as informações da API key derivadas do header x-api-key. Use para verificar a conectividade e descobrir o account_id."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key do BOH.
</ParamField>

<ResponseField name="account_id" type="string">UUID da conta associada a esta key.</ResponseField>
<ResponseField name="api_key" type="object">`{ id, key_prefix }` — UUID da key e o prefixo não secreto para exibição.</ResponseField>
<ResponseField name="currency_id" type="string">UUID da moeda configurada na conta (ou `null`).</ResponseField>
<ResponseField name="currency" type="object">`{ id, code, name, symbol, decimal_places }` — detalhes completos da moeda, ou `null`.</ResponseField>

<ResponseExample>
```json 200
{
  "account_id": "acc_01j5k...",
  "api_key": {
    "id": "key_01j5k...",
    "key_prefix": "boh_live_xxxx"
  },
  "currency_id": "cur_01...",
  "currency": {
    "id": "cur_01...",
    "code": "BRL",
    "name": "Brazilian Real",
    "symbol": "R$",
    "decimal_places": 2
  }
}
```
</ResponseExample>
