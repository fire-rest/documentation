---
title: "Obter um fornecedor"
api: "GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers/{supplierId}"
description: "Retorna detalhes completos de um único fornecedor incluindo metadata."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key do BOH com escopo `catalog:read`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>
<ParamField path="supplierId" type="string" required>UUID do fornecedor.</ParamField>

<ResponseExample>
```json 200
{
  "id": "sup_01j5k...",
  "account_id": "acc_01j5k...",
  "name": "Fornecedor Fresco Ltda.",
  "external_supplier_id": "fornecedor-fresco",
  "status": "ACTIVE",
  "metadata": {}
}
```

```json 404
{
  "error": {
    "kind": "supplier_not_found",
    "message": "Supplier not found"
  }
}
```
</ResponseExample>
