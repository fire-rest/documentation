---
title: "Listar vendors"
api: "GET https://boh.api.fire.rest/api/v1/public/identity/vendors"
description: "Retorna todos os vendors da sua conta. Use para descobrir os IDs de vendor necessários para as demais chamadas."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key do BOH com escopo `catalog:read`.
</ParamField>

<ResponseField name="vendors" type="object[]">
  Array de objetos vendor: `id`, `account_id`, `external_vendor_id`, `name`, `status`, `metadata`, `created_at`, `updated_at`.
</ResponseField>
