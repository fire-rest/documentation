---
title: "Criar um estabelecimento"
api: "POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/stores"
description: "Cria um novo estabelecimento (localização física) para o vendor."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key do BOH com escopo `catalog:write`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>
<ParamField body="name" type="string" required>Nome de exibição (máx. 200 caracteres).</ParamField>
<ParamField body="timezone" type="string" required>Identificador de fuso horário IANA (ex. `America/Sao_Paulo`).</ParamField>
<ParamField body="code" type="string">Código alfanumérico curto.</ParamField>
<ParamField body="external_store_id" type="string">Identificador do estabelecimento no seu sistema.</ParamField>
<ParamField body="tax_id" type="string">Identificador fiscal do estabelecimento (RUC, CNPJ, CUIT, NIT, RUT, RFC ou qualquer código alfanumérico do país, máx. 64 chars). Opcional e não único — em alguns países todos os estabelecimentos de uma empresa compartilham o mesmo valor. Usado para resolver o estabelecimento em ordens de compra via `store_tax_id`. Envie `null` para limpar.</ParamField>
<ParamField body="metadata" type="object">Dados adicionais livres.</ParamField>
<ParamField body="external_user_id" type="string">Ator para auditoria.</ParamField>

<RequestExample>
```json
{
  "name": "Cozinha Principal",
  "timezone": "America/Sao_Paulo",
  "code": "EST-001",
  "external_store_id": "loja-principal",
  "external_user_id": "admin_01"
}
```
</RequestExample>

<ResponseExample>
```json 201
{
  "id": "str_principal_01...",
  "name": "Cozinha Principal",
  "timezone": "America/Sao_Paulo",
  "status": "ACTIVE",
  "external_store_id": "loja-principal",
  "tax_id": null,
  "metadata": {},
  "created_at": "2026-08-07T14:30:00.000Z",
  "updated_at": "2026-08-07T14:30:00.000Z"
}
```
</ResponseExample>
