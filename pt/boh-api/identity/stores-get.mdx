---
title: "Obter um estabelecimento"
api: "GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/stores/{storeId}"
description: "Retorna um único estabelecimento com detalhes completos incluindo metadata."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key do BOH com escopo `catalog:read`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>
<ParamField path="storeId" type="string" required>UUID do estabelecimento.</ParamField>

<ResponseExample>
```json 200
{
  "id": "str_principal_01...",
  "account_id": "acc_01j5k...",
  "code": "EST-001",
  "name": "Cozinha Principal",
  "timezone": "America/Sao_Paulo",
  "status": "ACTIVE",
  "external_store_id": "loja-principal",
  "metadata": {}
}
```

```json 404
{
  "error": {
    "kind": "store_not_found",
    "message": "Store not found"
  }
}
```
</ResponseExample>
