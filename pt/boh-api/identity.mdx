title: "Identidade"

---

Os endpoints de identidade são seu ponto de partida. Permitem confirmar a qual conta sua API key está vinculada, descobrir seus vendors e enumerar os estabelecimentos e fornecedores que você referenciará nas chamadas de catálogo e operações.

**Scopes necessários:** `catalog:read` para a maioria das leituras; `catalog:write` para criações e atualizações.

---

## Me

### Obter meu contexto de conta

<api>GET https://boh.api.fire.rest/api/v1/public/identity/me</api>

Retorna a conta e as informações da API key derivadas do header `x-api-key`. Use esta chamada para verificar a conectividade e descobrir seu `account_id` antes de fazer escritas.

<ParamField header="x-api-key" type="string" required>API key do BOH.</ParamField>

<ResponseField name="account_id" type="string">UUID da conta associada a esta key.</ResponseField>
<ResponseField name="api_key" type="object">
  `{ id, key_prefix }` — UUID da key e o prefixo não secreto para exibição.
</ResponseField>
<ResponseField name="currency_id" type="string">UUID da moeda configurada na conta (ou `null` se não configurada).</ResponseField>
<ResponseField name="currency" type="object">
  `{ id, code, name, symbol, decimal_places }` — detalhes completos da moeda, ou `null`.
</ResponseField>

<ResponseExample>
```json 200
{
  "account_id": "acc_01j5k...",
  "api_key": {
    "id": "key_01j5k...",
    "key_prefix": "boh_live_xxxx"
  },
  "currency_id": "cur_01...",
  "currency": {
    "id": "cur_01...",
    "code": "BRL",
    "name": "Brazilian Real",
    "symbol": "R$",
    "decimal_places": 2
  }
}
```
</ResponseExample>

## Vendors

Um **vendor** representa uma entidade operacional configurada no BOH (uma marca de restaurante ou unidade). A maioria dos outros endpoints inclui um parâmetro de rota `{vendorId}` que deve ser um UUID de vendor válido para sua conta.

### Listar vendors

<api>GET https://boh.api.fire.rest/api/v1/public/identity/vendors</api>

Retorna todos os vendors da sua conta. Use para descobrir os IDs de vendor.

<ResponseField name="vendors" type="object[]">
  Array de objetos vendor: `id`, `account_id`, `external_vendor_id`, `name`, `status`, `metadata`, `created_at`, `updated_at`.
</ResponseField>

<ResponseExample>
```json 200
{
  "vendors": [
    {
      "id": "vnd_01j5k...",
      "account_id": "acc_01j5k...",
      "external_vendor_id": "marca-principal",
      "name": "Minha Marca de Restaurante",
      "status": "ACTIVE",
      "metadata": {},
      "created_at": "2026-01-01T00:00:00.000Z",
      "updated_at": "2026-01-01T00:00:00.000Z"
    }
  ]
}
```
</ResponseExample>

---

### Obter um vendor

<api>GET https://boh.api.fire.rest/api/v1/public/identity/vendors/{vendorId}</api>

Retorna um único vendor pelo UUID.

<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>

## Estabelecimentos

Estabelecimentos representam localizações físicas (cozinhas, depósitos, pontos de venda). Operações como recebimentos, contagens e transferências têm como alvo um estabelecimento específico.

### Listar estabelecimentos

<api>GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/stores</api>

<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>
<ParamField query="limit" type="number">Resultados por página (1–200, padrão 50).</ParamField>
<ParamField query="offset" type="number">Offset de paginação (padrão 0).</ParamField>
<ParamField query="status" type="string">Filtrar por `ACTIVE` ou `INACTIVE`.</ParamField>

<ResponseField name="items" type="object[]">
  Array de objetos de estabelecimento: `id`, `account_id`, `code`, `name`, `timezone`, `status`, `external_store_id`, `created_at`, `updated_at`.
</ResponseField>
<ResponseField name="total" type="number">Total de registros correspondentes.</ResponseField>
<ResponseField name="limit" type="number">Tamanho de página atual.</ResponseField>
<ResponseField name="offset" type="number">Offset atual.</ResponseField>

<ResponseExample>
```json 200
{
  "items": [
    {
      "id": "str_principal_01...",
      "account_id": "acc_01j5k...",
      "code": "EST-001",
      "name": "Cozinha Principal",
      "timezone": "America/Sao_Paulo",
      "status": "ACTIVE",
      "external_store_id": "loja-principal",
      "created_at": "2026-01-01T00:00:00.000Z",
      "updated_at": "2026-01-01T00:00:00.000Z"
    }
  ],
  "total": 1,
  "limit": 50,
  "offset": 0
}
```
</ResponseExample>

---

### Obter um estabelecimento

<api>GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/stores/{storeId}</api>

Retorna um único estabelecimento com detalhes completos (inclui `metadata`).

<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>
<ParamField path="storeId" type="string" required>UUID do estabelecimento.</ParamField>

---

### Criar um estabelecimento

<api>POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/stores</api>

<ParamField body="name" type="string" required>Nome de exibição (máx. 200 chars).</ParamField>
<ParamField body="code" type="string">Código alfanumérico curto.</ParamField>
<ParamField body="timezone" type="string" required>Identificador de fuso horário IANA (ex. `America/Sao_Paulo`).</ParamField>
<ParamField body="external_store_id" type="string">Identificador do estabelecimento no seu sistema (usado em payloads de operações em vez do UUID).</ParamField>
<ParamField body="metadata" type="object">Dados extras livres.</ParamField>
<ParamField body="external_user_id" type="string">Ator para auditoria.</ParamField>

---

### Atualizar um estabelecimento

<api>PATCH https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/stores/{storeId}</api>

Atualização parcial — inclua apenas os campos que deseja alterar.

---

### Arquivar / Desarquivar um estabelecimento

<api>POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/stores/{storeId}/archive</api>
<api>POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/stores/{storeId}/unarchive</api>

---

## Fornecedores

Fornecedores são as empresas das quais você compra. São referenciados em recebimentos de mercadoria e ordens de compra.

### Listar fornecedores

<api>GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers</api>

<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>
<ParamField query="limit" type="number">Resultados por página (1–200, padrão 50).</ParamField>
<ParamField query="offset" type="number">Offset de paginação.</ParamField>
<ParamField query="include_archived" type="boolean">Padrão `false`.</ParamField>

<ResponseField name="items" type="object[]">
  Array de objetos de fornecedor: `id`, `account_id`, `external_supplier_id`, `code`, `name`, `email`, `phone`, `tax_id`, `is_active`, `created_at`, `updated_at`.
</ResponseField>

---

### Obter um fornecedor

<api>GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers/{supplierId}</api>

Retorna um único fornecedor com `metadata`.

---

### Criar um fornecedor

<api>POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers</api>

<ParamField body="name" type="string" required>Nome do fornecedor.</ParamField>
<ParamField body="code" type="string">Código alfanumérico curto.</ParamField>
<ParamField body="external_supplier_id" type="string">Identificador do fornecedor no seu sistema. Deve ser único dentro da conta.</ParamField>
<ParamField body="email" type="string">E-mail de contato.</ParamField>
<ParamField body="phone" type="string">Telefone de contato.</ParamField>
<ParamField body="tax_id" type="string">Identificador fiscal (CNPJ, etc.).</ParamField>
<ParamField body="metadata" type="object">Dados extras livres.</ParamField>
<ParamField body="external_user_id" type="string">Ator para auditoria.</ParamField>

---

### Atualizar um fornecedor

<api>PATCH https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers/{supplierId}</api>

Atualização parcial — inclua apenas os campos que deseja alterar.

---

### Arquivar / Desarquivar um fornecedor

<api>POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers/{supplierId}/archive</api>
<api>POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers/{supplierId}/unarchive</api>

---

### Sincronização em massa de fornecedores

<api>PUT https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers</api>

Ver [Catálogo: Sincronização em massa → Sincronizar fornecedores](/pt/boh-api/catalog-sync#sincronizar-fornecedores) para a referência completa.
