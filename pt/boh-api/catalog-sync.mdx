---
title: "Catálogo: Sincronização em massa"
description: "Upsert em massa de unidades, fornecedores e atribuições de classificação via endpoints PUT."
---

O BOH expõe endpoints PUT de sincronização em massa para recursos que normalmente são gerenciados a partir de um sistema de registro externo. Todas as operações de sync usam `code` ou um campo `external_*_id` como chave de idempotência e retornam uma resposta `{ results, summary }`.

**Scope necessário:** `catalog:write`.

---

## Sincronizar unidades

<api>PUT https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/catalog/units</api>

Upsert de unidades por `code` + `unit_group_code`. As que coincidem com um registro existente são atualizadas; as novas são criadas. Unidades globais (definidas pelo sistema) são retornadas como `action: "skipped_global"` e não são modificadas.

<ParamField header="x-api-key" type="string" required>API key do BOH com scope `catalog:write`.</ParamField>
<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>

<ParamField body="units" type="object[]" required>
  Array de linhas de unidade:
  <Expandable title="campos da linha de unidade">
    <ParamField body="code" type="string" required>Código alfanumérico único dentro do grupo de unidades (1–64 chars).</ParamField>
    <ParamField body="name" type="string" required>Nome de exibição.</ParamField>
    <ParamField body="unit_group_code" type="string" required>Código do grupo de unidades pai (ex. `MASS`, `VOLUME`, `COUNT`).</ParamField>
    <ParamField body="conversion_factor_to_base" type="number" required>Quantas unidades base equivalem a uma unidade deste tipo (ex. `1000` para kg quando a base é g).</ParamField>
    <ParamField body="symbol" type="string">Símbolo de exibição (ex. `kg`, `ml`).</ParamField>
    <ParamField body="system" type="string">`METRIC`, `IMPERIAL` ou `OTHER`.</ParamField>
    <ParamField body="archived" type="boolean">Enviar `true` para arquivar a unidade.</ParamField>
  </Expandable>
</ParamField>

<ParamField body="external_user_id" type="string">Ator para auditoria.</ParamField>

<ResponseField name="results" type="object[]">
  Uma entrada por linha de entrada: `code`, `unit_group_code`, `id` e `action` (`created`, `updated`, `unchanged` ou `skipped_global`).
</ResponseField>

<ResponseField name="summary" type="object">
  Contagens `{ created, updated, unchanged, skipped_global }`.
</ResponseField>

<RequestExample>
```json
{
  "units": [
    {
      "code": "KG",
      "name": "Quilograma",
      "unit_group_code": "MASS",
      "conversion_factor_to_base": 1000,
      "symbol": "kg",
      "system": "METRIC"
    },
    {
      "code": "LB",
      "name": "Libra",
      "unit_group_code": "MASS",
      "conversion_factor_to_base": 453.592,
      "symbol": "lb",
      "system": "IMPERIAL"
    }
  ],
  "external_user_id": "user_setup_01"
}
```
</RequestExample>

<ResponseExample>
```json 200
{
  "results": [
    { "code": "KG", "unit_group_code": "MASS", "id": "unit_kg_01...", "action": "unchanged" },
    { "code": "LB", "unit_group_code": "MASS", "id": "unit_lb_01...", "action": "created" }
  ],
  "summary": { "created": 1, "updated": 0, "unchanged": 1, "skipped_global": 0 }
}
```
</ResponseExample>

## Sincronizar fornecedores

<api>PUT https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers</api>

Upsert de fornecedores por `external_supplier_id`. Fornecedores cujo `external_supplier_id` não está no lote são deixados intactos.

<ParamField header="x-api-key" type="string" required>API key do BOH com scope `catalog:write`.</ParamField>
<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>

<ParamField body="suppliers" type="object[]" required>
  Array de linhas de fornecedor:
  <Expandable title="campos da linha de fornecedor">
    <ParamField body="external_supplier_id" type="string" required>Chave única no seu sistema (1–128 chars). Usada como chave de correspondência.</ParamField>
    <ParamField body="name" type="string" required>Nome de exibição.</ParamField>
    <ParamField body="code" type="string">Código alfanumérico curto.</ParamField>
    <ParamField body="email" type="string">E-mail de contato.</ParamField>
    <ParamField body="phone" type="string">Telefone de contato.</ParamField>
    <ParamField body="tax_id" type="string">Identificador fiscal.</ParamField>
    <ParamField body="archived" type="boolean">Enviar `true` para arquivar o fornecedor.</ParamField>
    <ParamField body="metadata" type="object">Dados extras livres.</ParamField>
  </Expandable>
</ParamField>

<ParamField body="external_user_id" type="string">Ator para auditoria.</ParamField>

<ResponseField name="results" type="object[]">
  Uma entrada por linha: `external_supplier_id`, `id`, `action` (`created`, `updated`, `unchanged`).
</ResponseField>

<ResponseField name="summary" type="object">
  Contagens `{ created, updated, unchanged }`.
</ResponseField>

<RequestExample>
```json
{
  "suppliers": [
    {
      "external_supplier_id": "FORN-001",
      "name": "Alimentos do Norte Ltda.",
      "code": "ALT-NORTE",
      "email": "pedidos@alimentosnorte.com.br",
      "tax_id": "12.345.678/0001-99"
    },
    {
      "external_supplier_id": "FORN-002",
      "name": "Fornecedor Antigo",
      "archived": true
    }
  ],
  "external_user_id": "user_setup_01"
}
```
</RequestExample>

<ResponseExample>
```json 200
{
  "results": [
    { "external_supplier_id": "FORN-001", "id": "sup_01...", "action": "created" },
    { "external_supplier_id": "FORN-002", "id": "sup_02...", "action": "updated" }
  ],
  "summary": { "created": 1, "updated": 1, "unchanged": 0 }
}
```
</ResponseExample>

## Substituir atribuições de classificação

<api>PUT https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/catalog/classifications/assignments</api>

**Substitui** todas as atribuições de classificação de uma entidade (item ou estabelecimento). Esta é uma operação destrutiva: atribuições existentes da entidade que não estiverem na requisição são excluídas. Use `GET /catalog/classifications/assignments?entity_type=ITEM&entity_id={id}` primeiro se quiser ler o estado atual.

<ParamField header="x-api-key" type="string" required>API key do BOH com scope `catalog:write`.</ParamField>
<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>

<ParamField body="entity_type" type="string" required>
  `ITEM` ou `STORE`.
</ParamField>

<ParamField body="entity_id" type="string" required>
  UUID do item ou estabelecimento a classificar.
</ParamField>

<ParamField body="assignments" type="object[]" required>
  Uma entrada por categoria de classificação:
  <Expandable title="campos da entrada de atribuição">
    <ParamField body="classification_category_id" type="string" required>UUID da categoria de classificação.</ParamField>
    <ParamField body="classification_ids" type="string[]" required>UUIDs dos valores a atribuir nesta categoria. Envie `[]` para limpar a categoria.</ParamField>
  </Expandable>
</ParamField>

<ParamField body="external_user_id" type="string">Ator para auditoria.</ParamField>

<ResponseField name="items" type="object[]">
  A lista completa de atribuições agora vigentes para a entidade.
</ResponseField>

<Warning>
  Este endpoint exclui todas as atribuições existentes da entidade que não estiverem na requisição. Se quiser adicionar ou atualizar apenas uma categoria, você deve incluir também todas as outras categorias que deseja manter.
</Warning>

## Ler atribuições de classificação

<api>GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/catalog/classifications/assignments</api>

Retorna todas as atribuições de classificação filtradas por entidade.

<ParamField query="entity_type" type="string">`ITEM` ou `STORE`.</ParamField>
<ParamField query="entity_id" type="string">UUID da entidade.</ParamField>
