---
title: "Obter item"
api: "GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/catalog/items/{itemId}"
description: "Retorna detalhes completos de um item do catálogo."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key do BOH com escopo `catalog:read`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>
<ParamField path="itemId" type="string" required>UUID do item.</ParamField>

<ResponseExample>
```json 200
{
  "id": "itm_01...",
  "name": "Tomate",
  "status": "ACTIVE",
  "base_unit_id": "unit_kg_01...",
  "unit_group_id": "ug_peso_01...",
  "external_item_id": "tomate"
}
```

```json 404
{
  "error": {
    "kind": "item_not_found",
    "message": "Item not found"
  }
}
```
</ResponseExample>
