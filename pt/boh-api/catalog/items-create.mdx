---
title: "Criar item"
api: "POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/catalog/items"
description: "Cria um novo item no catálogo para o vendor."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key do BOH com escopo `catalog:write`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>
<ParamField body="name" type="string" required>Nome do item (máx. 200 caracteres).</ParamField>
<ParamField body="base_unit_id" type="string" required>UUID da unidade de medida base.</ParamField>
<ParamField body="unit_group_id" type="string" required>UUID do grupo de unidades.</ParamField>
<ParamField body="external_item_id" type="string">Identificador no seu sistema.</ParamField>
<ParamField body="metadata" type="object">Dados adicionais livres.</ParamField>
<ParamField body="external_user_id" type="string">Ator para auditoria.</ParamField>

<RequestExample>
```json
{
  "name": "Tomate",
  "base_unit_id": "unit_kg_01...",
  "unit_group_id": "ug_peso_01...",
  "external_item_id": "tomate"
}
```
</RequestExample>

<ResponseExample>
```json 201
{
  "id": "itm_01...",
  "name": "Tomate",
  "status": "ACTIVE"
}
```
</ResponseExample>
