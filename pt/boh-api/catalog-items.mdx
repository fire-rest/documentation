---
title: "Catálogo: Itens"
description: "Listar, criar, atualizar, sincronizar e arquivar itens de inventário no catálogo do BOH."
---

Itens são os insumos e ingredientes físicos que você rastreia no BOH. Cada item pertence a um grupo de unidades, tem uma unidade base e pode ser vinculado a fornecedores, etiquetas de itens e valores de classificação.

**Escopos necessários:** `catalog:read` (leituras), `catalog:write` (escritas).

---

## Listar itens

<api>GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/catalog/items</api>

Retorna itens do vendor com filtros opcionais. Suporta **paginação por offset** (padrão, retorna `total`) e **paginação por cursor** (passe `cursor`, retorna `next_cursor` e `has_more`).

<ParamField header="x-api-key" type="string" required>
  API key do BOH com escopo `catalog:read`.
</ParamField>

<ParamField path="vendorId" type="string" required>
  UUID do vendor (entidade BOH).
</ParamField>

<ParamField query="search" type="string">
  Correspondência parcial no nome ou código do item (1–256 caracteres).
</ParamField>

<ParamField query="status" type="string" default="ACTIVE">
  Filtrar por status: `ACTIVE`, `ARCHIVED` ou `ALL`.
</ParamField>

<ParamField query="procurement_type" type="string">
  `PURCHASED`, `PRODUCED` ou `PURCHASED_AND_PRODUCED`.
</ParamField>

<ParamField query="tag_id" type="string">
  UUID de uma etiqueta de itens — retorna apenas itens que pertencem a essa etiqueta.
</ParamField>

<ParamField query="include" type="string">
  Sideloads separados por vírgula: `tags`, `unit_group`, `memberships`.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Tamanho da página (1–200).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Offset para paginação baseada em páginas.
</ParamField>

<ParamField query="cursor" type="string">
  Cursor opaco para paginação por cursor. Mutuamente exclusivo com `offset`.
</ParamField>

<RequestExample>
```http
GET /api/v1/public/vendors/vnd_abc123/catalog/items?status=ACTIVE&include=tags&limit=20
x-api-key: boh_live_xxxxxxxx
```
</RequestExample>

## Criar item

<api>POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/catalog/items</api>

Cria um novo item no catálogo.

<ParamField header="x-api-key" type="string" required>
  API key do BOH com escopo `catalog:write`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>

<ParamField body="name" type="string" required>Nome para exibição (1–256 caracteres).</ParamField>

<ParamField body="type" type="string" required>
  Tipo do item: `INGREDIENT`, `PACKAGING`, `SUPPLY`, `PREPARED_ITEM` ou `FINISHED_GOOD`.
</ParamField>

<ParamField body="procurement_type" type="string" required>
  Como o item é obtido: `PURCHASED`, `PRODUCED` ou `PURCHASED_AND_PRODUCED`.
</ParamField>

<ParamField body="unit_group_id" type="string" required>
  UUID do grupo de unidades (ex.: massa, volume, contagem). Não pode ser alterado após a criação.
</ParamField>

<ParamField body="base_unit_id" type="string" required>
  UUID da unidade base dentro do grupo (ex.: gramas dentro de massa). Não pode ser alterado após a criação.
</ParamField>

<ParamField body="external_item_id" type="string">
  Identificador do seu sistema para este item (1–128 caracteres). Usado para reconciliação no sync.
</ParamField>

<ParamField body="code" type="string">
  Código alfanumérico curto (1–64 caracteres). Deve ser único dentro do vendor.
</ParamField>

<ParamField body="is_inventory_tracked" type="boolean" default="true">
  Se o BOH registra movimentações de estoque para este item.
</ParamField>

<ParamField body="count_frequency" type="string | null">
  Ciclo de contagem física sugerido: `DAILY`, `WEEKLY`, `MONTHLY` ou `null`.
</ParamField>

<ParamField body="metadata" type="object">
  Armazenamento livre de chave-valor para dados extras do seu sistema.
</ParamField>

<ParamField body="external_user_id" type="string">
  ID do usuário que realiza esta ação no seu sistema (para auditoria).
</ParamField>

<RequestExample>
```json
{
  "name": "Farinha de trigo",

  "unit_group_id": "ug_massa_01...",

  "is_inventory_tracked": true,

  "external_user_id": "user_jane_42"
}
```

  "unit_group_id": "ug_massa_01...",

## Sincronizar itens (bulk upsert)

<api>PUT https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/catalog/items</api>

Upsert de até **200 itens** em uma única chamada usando `external_item_id` como chave de correspondência. Itens são criados ou atualizados; itens existentes cujo `external_item_id` não esteja no batch não são tocados. Para arquivar um item via sync, defina `"archived": true` na sua linha.

<ParamField body="items" type="object[]" required>
  Array de 1–200 linhas de itens. Cada linha aceita os mesmos campos que a criação individual, usando `unit_group_code` e `base_unit_code` (códigos) em vez de UUIDs.
</ParamField>

<ParamField body="external_user_id" type="string">
  ID do usuário que realiza esta ação no seu sistema.
</ParamField>

<ResponseField name="results" type="object[]">
  Uma entrada por linha de entrada: `external_item_id`, `id` e `action` (`created`, `updated` ou `unchanged`).
</ResponseField>

<ResponseField name="summary" type="object">
  Contagens `{ created, updated, unchanged }`.
</ResponseField>

## Obter item

<api>GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/catalog/items/{itemId}</api>

Retorna um único item com seu detalhe completo incluindo `metadata`.

---

## Atualizar item

<api>PATCH https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/catalog/items/{itemId}</api>

Atualiza parcialmente um item. Apenas os campos enviados são alterados. `unit_group_id` e `base_unit_id` não podem ser alterados após a criação.

<ParamField body="name" type="string">Novo nome.</ParamField>
<ParamField body="type" type="string">Novo tipo.</ParamField>
<ParamField body="procurement_type" type="string">Novo tipo de abastecimento.</ParamField>
<ParamField body="is_inventory_tracked" type="boolean">Alternar rastreamento de estoque.</ParamField>
<ParamField body="count_frequency" type="string | null">Novo ciclo de contagem.</ParamField>
<ParamField body="metadata" type="object">Substitui o objeto metadata existente.</ParamField>
<ParamField body="external_user_id" type="string">Ator para auditoria.</ParamField>

---

## Arquivar item

<api>POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/catalog/items/{itemId}/archive</api>

Exclusão lógica do item. Itens arquivados não aparecem em listagens por padrão (`status=ACTIVE`). Receitas e movimentações históricas que referenciam o item não são afetadas.

Retorna `{ "ok": true }` em caso de sucesso.

---

## Desarquivar item

<api>POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/catalog/items/{itemId}/unarchive</api>

Restaura um item arquivado ao status ativo.

Retorna `{ "ok": true }` em caso de sucesso.
