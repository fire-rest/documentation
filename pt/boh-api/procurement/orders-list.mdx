---
title: "Listar pedidos de compra"
api: "GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/procurement/orders"
description: "Retorna os pedidos de compra do vendor com filtros opcionais."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key do BOH com escopo `inventory:read`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>
<ParamField query="status" type="string">Filtrar por status: `DRAFT`, `SUBMITTED`, `CONFIRMED`, `PARTIALLY_RECEIVED`, `CLOSED`, ou `CANCELLED`.</ParamField>
<ParamField query="supplier_id" type="string">Filtrar por fornecedor.</ParamField>
<ParamField query="store_id" type="string">Filtrar por estabelecimento.</ParamField>
<ParamField query="from" type="string">Data de início (ISO 8601).</ParamField>
<ParamField query="to" type="string">Data de fim (ISO 8601).</ParamField>
<ParamField query="limit" type="number">Resultados por página (padrão 50).</ParamField>
<ParamField query="offset" type="number">Offset de paginação.</ParamField>

<ResponseField name="purchase_orders" type="object[]">Array de pedidos de compra.</ResponseField>
<ResponseField name="total" type="number">Total de registros.</ResponseField>

<ResponseExample>
```json 200
{
  "purchase_orders": [
    {
      "id": "po_01...",
      "status": "SUBMITTED",
      "supplier_id": "sup_01...",
      "expected_delivery_date": "2026-08-10"
    }
  ],
  "total": 1
}
```
</ResponseExample>
