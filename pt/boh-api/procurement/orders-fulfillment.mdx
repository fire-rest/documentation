---
title: "Obter status de fulfillment"
api: "GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/procurement/orders/{orderId}/fulfillment"
description: "Retorna o status de fulfillment do pedido mostrando a quantidade pedida vs. recebida por linha."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key do BOH com escopo `inventory:read`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>
<ParamField path="orderId" type="string" required>UUID do pedido de compra.</ParamField>

<ResponseField name="order_id" type="string">UUID do pedido.</ResponseField>
<ResponseField name="status" type="string">Status atual do pedido.</ResponseField>
<ResponseField name="lines" type="object[]">Linhas com quantidade pedida e recebida.</ResponseField>

<ResponseExample>
```json 200
{
  "order_id": "po_01...",
  "status": "PARTIALLY_RECEIVED",
  "lines": [
    {
      "line_id": "pol_01...",
      "item_id": "itm_01...",
      "quantity_ordered": 20,
      "quantity_received": 12,
      "unit_id": "unit_kg_01..."
    }
  ]
}
```
</ResponseExample>
