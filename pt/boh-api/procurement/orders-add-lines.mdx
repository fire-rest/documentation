---
title: "Adicionar linhas ao pedido de compra"
api: "POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/procurement/orders/{orderId}?action=add-lines"
description: "Adiciona linhas a um pedido de compra em status DRAFT. Retorna as linhas criadas com HTTP 201."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key do BOH com escopo `inventory:write`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>
<ParamField path="orderId" type="string" required>UUID do pedido de compra.</ParamField>

<ParamField body="lines" type="object[]" required>
  Linhas a adicionar (mínimo 1). Mesmos campos da criação do pedido: `item_id` / `external_item_id` / `supplier_sku`, `qty`, `qty_base`, `base_unit_id`, `item_unit_id`, `unit_code`, `unit_label`, `unit_cost`, `tax_amount`, `delivery_amount`, `total_amount`, `markup_amount`, `notes`, `metadata`. `qty_base` é opcional quando a linha referencia `unit_code` ou `item_unit_id` — o servidor o deriva a partir do `factor_to_base` da unidade.
</ParamField>

<ParamField body="enforce_supplier_catalog" type="boolean">
  Com `true`, cada item de linha deve existir no catálogo do fornecedor.
</ParamField>

<RequestExample>
```json
{
  "lines": [
    {
      "external_item_id": "cebola",
      "qty": 10,
      "unit_code": "kg",
      "unit_cost": 15.00
    }
  ]
}
```
</RequestExample>

<ResponseExample>
```json 200
{ "purchase_order": { "id": "po_01...", "status": "DRAFT" } }
```
</ResponseExample>
