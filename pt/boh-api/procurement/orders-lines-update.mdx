---
title: "Atualizar uma linha de PC"
api: "PATCH https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/procurement/orders/{orderId}/lines/{lineId}"
description: "Atualiza a quantidade ou o custo de uma linha do pedido de compra. Permitido apenas em pedidos DRAFT."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key do BOH com escopo `inventory:write`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>
<ParamField path="orderId" type="string" required>UUID do pedido de compra.</ParamField>
<ParamField path="lineId" type="string" required>UUID da linha.</ParamField>
<ParamField body="qty" type="number" required>Nova quantidade pedida na unidade de entrada.</ParamField>
<ParamField body="qty_base" type="number">Nova quantidade na unidade base. Opcional quando a linha referencia `unit_code` ou `item_unit_id` — o servidor a deriva como `qty × factor_to_base`.</ParamField>
<ParamField body="unit_cost" type="number">Novo custo unitário.</ParamField>
<ParamField body="unit_label" type="string">Novo rótulo de unidade.</ParamField>
<ParamField body="tax_amount" type="number">Novo valor de impostos.</ParamField>
<ParamField body="delivery_amount" type="number">Novo valor de entrega.</ParamField>
<ParamField body="total_amount" type="number">Novo valor total.</ParamField>
<ParamField body="markup_amount" type="number">Novo valor de markup.</ParamField>
<ParamField body="notes" type="string">Novas notas da linha.</ParamField>
<ParamField body="metadata" type="object">Novos dados adicionais.</ParamField>

<RequestExample>
```json
{
  "qty": 15,
  "qty_base": 15000,
  "unit_cost": 4.3
}
```
</RequestExample>

<ResponseExample>
```json 200
{
  "line": {
    "id": "pol_01...",
    "purchase_order_id": "po_01j5k...",
    "item_id": "itm_frango_01...",
    "qty": 15,
    "qty_base": 15000,
    "unit_cost": 4.3
  }
}
```
</ResponseExample>
