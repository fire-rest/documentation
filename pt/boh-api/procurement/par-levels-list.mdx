---
title: "Listar níveis de reposição"
api: "GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/procurement/par-levels"
description: "Retorna todos os níveis de reposição configurados para o vendor."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key do BOH com escopo `procurement:read`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>
<ParamField query="store_id" type="string">Filtrar por estabelecimento.</ParamField>
<ParamField query="supplier_id" type="string">Filtrar por fornecedor.</ParamField>

<ResponseField name="par_levels" type="object[]">Array de níveis de reposição.</ResponseField>

<ResponseExample>
```json 200
{
  "par_levels": [
    {
      "item_id": "itm_01...",
      "store_id": "str_principal_01...",
      "par_quantity": 20,
      "unit_id": "unit_kg_01...",
      "reorder_point": 5
    }
  ]
}
```
</ResponseExample>
