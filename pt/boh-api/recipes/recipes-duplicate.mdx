---
title: "Duplicar receita como rascunho"
api: "POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/recipes/{recipeId}/duplicate"
description: "Cria uma cópia da receita em estado DRAFT. Os ingredientes são copiados; o vínculo com o produto é limpo."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key do BOH com escopo `recipes:write`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>
<ParamField path="recipeId" type="string" required>UUID da receita a duplicar.</ParamField>
<ParamField body="name" type="string">Nome para a nova receita.</ParamField>
<ParamField body="external_user_id" type="string">Ator para auditoria.</ParamField>

<RequestExample>
```json
{ "name": "Molho de Tomate v2", "external_user_id": "chef_01" }
```
</RequestExample>

<ResponseExample>
```json 201
{ "id": "rec_02...", "name": "Molho de Tomate v2", "status": "DRAFT" }
```
</ResponseExample>
