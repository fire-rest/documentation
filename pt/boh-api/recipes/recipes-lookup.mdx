---
title: "Buscar receita publicada por produto"
api: "GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/recipes/lookup"
description: "Retorna a receita publicada vinculada a um produto do cardápio."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key do BOH com escopo `recipes:read`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>
<ParamField query="product_id" type="string">UUID do produto do cardápio.</ParamField>
<ParamField query="external_product_id" type="string">ID externo do produto.</ParamField>

<ResponseField name="recipe" type="object">Receita publicada com ingredientes completos, ou `null`.</ResponseField>

<ResponseExample>
```json 200
{
  "recipe": {
    "id": "rec_01...",
    "name": "Molho de Tomate",
    "status": "PUBLISHED",
    "yield_quantity": 1,
    "yield_unit_id": "unit_lt_01...",
    "ingredients": []
  }
}
```
</ResponseExample>
