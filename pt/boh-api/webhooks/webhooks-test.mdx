---
title: "Testar webhook"
api: "POST https://boh.api.fire.rest/api/v1/public/admin/webhooks/{webhookId}/test"
description: "Envia um evento de ping ao endpoint imediatamente. Útil para verificar a conectividade e sua lógica de verificação de assinatura."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key do BOH com escopo `admin:webhooks`.
</ParamField>

<ParamField path="webhookId" type="string" required>UUID do webhook.</ParamField>

<ResponseField name="delivery_id" type="string">UUID da entrega de teste criada.</ResponseField>

<RequestExample>
```http
POST /api/v1/public/admin/webhooks/wep_01j5k.../test
x-api-key: boh_live_xxxxxxxx
```
</RequestExample>

<ResponseExample>
```json 200
{ "delivery_id": "del_01j5k..." }
```
</ResponseExample>
