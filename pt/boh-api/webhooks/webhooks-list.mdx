---
title: "Listar webhooks"
api: "GET https://boh.api.fire.rest/api/v1/public/admin/webhooks"
description: "Retorna todos os endpoints webhook registrados para a conta."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key do BOH com escopo `admin:webhooks`.
</ParamField>

<ResponseField name="webhooks" type="object[]">Array de endpoints webhook.</ResponseField>

<ResponseExample>
```json 200
{
  "webhooks": [
    {
      "id": "wep_01j5k...",
      "url": "https://meu-sistema.com/webhooks/boh",
      "events": ["inventory_transaction.completed"],
      "status": "ACTIVE"
    }
  ]
}
```
</ResponseExample>
