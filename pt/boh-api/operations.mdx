---
title: "Operações"
description: "Registre e consulte movimentações de estoque: recebimentos, contagens, perdas, transferências e lotes de produção."
---

As **operações** são as transações de estoque que movimentam o estoque fisicamente: mercadorias chegando de um fornecedor, uma contagem física que reconcilia saldos, perdas descartadas, estoque transferido entre estabelecimentos e produções que convertem ingredientes em um produto acabado.

Todas as escritas são **assíncronas** (HTTP 202). Respondem imediatamente com um `tracking_id`; as movimentações de estoque são processadas em segundos. Consulte `GET /api/v1/public/operations/transactions/{trackingId}` para acompanhar o status.

**Scopes necessários:** `inventory:read` (leitura), `inventory:write` (escrita).

## Recebimentos de mercadoria

### Criar um recebimento de mercadoria

<api>POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/operations/goods-receipts</api>

Registra estoque chegando de um fornecedor. Cada linha pode vincular uma ordem de compra (opcional) e adiciona estoque.

<ParamField header="x-api-key" type="string" required>API key com scope `inventory:write`.</ParamField>
<ParamField path="vendorId" type="string" required>UUID do vendor.</ParamField>

<ParamField body="idempotency_key" type="string" required>Chave de idempotência (1–128 chars). Envios duplicados retornam a resposta original com `"idempotent": true`.</ParamField>
<ParamField body="external_user_id" type="string" required>Identificador do ator para trilha de auditoria.</ParamField>
<ParamField body="store_id" type="string">UUID do estabelecimento receptor. Exatamente um de `store_id` ou `external_store_id` deve ser fornecido.</ParamField>
<ParamField body="external_store_id" type="string">Identificador do estabelecimento no seu sistema.</ParamField>
<ParamField body="supplier_id" type="string">UUID do fornecedor no BOH.</ParamField>
<ParamField body="external_supplier_id" type="string">Identificador do fornecedor no seu sistema.</ParamField>
<ParamField body="reference" type="string">Número de nota fiscal ou guia de entrega (máx. 200 chars).</ParamField>
<ParamField body="purchase_order_id" type="string">UUID da ordem de compra que este recebimento cumpre (opcional).</ParamField>
<ParamField body="lines" type="object[]" required>
  Itens da linha (1–500 linhas):
  <Expandable title="campos da linha">
    <ParamField body="item_id" type="string">UUID do item no BOH. Exatamente um de `item_id` ou `external_item_id` é obrigatório.</ParamField>
    <ParamField body="external_item_id" type="string">Identificador do item no seu sistema.</ParamField>
    <ParamField body="purchase_order_line_id" type="string">UUID da linha da OC que está sendo cumprida.</ParamField>
    <ParamField body="qty" type="number" required>Quantidade recebida na unidade indicada.</ParamField>
    <ParamField body="qty_base" type="number" required>Quantidade convertida para a unidade base do item.</ParamField>
    <ParamField body="base_unit_id" type="string" required>UUID da unidade base.</ParamField>
    <ParamField body="unit_id" type="string">UUID da unidade usada para `qty`.</ParamField>
    <ParamField body="unit_label" type="string">Rótulo da unidade (para exibição).</ParamField>
    <ParamField body="unit_to_base_factor" type="number" required>Fator de conversão de `unit_id` para `base_unit_id`.</ParamField>
    <ParamField body="unit_cost" type="number" required>Custo por unidade (na moeda da conta, ≥ 0).</ParamField>
    <ParamField body="total_cost" type="number">Custo total pré-calculado. Padrão `qty × unit_cost`.</ParamField>
    <ParamField body="metadata" type="object">Dados extras livres.</ParamField>
  </Expandable>
</ParamField>

<ResponseField name="tracking_id" type="string">Use isso para consultar o status final de processamento.</ResponseField>
<ResponseField name="inventory_transaction_id" type="string">UUID da transação de estoque criada.</ResponseField>
<ResponseField name="goods_receipt_id" type="string">UUID do recebimento criado.</ResponseField>
<ResponseField name="idempotent" type="boolean">`true` se um envio anterior idêntico foi encontrado.</ResponseField>

<RequestExample>
```json
{
  "idempotency_key": "rcbt-2026-08-07-001",
  "external_user_id": "usuario_recebimento",
  "store_id": "str_principal_01...",
  "supplier_id": "sup_fornecedor_01...",
  "reference": "NF-2026-1234",
  "lines": [
    {
      "item_id": "itm_frango_01...",
      "qty": 10,
      "qty_base": 10000,
      "base_unit_id": "unit_g_01...",
      "unit_id": "unit_kg_01...",
      "unit_label": "kg",
      "unit_to_base_factor": 1000,
      "unit_cost": 4.5
    }
  ]
}
```
</RequestExample>

<ResponseExample>
```json 202
{
  "tracking_id": "trk_01j5k...",
  "inventory_transaction_id": "txn_01j5k...",
  "goods_receipt_id": "rcpt_01j5k...",
  "idempotent": false
}
```
</ResponseExample>

    <ParamField body="qty" type="number" required>Quantidade na unidade de exibição.</ParamField>

<api>GET https://boh.api.fire.rest/api/v1/public/operations/transactions/{trackingId}</api>
