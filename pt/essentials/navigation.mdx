O menu de navegação é a lista de links do site.

Você provavelmente atualizará o `docs.json` sempre que adicionar uma página. As páginas não aparecem automaticamente.

## Sintaxe de navegação

A sintaxe é recursiva: você pode criar grupos aninhados. Não é necessário incluir `.mdx` nos nomes.

<CodeGroup>

```json Navegação simples
"navigation": {
  "tabs": [
    {
      "tab": "Docs",
      "groups": [
        {
          "group": "Getting Started",
          "pages": ["quickstart"]
        }
      ]
    }
  ]
}
```

```json Navegação aninhada
"navigation": {
  "tabs": [
    {
      "tab": "Docs",
      "groups": [
        {
          "group": "Getting Started",
          "pages": [
            "quickstart",
            {
              "group": "Nested Reference Pages",
              "pages": ["nested-reference-page"]
            }
          ]
        }
      ]
    }
  ]
}
```

</CodeGroup>

## Pastas

Coloque seus arquivos MDX em pastas e atualize os caminhos no `docs.json`.

Por exemplo, para `https://yoursite.com/your-folder/your-page`, crie a pasta `your-folder` com o arquivo `your-page.mdx`.

<Warning>

Você não pode usar `api` como nome de pasta na raiz, a menos que esteja aninhada. O Mintlify usa Next.js, que reserva a pasta `api` de nível superior. Um nome como `api-reference` é aceito.

</Warning>

```json Navegação com pasta
"navigation": {
  "tabs": [
    {
      "tab": "Docs",
      "groups": [
        {
          "group": "Group Name",
          "pages": ["your-folder/your-page"]
        }
      ]
    }
  ]
}
```

## Páginas ocultas

Arquivos MDX não incluídos no `docs.json` não aparecem na barra lateral, mas ficam acessíveis pela busca e por link direto.
