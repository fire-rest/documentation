## Títulos

Para cabeçalhos de seção.

```md
## Títulos
```

### Subtítulos

Para subseções.

```md
### Subtítulos
```

<Tip>

Cada **título** e **subtítulo** cria uma âncora e aparece no sumário à direita.

</Tip>

## Formatação de texto

Suportamos a maior parte do Markdown: `**`, `_` ou `~` em volta do texto.

| Estilo        | Como escrever     | Resultado       |
| ------------- | ----------------- | --------------- |
| Negrito       | `**negrito**`    | **negrito**     |
| Itálico       | `_itálico_`       | _itálico_       |
| Riscado       | `~riscado~`       | ~riscado~       |

Você pode combinar. Por exemplo, `**_negrito e itálico_**` gera **_negrito e itálico_**.

Para sobrescrito e subscrito use HTML: `<sup>` ou `<sub>`.

| Tamanho     | Como escrever            | Resultado                 |
| ----------- | ------------------------ | ------------------------- |
| Sobrescrito | `<sup>sobre</sup>`       | <sup>sobre</sup>          |
| Subscrito   | `<sub>sub</sub>`         | <sub>sub</sub>            |

## Links para páginas

Adicione links com `[]()`. Por exemplo `[Google](https://google.com)`.

Links internos devem ser relativos à raiz do site, com o caminho completo da pasta: `[texto](/writing-content/text)`.

Links relativos como `[texto](../text)` podem carregar mais devagar.

## Citações em bloco

### Uma linha

Adicione `>` na frente do parágrafo.

> Dorothy seguiu a bruxa por muitos cômodos do castelo.

```md
> Dorothy seguiu a bruxa por muitos cômodos do castelo.
```

### Várias linhas

> Dorothy seguiu a bruxa por muitos cômodos do castelo.
>
> A Bruxa mandou ela limpar panelas e varrer o chão.

```md
> Dorothy seguiu a bruxa por muitos cômodos do castelo.
>
> A Bruxa mandou ela limpar panelas e varrer o chão.
```

### LaTeX

O Mintlify suporta [LaTeX](https://www.latex-project.org) com o componente Latex.

<Latex>8 x (vk x H1 - H2) = (0,1)</Latex>

```md
<Latex>8 x (vk x H1 - H2) = (0,1)</Latex>
```
