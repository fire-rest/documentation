## Código em linha

Para marcar uma `palavra` ou `frase` como código, use crases (\`).

```
Para marcar uma `palavra` ou `frase` como código, envolva com crases (`).
```

## Blocos de código

Use [blocos cercados](https://www.markdownguide.org/extended-syntax/#fenced-code-blocks) com três crases e a linguagem para destaque de sintaxe. Opcionalmente coloque um nome após a linguagem.

```java HelloWorld.java
class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```
