## Imagem

### Com Markdown

A [sintaxe Markdown](https://www.markdownguide.org/basic-syntax/#images) permite adicionar imagens assim:

```md
![título](/path/image.jpg)
```

O arquivo deve ter menos de 5 MB. Caso contrário, hospede em [Cloudinary](https://cloudinary.com/) ou [S3](https://aws.amazon.com/s3/) e use a URL.

### Com embeds

Para mais controle, use [embeds](https://mintlify.com/docs) para imagens.

```html
<img height="200" src="/path/image.jpg" />
```

### iFrames

Carrega outra página HTML no documento. Comum para incorporar vídeos.

```html
<iframe src="https://www.youtube.com/embed/4KzFe50RQkQ"> </iframe>
```
