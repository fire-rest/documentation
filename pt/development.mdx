<Info>
  **Pré-requisitos**:
  - Node.js versão 19 ou superior
  - Um repositório de documentação com um arquivo `docs.json`
</Info>

Siga estes passos para instalar e executar o Mintlify no seu sistema.

<Steps>
<Step title="Instalar a CLI do Mintlify">

```bash
npm i -g mint
```
</Step>

<Step title="Pré-visualizar localmente">

No diretório da documentação onde está o `docs.json`, execute:

```bash
mint dev
```

A pré-visualização ficará disponível em `http://localhost:3000`.

</Step>
</Steps>

## Portas personalizadas

Por padrão o Mintlify usa a porta 3000. Você pode alterar com a opção `--port`. Por exemplo, para a porta 3333:

```bash
mint dev --port 3333
```

Se a porta estiver em uso, a próxima disponível será usada:

```md
Port 3000 is already in use. Trying 3001 instead.
```

## Versões do Mintlify

Cada versão da CLI corresponde a uma versão específica do Mintlify. Se a pré-visualização não bater com produção, atualize a CLI:

```bash
npm mint update
```

## Validar links

Para identificar links quebrados:

```bash
mint broken-links
```

## Solução de problemas

<AccordionGroup>
  <Accordion title='Error: Could not load the "sharp" module using the darwin-arm64 runtime'>

    Pode ser uma versão antiga do Node. Tente:
    1. Remover a CLI: `npm remove -g mint`
    2. Atualizar para Node v19 ou superior.
    3. Reinstalar: `npm i -g mint`
  </Accordion>

  <Accordion title="Problema: erro desconhecido">
  
    Solução: na raiz do usuário, exclua a pasta `~/.mintlify` e execute `mint dev` novamente.
  </Accordion>
</AccordionGroup>

Quer ver o que mudou na CLI? Veja o [changelog no npm](https://www.npmjs.com/package/mintlify?activeTab=versions).
