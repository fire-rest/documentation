</Warning>

`menu.list_ready` é a metade de notificação da [entrega
híbrida](/pt/hybrid-delivery/overview): avisa seu sistema que um menu está pronto
para uma loja e canal específicos, sem levar nenhum dado de catálogo. Chame
[`GET /v1/menus/{listId}`](/pt/hybrid-delivery/get-menu) com o `listId` deste
evento para buscar o menu de fato.

## Payload

```json
{
  "event": {
    "id": "evt_ghi789",
    "type": "menu.list_ready",
    "executionId": "exec_def456",
    "createdAt": "2025-01-15T14:31:00.000Z"
  },
  "data": {
    "account": "1",
    "country": "EC",
    "groupId": "a3f7c2d1-84be-4e10-9b3a-2c5d6e7f8091",
    "listId": "805-iFood-delivery",
    "storeId": "b3d2a1f0-6e21-4c3a-9f5d-7a8b9c0d1e2f",
    "channelId": "0E049503-85CF-E511-80C6-000D3A3261F3"
  }
}
```

## Campos

### `data`

| Campo | Tipo | Descrição |
|---|---|---|
| `account` | string | Identificador da conta |
| `country` | string | Código do país ISO 3166-1 alpha-2 (ex.: `EC`, `BR`, `CO`) |
| `groupId` | string | UUID que correlaciona eventos do mesmo batch de publicação ou sincronização |
| `listId` | string | Identificador do menu. Passe-o para [`GET /v1/menus/{listId}`](/pt/hybrid-delivery/get-menu) para buscar o menu |
| `storeId` | string | UUID interno da loja (PK `stores.id`) — mesma convenção que `list.storeId` em [`menu.updated`](/pt/webhook-reference/menu-updated) |
| `channelId` | string | UUID interno do canal de vendas (PK `channels.id`) — mesma convenção que `list.channelId` em [`menu.updated`](/pt/webhook-reference/menu-updated) |

## Notas

- Este evento não leva dados de catálogo. Se você precisar de categorias, produtos
  ou grupos de modificadores, chame
  [`GET /v1/menus/{listId}`](/pt/hybrid-delivery/get-menu).
- `listId` é a chave de correlação entre este evento e o endpoint de busca — mesmo
  identificador usado nos demais eventos de menu (`list.listId` em `menu.updated`).
