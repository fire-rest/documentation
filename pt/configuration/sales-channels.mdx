Os canais de venda representam os agregadores de delivery (iFood, Keeta, 99, Rappi, etc.) configurados dentro do Fire para cada loja. Se sua integração publica cardápios para agregadores ou injeta pedidos, você precisa mapear os IDs de canal do Fire para os IDs do agregador correspondente.

## Obter canais

```http
GET /v1/sales-channels
Authorization: Bearer <your_api_key>
```

```json
      "type": "rappi",
      "store_id": "store_xyz"
    }
  ]
}
```

## Mapeamento de canais

Quando o Fire emite um evento de publicação, o payload inclui um array `channels` com os IDs de canal do Fire. Use seu mapeamento armazenado para resolver a qual agregador corresponde cada ID.

```json
{
  "event": "menu.updated",
  "data": {
    "channels": ["channel_abc123", "channel_def456"],
    ...
  }
}
```

Armazene o mapeamento na inicialização e atualize-o quando necessário.

## Quando re-obter

Re-obtenha a lista de canais:

- Na inicialização
- Quando encontrar um `channel_id` desconhecido em um evento webhook
- Em um intervalo programado (recomendado: a cada 24 horas)
