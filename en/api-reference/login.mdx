---
title: "Login"
api: "POST https://api.fire.rest/v1/auth/login"
description: "Exchange your credentials for an access token. Use the returned token as a Bearer token in all subsequent API requests."
---

<ParamField header="x-api-key" type="string" required>
  Your Fire API key. Issued from the Fire dashboard under **Settings → API Keys**.
</ParamField>

<ParamField body="username" type="string" required>
  Your Fire account username.
</ParamField>

<ParamField body="password" type="string" required>
  Your Fire account password.
</ParamField>

<ResponseField name="token" type="string">
  Access token. Include this in the `Authorization: Bearer <token>` header for all API requests.
</ResponseField>

<ResponseField name="expiresIn" type="number">
  Token lifetime in seconds.
</ResponseField>

<ResponseExample>
```json 200
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expiresIn": 3600
}
```

```json 401
{
  "error": {
    "code": "unauthorized",
    "message": "Invalid credentials"
  }
}
```
</ResponseExample>
