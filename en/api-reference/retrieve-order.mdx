---
title: "Retrieve an order"
api: "GET https://api.fire.rest/v1/orders/{orderId}"
description: "Returns a single order by its Fire ID. Useful to look up the current state of an order or replay the original payload."
authMethod: "bearer"
---

<ParamField header="x-api-key" type="string" required>
  Your Fire API key with the `orders:read` scope.
</ParamField>

<ParamField path="orderId" type="string" required>
  The order's Fire UUID — the `orderId` field from any `order.*` event payload, or returned from `POST /v1/orders`.
</ParamField>

### Response

Returns the full V4 Order Snapshot — same shape as the `data` block in the [`order.completed`](/en/webhook-reference/order-completed) event. If the order has been cancelled or has fiscal events, those blocks (`cancellation`, `fiscal`) are present as well, exactly mirroring the latest event Fire emitted for this order.

<RequestExample>

```bash curl
curl https://api.fire.rest/v1/orders/df8cdf6a-62c5-4daf-b35f-b6e7bb1b98b3 \
  -H "x-api-key: pk_live_a1b2c3..." \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..."
```

```js Node.js
const orderId = "df8cdf6a-62c5-4daf-b35f-b6e7bb1b98b3";
const res = await fetch(`https://api.fire.rest/v1/orders/${orderId}`, {
  headers: {
    "x-api-key":     process.env.FIRE_API_KEY,
    "Authorization": `Bearer ${accessToken}`,
  },
});
const order = await res.json();
```

```python Python
import os, requests

order_id = "df8cdf6a-62c5-4daf-b35f-b6e7bb1b98b3"
res = requests.get(
    f"https://api.fire.rest/v1/orders/{order_id}",
    headers={
        "x-api-key":     os.environ["FIRE_API_KEY"],
        "Authorization": f"Bearer {access_token}",
    },
)
res.raise_for_status()
order = res.json()
```
