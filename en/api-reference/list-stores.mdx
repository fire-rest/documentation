---
title: "List stores"
api: "GET https://app.fire.rest/api/v1/fire/external/stores"
description: "List the stores of the account and vendor bound to your API key, with pagination and filters."
authMethod: "bearer"
---

Returns the stores of the account + vendor bound to your API key. The response is a slim, stable
representation of each store — it excludes internal fields (raw settings, drafts, overrides).

## Authentication

<ParamField header="x-api-key" type="string" required>
  Your Fire API key with the `store:read` scope. The key **must be vendor-scoped** (account +
  vendor binding) — keys without a `vendorId` are rejected with `403`.
</ParamField>

## Query parameters

<ParamField query="accountId" type="string" required>
  Account identifier. **Must match** the account bound to your API key, or the request is rejected with `403`.
</ParamField>

<ParamField query="vendorId" type="string" required>
  Vendor identifier. **Must match** the vendor bound to your API key, or the request is rejected with `403`.
</ParamField>

<ParamField query="status" type="string">
  Filter by publication status: `DRAFT`, `PUBLISHED`, `PARTIALLY_PUBLISHED`, `ARCHIVED`.
</ParamField>

<ParamField query="active" type="string">
  Filter by operational state: `ACTIVE`, `INACTIVE`, `SUSPENDED`.
</ParamField>

<ParamField query="syncStatus" type="string">
  Filter by sync state: `SYNCED`, `PENDING`, `FAILED`.
</ParamField>

<ParamField query="countryId" type="string">Filter by country id.</ParamField>
<ParamField query="cityId" type="string">Filter by city id.</ParamField>
<ParamField query="channel" type="string">Filter by a published channel code (e.g. `APP`).</ParamField>
<ParamField query="query" type="string">Free-text search over name, store code and external id.</ParamField>

<ParamField query="page" type="integer" default="1">Page number (1-based).</ParamField>
<ParamField query="size" type="integer" default="20">Page size (1–500).</ParamField>

## Request

<RequestExample>
```http
GET https://app.fire.rest/api/v1/fire/external/stores?accountId=100&vendorId=100.1.10&page=1&size=20
x-api-key: <your_api_key>
```
</RequestExample>

    <ResponseField name="externalId" type="string | null">External identifier controlled by Fire.</ResponseField>
