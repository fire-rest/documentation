## Price object

The following fields appear in price objects throughout the payload (`unitPrice`, `totalPrice`):

| Field | Type | Description |
|---|---|---|
| `currencyCode` | string | ISO 4217 currency code (e.g. `USD`) |
| `totalBeforeSale` | string | Price before any sale pricing |
| `subtotalWithoutTaxes` | string | Subtotal excluding taxes |
| `discountPercentage` | string | Discount percentage applied |
| `discountsValue` | string | Discount amount |
| `subtotalIncludeDiscounts` | string | Subtotal after discounts, before taxes |
| `taxesPercentage` | string | Tax percentage |
| `taxValue` | string | Tax amount |
| `total` | string | Final total |
| `suggestedPrice` | string | Original suggested price |
