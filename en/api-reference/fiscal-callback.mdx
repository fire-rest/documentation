---
title: "Report fiscal event"
api: "POST https://api.fire.rest/v1/webhooks/fiscal/callback"
description: "Report the result of your local fiscal integration back to Fire (CO, EC, CL, AR, VE)."
authMethod: "bearer"
---

Single multi-country endpoint to report fiscal events. See the [Fiscal callback guide](/en/configuration/fiscal-callback) for the full conceptual context, when to call it, and per-country examples.

### Headers

<ParamField header="x-api-key" type="string" required>
  Your Fire API key with the `webhooks:fiscal` scope.
</ParamField>

### Body

<ParamField body="countryCode" type="string" required>
  ISO country code. One of `CO`, `EC`, `CL`, `AR`, `VE`. Drives the validation of `document`.
</ParamField>

<ParamField body="eventType" type="string" required>
  One of `authorized`, `cancelled`, `rejected`, `denied`, `error`.
</ParamField>

<ParamField body="providerEventId" type="string" required>
  Idempotency key. Fire indexes `(provider_code, providerEventId)` UNIQUE.
</ParamField>

<ParamField body="occurredAt" type="string" required>
  ISO 8601 UTC timestamp when the event happened in your system.
</ParamField>

<ParamField body="orderId" type="string" required>
  Fire order UUID — `data.orderId` from the order envelope Fire emitted.
</ParamField>

<ParamField body="eventId" type="string" required>
  The `event.id` Fire sent you in the original envelope. Correlates the callback with the specific run.
</ParamField>

<ParamField body="document" type="object">
  Country-specific fiscal data. Required when `eventType` is `authorized` or `cancelled`.

### Response

<ResponseField name="received" type="boolean">
  Always `true` on `2xx`.
</ResponseField>

<ResponseField name="receiptId" type="string">
  Fire-side identifier of this callback delivery.
</ResponseField>

<ResponseField name="outcome" type="string">
  One of `created`, `updated`, `idempotent`, `regression`, `duplicate`.
</ResponseField>

<ResponseField name="documentId" type="string">
  Fire's internal id of the persisted fiscal document.
</ResponseField>

<ResponseField name="processingMs" type="number">
  Server-side processing time in milliseconds.
</ResponseField>
