title: "Fire Agent"

Fire Agent is a small Windows application that runs in the background and lets the browser print to local **thermal POS printers**. The POS (and other Fire web apps) talk to it over a local WebSocket, so receipts, vouchers and reports reach the printer connected to the machine.

Install it once per Windows device that has a printer attached. After installation it starts automatically with Windows and stays in the system tray.

## Prerequisites

- **Windows 10 or 11 (64-bit).** No Node.js or extra runtime is required.
- **Administrator rights** on the machine to run the installer.
- The thermal printer installed in Windows with its driver, so it appears under **Settings → Bluetooth & devices → Printers & scanners**.

<Note>
  Fire Agent only listens on the same machine (`127.0.0.1`, loopback). It is never reachable from the network, and no firewall rule is needed.
</Note>

## 1. Get the installer

Download `fireAgentSetup.exe` and save it to any folder on the device.

The installer already carries the connection token for your operation, so you do not need to configure anything by hand.

## 2. Run the installer

1. Right-click `fireAgentSetup.exe` and choose **Run as administrator**.
2. On the welcome page, click **Next**.
3. Confirm the installation folder (`C:\Program Files\FireAgent` by default) and click **Next**.
4. The installer copies the program, registers it to start with Windows and adds it to **Add or Remove Programs**.
5. On the last page, leave **Start Fire Agent now** ticked and click **Finish**.

On its first launch Fire Agent prepares its own secure certificate so encrypted pages can reach it without warnings. This happens automatically — no extra prompts.

<Check>
  Fire Agent is installed and runs in the background. It restarts automatically every time Windows boots.
</Check>

## 3. Verify it is running

Fire Agent adds an icon to the **system tray** (near the clock). Click it to open the status panel, which shows:

- The installed version and whether the agent is active.
- The thermal printers detected on the machine.
- The auto-update status.
- The local connection URLs the POS uses.

<Frame>
  <img src="/images/manuals/pos/coming-soon.svg" alt="Fire Agent tray panel showing status and detected printers" />
</Frame>

If a printer is plugged in and installed in Windows but does not appear here, reinstall its driver from Windows settings and reopen the panel.

## Ports and firewall

Fire Agent listens only on the local machine:

| Port | Address | Use |
|------|---------|-----|
| `9100` | `127.0.0.1` | Standard local connection |
| `9101` | `127.0.0.1` | Encrypted local connection |

Because both ports are bound to loopback, the agent cannot be reached from other computers and **Windows Firewall does not need any rule**.

## Updates

When auto-update is enabled for your operation, Fire Agent checks for a newer version on each start and updates itself silently. You can confirm the current version from the tray panel.

## Uninstall

You can remove Fire Agent in either of these ways:

- **Add or Remove Programs:** open **Settings → Apps**, find **Fire Agent** and choose **Uninstall**.
- **Standalone uninstaller:** right-click `fireAgentUninstall.exe` → **Run as administrator** and confirm.

Both methods stop the agent, remove the auto-start entry and the connection token, delete the security certificate it created, and remove its files.

## Troubleshooting

| Symptom | Likely cause | What to do |
|---------|--------------|------------|
| The POS cannot reach the agent | Fire Agent is not running | Open it from the Start menu or restart the PC; the agent starts with Windows |
| A printer is missing from the list | The driver is not installed in Windows | Install the printer driver from Windows settings, then reopen the tray panel |
| An encrypted page cannot connect | The browser does not trust the local certificate | Reinstall Fire Agent, or import `%APPDATA%\FireAgent\ssl\cert.cer` into **Trusted Root Certification Authorities** |
| Connection rejected after a token change | The device token no longer matches | Reinstall with the correct installer provided by your Fire contact |

If the problem persists, share the agent version (from the tray panel) and a description of the printer with your Fire contact.
