When something fails, the kiosk shows a short message for the customer, a reference and a **View details** button with the technical text. Below it there is a line with the app version, the store, the kiosk and the time of the error, plus the order if it was already sent: a single screenshot is enough to find the case in the logs.

```text
              Este produto não está disponível
   Não conseguimos carregar este produto. Tente novamente em alguns minutos.

            Ref.: T153 · T102 · 500        Ver detalhes ▾

        P 1.2.12-fire · K066 · 98051774 · 05/10 15:58:56
```

## How to read the code

The letter tells who owns the error, that is, who to contact. When two owners share an initial, the prefix has two letters.

| Prefix | Owner | Who to contact |
|---|---|---|
| **T** | TRD | TRD team (kiosk, Fire, Firebase, PayBridge, Masivo) |
| **K** | KFC | KFC: Maxpoint and the store infrastructure |
| **B** | CliSiTef | Software Express / Fiserv (SiTef Brazil) |
| **D** | DeUna | DeUna |
| **DF** | Datafast | Datafast (Ecuador pinpad) |
| **M** | Medianet | Medianet (Ecuador pinpad) |
| **R** | Redeban | Redeban (Colombia card terminal) |
| **PC** | Pinpad Colombia | Colombia pinpad provider |
| **TB** | Transbank | Transbank (Chile) |
| **H** | Hasar | Hasar (Chile) |
| **PN** | POSNET | POSNET (Argentina) |
| **S** | Sitef | Sitef Venezuela (mobile payment) |
| **I** | Impresora | Store staff: check the printer |

For TRD, the number also tells which part of the flow failed:

| Range | Part of the flow |
|---|---|
| T001–T049 | Linking and Firebase |
| T050–T099 | Device and configuration |
| T100–T149 | Connection |
| T150–T199 | Menu and products |
| T200–T249 | Cart, coupons and loyalty |
| T250–T299 | Payments |
| T300–T349 | Order |
| T350–T399 | Cancellations |
| T900–T999 | Logs only |

## How to read the reference and the technical line

- **First code:** the service error, for example `T153` (the product could not be loaded).
- **Second code:** what happened with the connection, for example `T102` (the server answered with an error).
- **Last number:** the HTTP status returned by the server, for example `500`.
- **In CliSiTef:** the library return code and the fiscal coupon, for example `Ref.: B006 rc=-5 · cp=1790342446698`.
- **Technical line:** app version · store · kiosk (8 characters of the deviceId, same as in the logs) · kiosk date and time · order.
