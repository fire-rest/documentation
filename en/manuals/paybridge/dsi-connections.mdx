---
title: "DSI connections"
description: "How to configure and test the DSI connection per country in PayBridge (Super Admin)."
---

The **DSI** connection is **global per country**: it defines the base URL and credentials PayBridge uses to process payments routed to DSI in that country. This is a **Super Admin** task.

## Prerequisites

- Backoffice access at **[app.fire.rest](https://app.fire.rest)**, with the **Super Admin** role.
- The credentials DSI provided for each country: **base URL**, **client ID**, **client secret**, and, if applicable, the **webhook HMAC secret**.

## 1. Open DSI connections

In the Super Admin sidebar, open **PayBridge → DSI connections**. You'll see one row per country with its status and the result of the last test.

<Frame>
  <img src="/images/manuals/paybridge/dsi-connections/01-connections-list.png" alt="DSI connections list by country" />
</Frame>

## 2. Configure a country's connection

In the country's row, click **Configure** (or **Edit** if it already has a connection). The country's **DSI connection** modal opens. Fill in:

- **Base URL** — the Paybridge DSI base URL for that country. The methods' endpoints are resolved against this URL.
- **Client ID** — the client identifier provided by DSI. It's shown masked; use the eye icon to reveal it.
- **Client secret** — the client secret. It's shown masked; leave it empty to keep the current one.
- **Webhook HMAC secret** — DSI signs the
  [payment status notifications](/en/webhook-reference/dsi-payment-status) with this secret, and Fire
  validates the `X-Hmac-Signature` header. The form leaves it optional, but **without a secret Fire
  accepts the notifications without validating the signature**: load it before going to production.
- **Connection enabled** — the switch that enables or disables the connection.

<Frame>
  <img src="/images/manuals/paybridge/dsi-connections/02-connection-form.png" alt="DSI connection modal with masked secret fields" />
</Frame>

<Note>
When **editing**, leaving a secret field empty **keeps** the stored value. It's only overwritten if you type a new one.
</Note>

## 3. Save

Click **Save connection**. The connection is stored for that country and used at runtime to resolve the method's endpoints against its base URL.

<Frame>
  <img src="/images/manuals/paybridge/dsi-connections/03-save-button.png" alt="Save connection button" />
</Frame>

## 4. Test the connection

In the country's row, click **Test**. PayBridge requests a real token from DSI and stores the result (success or failure), which you'll see in the **Last test** column of the list.

<Frame>
  <img src="/images/manuals/paybridge/dsi-connections/04-test-button.png" alt="Test button for a DSI connection" />
</Frame>

<Warning>
If the test fails, check the base URL and the credentials. A failure here prevents processing DSI payments in that country.
</Warning>
