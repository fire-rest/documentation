---
title: "Supported payment methods by country"
description: "The payment methods PayBridge considers in each country (current roster, taken from the kiosks)."
---

These are the payment methods **PayBridge considers per country** today — the current roster already
operating in the kiosks. Which method shows up in each store and channel is decided later in
[Method availability](/en/manuals/paybridge/availability); this page is just the reference of what's
available where.

<Info>
Reference list, evolving. Some methods depend on confirmation with the provider or on the store's
hardware; it will be adjusted as they're finalized.
</Info>

## 🇪🇨 Ecuador

| Method | Type |
|---|---|
| Deuna / Banco Pichincha | Gateway (wallet, card, transfer) |
| Datafast | Card (pinpad) |
| Medianet | Card (pinpad) |

## 🇨🇱 Chile

| Method | Type |
|---|---|
| Mach | Wallet |
| Rutpay | Transfer |
| Amipass | Vouchers / benefits |
| Pluxee | Vouchers / benefits |
| Edenred | Vouchers / benefits |
| Transbank (VX805) | Card (pinpad) |

## 🇨🇴 Colombia

| Method | Type |
|---|---|
| Redeban | Card |
| ICT220 (Ingenico) | Card (pinpad) |
| Lane 3000 (CrediBanco) | Card (pinpad) |

## 🇦🇷 Argentina

| Method | Type |
|---|---|
| MercadoPago QR | QR / wallet |
| Posnet / Prisma | Card (pinpad) |

## 🇻🇪 Venezuela

| Method | Type |
|---|---|
| Pago Móvil / C2P | Transfer |
| Cashea | BNPL (buy now, pay later) |
| SiTef | Card (pinpad) |

## 🇧🇷 Brazil

| Method | Type |
|---|---|
| CliSiTef | Card (pinpad) |

<Note>
Other methods already available through the provider but not yet in use: **Daviplata** and **Nequi**
(wallets, Colombia), **Zelle** (transfer, Venezuela), and internal credits. They're enabled when the
business needs them.
</Note>
