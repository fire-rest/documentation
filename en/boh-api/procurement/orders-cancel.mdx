---
title: "Cancel purchase order"
api: "DELETE https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/procurement/orders/{orderId}"
description: "Cancels the purchase order. Returns HTTP 204. POST ...?action=cancel is equivalent."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key with `inventory:write` scope.
</ParamField>

<ParamField path="vendorId" type="string" required>
  Vendor UUID.
</ParamField>

<ParamField path="orderId" type="string" required>
  Purchase order UUID. Can be cancelled at any pre-received point (DRAFT, SUBMITTED, or CONFIRMED).
</ParamField>

<ResponseExample>
```json 204
```

```json 422
{
  "error": {
    "kind": "purchase_order_cannot_cancel",
    "message": "Purchase order cannot be cancelled in its current status"
  }
}
```
</ResponseExample>
