---
title: "Delete webhook"
api: "DELETE https://boh.api.fire.rest/api/v1/public/admin/webhooks/{webhookId}"
description: "Permanently removes the webhook endpoint. No more events will be delivered to that URL."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  BOH API key with `admin:webhooks` scope.
</ParamField>

<ParamField path="webhookId" type="string" required>
  Webhook endpoint UUID.
</ParamField>

<ResponseExample>
```json 204
```

```json 404
{
  "error": {
    "kind": "webhook_not_found",
    "message": "Webhook endpoint not found"
  }
}
```
</ResponseExample>
