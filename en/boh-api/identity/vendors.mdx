---
title: "List vendors"
api: "GET https://boh.api.fire.rest/api/v1/public/identity/vendors"
description: "Returns all vendors for your account. Use this to discover vendor IDs required for all other API calls."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  BOH API key with `catalog:read` scope.
</ParamField>

<ResponseField name="vendors" type="object[]">
  Array of vendor objects: `id`, `account_id`, `external_vendor_id`, `name`, `status`, `metadata`, `created_at`, `updated_at`.
</ResponseField>
