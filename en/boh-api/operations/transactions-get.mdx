---
title: "Get transaction status"
api: "GET https://boh.api.fire.rest/api/v1/public/operations/transactions/{trackingId}"
description: "Polls the processing status of any asynchronous write operation. Use the tracking_id returned by the create endpoint."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key with `inventory:read` scope.
</ParamField>

<ParamField path="trackingId" type="string" required>
  The `tracking_id` returned by a create operation (goods receipt, stock count, waste event, transfer, or production batch).
</ParamField>

<ResponseField name="status" type="string">
  `PENDING`, `PROCESSING`, `COMPLETED`, or `FAILED`.
</ResponseField>

<ResponseField name="error" type="object">
  Present only when `status` is `FAILED`. Contains `kind` and `message`.
</ResponseField>

<ResponseExample>
```json 200 (COMPLETED)
{
  "status": "COMPLETED"
}
```

```json 200 (FAILED)
{
  "status": "FAILED",
  "error": {
    "kind": "insufficient_stock",
    "message": "Insufficient stock for item itm_chicken_01..."
  }
}
```

```json 200 (PENDING)
{
  "status": "PENDING"
}
```
</ResponseExample>
