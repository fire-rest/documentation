---
title: "fiscal.cancelled.br"
description: "Brazil only. Sent when SEFAZ confirms cancellation of a previously authorized NFC-e or NF-e. Carries both the original document context and the SEFAZ cancellation result."
---

Fire fires `fiscal.cancelled.br` only for **Brazilian** stores, after SEFAZ confirms cancellation of a fiscal document that had been authorized. The payload mirrors the [`order.completed`](/en/webhook-reference/order-completed) snapshot **plus** a `cancellation` block whose `metadata.fiscal` carries the original authorized document **and** the SEFAZ cancellation result under `sefazCancellation`.

<Note>
  This event is **Brazil-only**. The top-level `fiscal` block from `fiscal.authorized.br` is **dropped**; everything fiscal lives inside `cancellation.metadata.fiscal` for cancellation events.
</Note>

## When it fires

| Trigger | Fires `fiscal.cancelled.br`? |
|---|---|
| SEFAZ confirms cancellation of an authorized document | ✅ Yes |
| SEFAZ rejects the cancellation request (e.g. outside the cancellation window) | ❌ No |
| Order is cancelled but no fiscal document was ever authorized | ❌ No (`order.cancelled` fires alone) |

## Envelope

```json
{
  "event": {
    "id":        "evt_c4d5e6f7890abcdef1234567890abcdef",
    "type":      "fiscal.cancelled.br",
    "createdAt": "2025-01-15T14:50:00.000Z"
  },
  "data": {
    /* V4 Order Snapshot (no top-level fiscal) + cancellation block */
  }
}
```

## Data fields

The `data` block is the **V4 Order Snapshot** (same shape documented in [`order.completed`](/en/webhook-reference/order-completed#data-fields)) without the top-level `fiscal` block, plus the `cancellation` block below.

### `cancellation`

<Expandable title="cancellation properties">

| Field | Type | Description |
|---|---|---|
| `cancellationId` | string | Fire's internal ID for this cancellation. |
| `cancelledAt` | string | ISO 8601 UTC — when the cancellation was recorded in Fire. |
| `cancelledBy` | string | Who triggered the cancellation. |
| `cancellationReason` | string | Free-form reason. For BR fiscal cancellations the reason must be ≥ 15 characters per SEFAZ rules. |
| `cancellationSource` | string | Origin: `BACKOFFICE`, `POS`, `API`. |
| `metadata.fiscal` | object | BR-only block carrying the original authorized document context and the SEFAZ cancellation result. |

**`cancellation.metadata.fiscal`** — Original authorized document context.

| Field | Type | Description |
|---|---|---|
| `docSubtype` | string | `nfce` or `nfe`. |
| `chaveAcesso` | string | 44-digit SEFAZ access key of the original authorized document. |
| `numero` | string | Document number. |
| `serie` | string \| null | Document series. |
| `protocolo` | string \| null | **Authorization** protocol of the original document. |
| `dataAutorizacao` | string \| null | ISO 8601 UTC — when the original document was authorized. |
| `xmlUrl` | string \| null | URL to the original authorization XML. |
| `pdfUrl` | string \| null | URL to the original DANFE PDF. |
| `providerDocId` | string | PlugNotas integration ID. |
| `sefazCancellation` | object | SEFAZ confirmation of the cancellation — see below. |

**`cancellation.metadata.fiscal.sefazCancellation`**

| Field | Type | Description |
|---|---|---|
| `protocolo` | string \| null | Cancellation protocol from SEFAZ. Different from the authorization protocol. |
| `date` | string \| null | ISO 8601 UTC — when SEFAZ confirmed the cancellation. |
| `xmlUrl` | string \| null | URL to download the cancellation XML. |
| `justificativa` | string \| null | Justification text sent to SEFAZ. Must be ≥ 15 characters. |
| `cStat` | string \| number \| null | SEFAZ status code. `135` is the standard success code for cancellation. |

</Expandable>

## Common consumer patterns

```js
async function handle(payload) {
  if (payload.event.type !== "fiscal.cancelled.br") return;

  const { orderId, cancellation } = payload.data;
  const fiscal = cancellation.metadata.fiscal;

  await db.fiscalDocuments.update({
    orderId,
    chaveAcesso: fiscal.chaveAcesso,
  }, {
    status:               "CANCELLED",
    cancellationProtocol: fiscal.sefazCancellation.protocolo,
    cancellationXmlUrl:   fiscal.sefazCancellation.xmlUrl,
    cancelledAt:          fiscal.sefazCancellation.date,
  });

  // Archive the cancellation XML for compliance retention
  await archiveXml(fiscal.sefazCancellation.xmlUrl, {
    orderId,
    chaveAcesso: fiscal.chaveAcesso,
    type:        "cancellation",
  });
}
```
