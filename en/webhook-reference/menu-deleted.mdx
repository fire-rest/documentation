---
title: "menu.deleted"
description: "Fired when a menu (list) is removed from Fire."
---

## Payload

```json
{
  "event": {
    "id": "evt_def457",
    "type": "menu.deleted",
    "createdAt": "2025-01-15T15:10:00Z",
    "timezone": "America/Guayaquil"
  },
  "data": {
    "listId": "pickup-menu-t005",
    "vendorId": "16",
    "storeId": "805",
    "channelId": "0E049503-85CF-E511-80C6-000D3A3261F3"
  }
}
```

## Fields

### `data`

| Field | Type | Description |
|---|---|---|
| `listId` | string | Identifier of the deleted menu |
| `vendorId` | string | Brand identifier |
| `storeId` | string | Store the menu belonged to |
| `channelId` | string | Channel UUID the menu was assigned to |

## Usage

When your system receives this event, remove or deactivate the menu in your downstream systems for the identified store and channel.

Unlike [`menu.updated`](/en/webhook-reference/menu-updated), this event is explicit — there is no ambiguity about whether the menu should still exist downstream.
