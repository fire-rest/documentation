Fire fires `fiscal.authorized.br` only for **Brazilian** stores, after SEFAZ confirms authorization of the fiscal document Fire emitted via PlugNotas. The payload mirrors the [`order.completed`](/en/webhook-reference/order-completed) snapshot **plus** a top-level `fiscal` block with the SEFAZ data.

<Note>
  This event is **Brazil-only**. For CO, EC, CL, AR, VE the fiscal step happens in your system — see the [Fiscal callback](/en/configuration/fiscal-callback) for how to report your local fiscal authorization back to Fire.
</Note>

## When it fires

The event fires once SEFAZ has authorized the document. SEFAZ authorization is **asynchronous** — there's typically a short delay between `order.completed` and `fiscal.authorized.br` (a few seconds in the happy path, longer if SEFAZ is degraded).

| Trigger | Fires `fiscal.authorized.br`? |
|---|---|
| SEFAZ authorizes a `nfce` document | ✅ Yes |
| SEFAZ authorizes a `nfe` document | ✅ Yes |
| SEFAZ rejects the document | ❌ No |
| SEFAZ is in contingency mode | ❌ No (fires once SEFAZ recovers and authorizes) |
| Same document is re-emitted after a rejection and gets authorized | ✅ Yes |

## Envelope

```json
{
  "event": {
    "id":        "evt_a8b9c1d2e3f4567890abcdef12345678",
    "type":      "fiscal.authorized.br",
    "createdAt": "2025-01-15T14:30:05.000Z"
  },
  "data": {
    /* V4 Order Snapshot + fiscal block */
  }
}
```

## Data fields

The `data` block is the **V4 Order Snapshot** (same shape documented in [`order.completed`](/en/webhook-reference/order-completed#data-fields)) plus the `fiscal` block below.

### `fiscal`

<Expandable title="fiscal properties">

| Field | Type | Description |
|---|---|---|
| `status` | string | Always `authorized` for this event. |
| `docSubtype` | string | `nfce` (Nota Fiscal de Consumidor Eletrônica) or `nfe` (Nota Fiscal Eletrônica). |
| `chaveAcesso` | string | 44-digit SEFAZ access key. Globally unique per document — use it to look up the document in SEFAZ portals. |
| `numero` | string | Sequential document number assigned by the issuing series, e.g. `1000013`. |
| `serie` | string \| null | Document series. May be `null` for documents authorized before the series field was persisted. |
| `protocolo` | string | SEFAZ authorization protocol number. Stamped on the DANFE. |
| `dataAutorizacao` | string | ISO 8601 UTC timestamp when SEFAZ authorized the document. |
| `xmlUrl` | string | Public URL to download the authorization XML. Hosted by PlugNotas. |
| `pdfUrl` | string | Public URL to download the DANFE PDF. Hosted by PlugNotas. |
| `providerDocId` | string | PlugNotas integration ID. Use it when correlating with PlugNotas dashboards or APIs. |
| `cStat` | string \| number \| null | SEFAZ status code. `100` is the standard success code. |

</Expandable>

## Common consumer patterns

```js
async function handle(payload) {
  if (payload.event.type !== "fiscal.authorized.br") return;

  const { orderId, fiscal } = payload.data;

  // Persist the document URLs against the order
  await db.fiscalDocuments.upsert({
    orderId,
    docSubtype:    fiscal.docSubtype,
    chaveAcesso:   fiscal.chaveAcesso,
    protocolo:     fiscal.protocolo,
    pdfUrl:        fiscal.pdfUrl,
    xmlUrl:        fiscal.xmlUrl,
    authorizedAt:  fiscal.dataAutorizacao,
  });

  // Optionally archive the XML for compliance retention
  await archiveXml(fiscal.xmlUrl, { orderId, chaveAcesso: fiscal.chaveAcesso });
}
```
