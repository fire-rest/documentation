Configura Claude Code para redactar y mantener tu documentación Mintlify.

## Requisitos

- Suscripción activa a Claude (Pro, Max o acceso API)

## Configuración

<Steps>
<Step title="Instala Claude Code">
  ```bash
  npm install -g @anthropic-ai/claude-code
  ```
</Step>

<Step title="Instala la skill de Mintlify">
  En el directorio de documentación, ejecuta:

  ```bash
  npx skills add https://mintlify.com/docs
  ```

  Así tendrás la referencia de componentes, estándares de redacción
  y guías de flujo de Mintlify.
</Step>

<Step title="Personaliza las instrucciones del proyecto">
  Edita `AGENTS.md` en la raíz para añadir terminología,
  estilo y límites del contenido.
</Step>

<Step title="Empieza a escribir con Claude Code">
  ```bash
  claude
  ```
</Step>
</Steps>
