Configura Cursor para redactar y mantener tu documentación Mintlify.

## Requisitos

- Editor Cursor instalado

## Configuración

<Steps>
<Step title="Abre el directorio de documentación en Cursor">
  Abre la raíz del repositorio donde está `docs.json`.
</Step>

<Step title="Instala la skill de Mintlify">
  En la terminal integrada, ejecuta:

  ```bash
  npx skills add https://mintlify.com/docs
  ```

  Así tendrás la referencia de componentes, estándares de redacción
  y guías de flujo de Mintlify.
</Step>

<Step title="Personaliza las instrucciones del proyecto">
  Edita `AGENTS.md` en la raíz para añadir terminología,
  estilo y límites del contenido.
</Step>

<Step title="Empieza a escribir con Cursor">
  Abre un archivo y usa las funciones de IA para redactar y editar la documentación.
</Step>
</Steps>
