---
title: "Listar órdenes"
api: "GET https://api.fire.rest/v1/orders"
description: "Devuelve una lista paginada de órdenes inyectadas en Fire. Filtrable por tienda, canal, estado y rango de fechas."
authMethod: "bearer"
---

<ParamField header="x-api-key" type="string" required>
  Tu API key de Fire con scope `orders:read`.
</ParamField>

<ParamField query="store_id" type="string">
  Filtrar por tienda. Si se omite, devuelve órdenes de todas las tiendas que la API key puede ver.
</ParamField>

<ParamField query="channel_id" type="string">
  Filtrar por canal de venta.
</ParamField>

<ParamField query="status" type="string">
  Filtrar por estado: `OPEN`, `COMPLETED`, `CANCELLED`, `FORCE_CLOSED`.
</ParamField>

<ParamField query="payment_status" type="string">
  Filtrar por estado de pago: `PENDING`, `SUCCEEDED`, `FAILED`.
</ParamField>

<ParamField query="business_day_from" type="string">
  Cota inferior (inclusiva) de `businessDayDate`, formato `YYYY-MM-DD`.
</ParamField>

<ParamField query="business_day_to" type="string">
  Cota superior (inclusiva) de `businessDayDate`.
</ParamField>

<ParamField query="created_from" type="string">
  Cota inferior (inclusiva) de `createdAt`, ISO 8601 UTC.
</ParamField>

<ParamField query="created_to" type="string">
  Cota superior (inclusiva) de `createdAt`.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Tamaño de página. Máx `200`.
</ParamField>

<ParamField query="starting_after" type="string">
  Cursor retornado en `next_cursor` de la respuesta anterior. Omitir para la primera página.
</ParamField>

### Respuesta

<ResponseField name="data" type="object[]">
  Array de órdenes, las más nuevas primero. Cada item lleva el V4 Order Snapshot completo — misma forma que el bloque `data` en el evento [`order.completed`](/es/webhook-reference/order-completed).
</ResponseField>

<ResponseField name="has_more" type="boolean">
  `true` si hay más órdenes que coinciden con los filtros más allá de esta página.
</ResponseField>

<ResponseField name="next_cursor" type="string | null">
  Pasa este valor como `starting_after` en el siguiente request. `null` cuando `has_more` es `false`.
</ResponseField>
