---
title: "Reportar evento fiscal"
api: "POST https://api.fire.rest/v1/webhooks/fiscal/callback"
description: "Reporta el resultado de tu integración fiscal local a Fire (CO, EC, CL, AR, VE)."
authMethod: "bearer"
---

Endpoint único multipaís para reportar eventos fiscales. Para el contexto conceptual, cuándo llamarlo y ejemplos por país ver la [guía de callback fiscal](/es/configuration/fiscal-callback).

### Headers

<ParamField header="x-api-key" type="string" required>
  API key de Fire con el scope `webhooks:fiscal`.
</ParamField>

### Body

<ParamField body="countryCode" type="string" required>
  Código ISO de país. Uno de `CO`, `EC`, `CL`, `AR`, `VE`. Determina la validación de `document`.
</ParamField>

<ParamField body="eventType" type="string" required>
  Uno de `authorized`, `cancelled`, `rejected`, `denied`, `error`.
</ParamField>

<ParamField body="providerEventId" type="string" required>
  Llave de idempotencia. Fire indexa `(provider_code, providerEventId)` UNIQUE.
</ParamField>

<ParamField body="occurredAt" type="string" required>
  Timestamp ISO 8601 UTC en que ocurrió el evento en tu sistema.
</ParamField>

<ParamField body="orderId" type="string" required>
  UUID de la orden en Fire — `data.orderId` del envelope que Fire emitió.
</ParamField>

<ParamField body="eventId" type="string" required>
  El `event.id` que Fire te envió en el envelope original. Correlaciona el callback con la ejecución específica.
</ParamField>

<ParamField body="document" type="object">
  Datos fiscales por país. Requerido cuando `eventType` es `authorized` o `cancelled`.

  <Expandable title="propiedades">
    <ParamField body="docType" type="string" required>
      `invoice` o `cancellation`.
    </ParamField>
    <ParamField body="docSubtype" type="string" required>
      Subtipo del país (`factura`, `boleta`, etc.).
    </ParamField>
    <ParamField body="totalAmount" type="number" required>
      Monto total con impuestos.
    </ParamField>
    <ParamField body="taxAmount" type="number">
      Porción de impuestos del total.
    </ParamField>
    <ParamField body="currencyCode" type="string" required>
      ISO 4217 (`COP`, `USD`, `CLP`, `ARS`, `VES`).
    </ParamField>
    <ParamField body="pdfUrl" type="string">
      URL donde está hosteado el PDF del documento legal.
    </ParamField>
    <ParamField body="xmlUrl" type="string">
      URL donde está hosteado el XML del documento legal.
    </ParamField>
    <ParamField body="emittedAt" type="string">
      ISO 8601 UTC.
    </ParamField>
    <ParamField body="cancelledAt" type="string">
      ISO 8601 UTC. Requerido cuando `eventType=cancelled`.

    <ParamField body="numeroDian" type="string">

    </ParamField>
    <ParamField body="qrCode" type="string">
      🇨🇴 Colombia — URL del catálogo DIAN.
    </ParamField>
    <ParamField body="claveAcceso" type="string">
      🇪🇨 Ecuador — clave de acceso SRI de 49 caracteres.
    </ParamField>
    <ParamField body="numeroAutorizacion" type="string">
      🇪🇨 Ecuador.
    </ParamField>
    <ParamField body="ambiente" type="string">
      🇪🇨 Ecuador — `1` (producción) o `2` (pruebas).
    </ParamField>
    <ParamField body="folio" type="string">
      🇨🇱 Chile — folio SII.
    </ParamField>
    <ParamField body="ted" type="string">
      🇨🇱 Chile — string TED PKCS#7.
    </ParamField>
    <ParamField body="tipoDte" type="string">
      🇨🇱 Chile.
    </ParamField>
    <ParamField body="trackId" type="string">
      🇨🇱 Chile.
    </ParamField>
    <ParamField body="cae" type="string">
      🇦🇷 Argentina — CAE de 14 dígitos.
    </ParamField>
    <ParamField body="fechaVtoCae" type="string">
      🇦🇷 Argentina — `YYYY-MM-DD`.

    <ParamField body="tipoComprobante" type="string">
      🇦🇷 Argentina.

    <ParamField body="numeroControl" type="string">

  </Expandable>
</ParamField>

<ParamField body="error" type="object">
  Requerido cuando `eventType` es `rejected`, `denied` o `error`.

  <Expandable title="propiedades">
    <ParamField body="code" type="string">
      Código de error específico del proveedor.
    </ParamField>
    <ParamField body="message" type="string">
      Descripción legible para humanos.
    </ParamField>
  </Expandable>
</ParamField>

### Respuesta

<ResponseField name="received" type="boolean">
  Siempre `true` con `2xx`.
</ResponseField>

<ResponseField name="receiptId" type="string">
  Identificador en Fire de esta entrega.
</ResponseField>

<ResponseField name="outcome" type="string">
  Uno de `created`, `updated`, `idempotent`, `regression`, `duplicate`.
</ResponseField>

<ResponseField name="documentId" type="string">
  ID interno en Fire del documento fiscal persistido.
</ResponseField>

<ResponseField name="processingMs" type="number">
  Tiempo de procesamiento server-side, en milisegundos.
</ResponseField>
