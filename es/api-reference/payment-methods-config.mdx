---
title: "Configuración de métodos de pago"
api: "GET https://api.fire.rest/api/v1/external/payment-methods/config"
description: "Lee los métodos de pago configurados (habilitados y deshabilitados) para el vendor asociado a tu API key. Úsalo para saber qué métodos de pago puede ofrecer tu integración."
authMethod: "bearer"
---

Devuelve la configuración completa de métodos de pago para el vendor asociado a tu API key, enriquecida con datos del catálogo global (`uuid`, `name`, `description`).

El endpoint no acepta query params — `accountId` y `vendorId` se derivan de la API key. **Devuelve todos los métodos** (habilitados y deshabilitados) para que el cliente decida qué mostrar. Los métodos del JSONB sin match en el catálogo se excluyen.

<Info>
  Ya existe una [v2 de este endpoint](/es/api-reference/payment-methods-config-v2) que resuelve la
  configuración **por tienda**, con niveles de canal, fulfillment y terminal, y devuelve los
  valores de configuración. **Esta v1 sigue disponible y no tiene fecha de baja** — migrá cuando
  te sirva.
</Info>

## Autenticación

<ParamField header="x-api-key" type="string" required>
  Tu API key de Fire con scope `payment-methods:read`. La key **debe ser vendor-scoped** (binding account + vendor) — las keys sin `vendorId` se rechazan con `403`.
</ParamField>

## Petición

<RequestExample>
```http
GET https://api.fire.rest/api/v1/external/payment-methods/config
x-api-key: <tu_api_key>
```
</RequestExample>

## Respuesta

<ResponseField name="accountId" type="string">UUID del account al que pertenece la API key.</ResponseField>

<ResponseField name="countries" type="object[]">
  <Expandable title="country">
    <ResponseField name="countryCode" type="string">ISO 3166-1 alpha-2 (ej. `BR`, `EC`, `CO`).</ResponseField>
    <ResponseField name="vendors" type="object[]">
      <Expandable title="vendor">
        <ResponseField name="vendorId" type="string">Identificador del vendor.</ResponseField>
        <ResponseField name="vendorName" type="string">Nombre legible del vendor.</ResponseField>
        <ResponseField name="paymentMethods" type="object[]">
          <Expandable title="paymentMethod">
            <ResponseField name="uuid" type="string">UUID del catálogo global de `payment_methods`.</ResponseField>
            <ResponseField name="code" type="string">Código del método (ej. `CASH`, `CREDIT_CARD`).</ResponseField>
            <ResponseField name="name" type="string">Nombre display.</ResponseField>
            <ResponseField name="description" type="string | null">Descripción opcional.</ResponseField>
            <ResponseField name="enabled" type="boolean">Si el método está activo para este vendor.</ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Notas

- `uuid` viene del catálogo global de `payment_methods`, no del JSONB por account.
- Los métodos deshabilitados se incluyen para que puedas renderizarlos con estado "no disponible" o esconderlos — es tu decisión.
- `countries` agrupa por código de país del JSONB.
