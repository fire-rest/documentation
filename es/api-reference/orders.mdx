## Objeto price

Los siguientes campos aparecen en los objetos price a lo largo del payload (`unitPrice`, `totalPrice`):

| Campo | Tipo | Descripción |
|---|---|---|
| `currencyCode` | string | Código de moneda ISO 4217 (p. ej. `USD`) |
| `totalBeforeSale` | string | Precio antes de cualquier precio en oferta |
| `subtotalWithoutTaxes` | string | Subtotal sin impuestos |
| `discountPercentage` | string | Porcentaje de descuento aplicado |
| `discountsValue` | string | Monto del descuento |
| `subtotalIncludeDiscounts` | string | Subtotal después de descuentos, antes de impuestos |
| `taxesPercentage` | string | Porcentaje de impuesto |
| `taxValue` | string | Monto del impuesto |
| `total` | string | Total final |
| `suggestedPrice` | string | Precio sugerido original |
