---
title: "Obtener una orden"
api: "GET https://api.fire.rest/v1/orders/{orderId}"
description: "Devuelve una sola orden por su ID Fire. Útil para consultar el estado actual o reproducir el payload original."
authMethod: "bearer"
---

<ParamField header="x-api-key" type="string" required>
  Tu API key de Fire con scope `orders:read`.
</ParamField>

<ParamField path="orderId" type="string" required>
  El UUID de Fire de la orden — el campo `orderId` en cualquier payload de evento `order.*`, o el retornado por `POST /v1/orders`.
</ParamField>

### Respuesta

Devuelve el V4 Order Snapshot completo — misma forma que el bloque `data` en el evento [`order.completed`](/es/webhook-reference/order-completed). Si la orden fue cancelada o tiene eventos fiscales, esos bloques (`cancellation`, `fiscal`) están presentes también, espejando exactamente el último evento que Fire emitió para esta orden.

<RequestExample>

```bash curl
curl https://api.fire.rest/v1/orders/df8cdf6a-62c5-4daf-b35f-b6e7bb1b98b3 \
  -H "x-api-key: pk_live_a1b2c3..." \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..."
```

```js Node.js
const orderId = "df8cdf6a-62c5-4daf-b35f-b6e7bb1b98b3";
const res = await fetch(`https://api.fire.rest/v1/orders/${orderId}`, {
  headers: {
    "x-api-key":     process.env.FIRE_API_KEY,
    "Authorization": `Bearer ${accessToken}`,
  },
});
const order = await res.json();
```

```python Python
import os, requests

order_id = "df8cdf6a-62c5-4daf-b35f-b6e7bb1b98b3"
res = requests.get(
    f"https://api.fire.rest/v1/orders/{order_id}",
    headers={
        "x-api-key":     os.environ["FIRE_API_KEY"],
        "Authorization": f"Bearer {access_token}",
    },
)
res.raise_for_status()
order = res.json()
```

</RequestExample>
