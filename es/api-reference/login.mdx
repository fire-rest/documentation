---
title: "Login"
api: "POST https://api.fire.rest/v1/auth/login"
description: "Cambia tus credenciales por un access token. Úsalo como Bearer en cada solicitud subsiguiente."
---

<ParamField header="x-api-key" type="string" required>
  Tu API key de Fire. Emitida desde el dashboard en **Settings → API Keys**.
</ParamField>

<ParamField body="username" type="string" required>
  Tu username de Fire.
</ParamField>

<ParamField body="password" type="string" required>
  Tu password de Fire.
</ParamField>

<ResponseField name="token" type="string">
  Access token. Inclúyelo en el header `Authorization: Bearer <token>` en todas las solicitudes.
</ResponseField>

<ResponseField name="expiresIn" type="number">
  Tiempo de vida del token en segundos.
</ResponseField>

<ResponseExample>
```json 200
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expiresIn": 3600
}
```

```json 401
{
  "error": {
    "code": "invalid_credentials",
    "message": "Invalid credentials"
  }
}
```
</ResponseExample>
