---
title: "Login"
api: "POST https://api.fire.rest/v1/auth/login"
description: "Intercambia tus credenciales por un token de acceso. Usa el token devuelto como Bearer token en todas las peticiones siguientes a la API."
---

<ParamField header="x-api-key" type="string" required>
  Tu API key de Fire. Se emite desde el dashboard de Fire en **Settings → API Keys**.
</ParamField>

<ParamField body="username" type="string" required>
  Tu nombre de usuario de Fire.
</ParamField>

<ParamField body="password" type="string" required>
  Tu contraseña de Fire.
</ParamField>

<ResponseField name="token" type="string">
  Token de acceso. Inclúyelo en la cabecera `Authorization: Bearer <token>` en todas las peticiones a la API.
</ResponseField>

<ResponseField name="expiresIn" type="number">
  Tiempo de vida del token en segundos.
</ResponseField>

<ResponseExample>
```json 200
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expiresIn": 3600
}
```

```json 401
{
  "error": {
    "code": "unauthorized",
    "message": "Invalid credentials"
  }
}
```
</ResponseExample>
