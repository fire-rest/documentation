---
title: "Configuración de canales"
api: "GET https://app.fire.rest/api/v1/external/channels/config"
description: "Lee la configuración activa de canales de venta (con tipos de fulfillment) para el vendor asociado a tu API key. Úsalo para saber qué canales y combinaciones de fulfillment puede usar tu integración."
authMethod: "bearer"
---

Devuelve la configuración completa de canales de venta para el vendor asociado a tu API key, enriquecida con datos del catálogo global (`uuid`, `name`, `description`) y los tipos de fulfillment configurados para cada canal.

El endpoint no acepta query params — `accountId` y `vendorId` se derivan de la API key. Solo retorna canales con `enabled !== false`. Los canales del JSONB del account que no tengan match en el catálogo se excluyen de la respuesta.

## Autenticación

<ParamField header="x-api-key" type="string" required>
  Tu API key de Fire con scope `channels:read`. La key **debe ser vendor-scoped** (binding account + vendor) — las keys sin `vendorId` se rechazan con `403`.
</ParamField>

## Petición

<RequestExample>
```http
GET https://app.fire.rest/api/v1/external/channels/config
x-api-key: <tu_api_key>
```
</RequestExample>

## Notas

- `uuid` viene del catálogo global de `channels`, no del JSONB por account.
- `fulfillmentTypes` solo incluye los tipos configurados para ese canal en el vendor. Tipos sin match en el catálogo se excluyen.
- `countries` agrupa por código de país del JSONB. Un vendor puede aparecer en múltiples países si tiene configuración por país.
