---
title: "Abrir la gaveta"
description: "Cuándo se abre sola la gaveta del efectivo y cómo abrirla fuera de una venta con el código del encargado."
---

Una gaveta que se abre sin una venta es por donde sale el efectivo sin dejar rastro. Por eso el POS la abre solo en los momentos en que el cajero tiene que tocar el dinero, y para abrirla fuera de esos momentos pide un código del encargado, que queda registrado.

<Note>
  **Lo mínimo que hay que saber**

  - La gaveta se abre **sola** cuando hay que recibir o devolver efectivo.
  - Abrirla **a mano** pide un código del encargado de **Accesos → Abrir gaveta**. Cada código sirve para una apertura.
  - La gaveta se abre a través del Agente Fire y la impresora, así que el equipo tiene que tenerlos configurados.
</Note>

## Requisitos previos

- La caja abierta.
- El Agente Fire instalado y la impresora configurada, con la gaveta conectada a la impresora. Consulta [Impresora y ajustes del terminal](/es/manuals/pos/terminal-settings).

## Cuándo se abre sola

| Momento | Por qué |
|---------|---------|
| Al tocar **Efectivo** en la pantalla de cobro | Para guardar el dinero que te da el cliente y sacar el vuelto |
| Al **anular un cobro** | Para devolver el efectivo del cobro anulado |
| Antes de cobrar un pedido de kiosco | Para recibir el efectivo del cliente |
| Al anular una venta finalizada que se pagó en efectivo | Para devolver el dinero |

No se abre al finalizar la venta ni cuando la venta se pagó solo con tarjeta.

## Abrirla a mano

Para abrir la gaveta fuera de una venta —dar cambio de billetes, guardar un pago que quedó afuera— hace falta el código del encargado.

1. Toca tu nombre arriba a la derecha para abrir **Configuraciones** y elige **Abrir gaveta**.
2. Pídele al encargado un código de **Accesos → Abrir gaveta**. Consulta [Códigos de autorización](/es/manuals/pos/authorization-codes).

   <Frame>
     <img src="/images/manuals/pos/cash-drawer/01-drawer-code.png" alt="Ventana Abrir gaveta pidiendo el código de autorización" />
   </Frame>

3. Escribe los 6 dígitos del código.

   <Frame>
     <img src="/images/manuals/pos/cash-drawer/02-drawer-code-typed.png" alt="Código de autorización de 6 dígitos escrito en la ventana Abrir gaveta" />
   </Frame>

4. Toca **Abrir gaveta**. El POS confirma **Gaveta abierta**.

   <Frame>
     <img src="/images/manuals/pos/cash-drawer/03-drawer-result.png" alt="Aviso Gaveta abierta" />
   </Frame>

<Tip>
  Si la gaveta se abrió, terminaste. El código ya no sirve para otra apertura.
</Tip>

---

## Errores que salen caros

<Warning>
  **Abrir la gaveta para dar vuelto de una venta que no se cobró.** Todo movimiento de efectivo tiene que pasar por un cobro. Si abres la gaveta a mano para cobrar "por fuera", ese dinero no aparece en ninguna venta y al cierre sale como sobrante o faltante.
</Warning>

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="Dice «Código inválido o ya usado»">
    El código ya se usó, venció o es para otra operación. Pídele al encargado uno nuevo de **Accesos → Abrir gaveta**.
  </Accordion>

  <Accordion title="El POS dice que abrió pero la gaveta no se movió">
    Revisa que el Agente Fire esté abierto, que la impresora esté configurada y que la gaveta esté conectada a la impresora.
  </Accordion>

  <Accordion title="¿Puedo usar el mismo código dos veces?">
    No. Cada código abre la gaveta una vez.
  </Accordion>
</AccordionGroup>
