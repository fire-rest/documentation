Una **pantalla** es un dispositivo KDS (monitor + app fire-kds). Cada pantalla tiene un **Device ID** único dentro de la tienda.

## Campos importantes

| Campo | Para qué sirve |
|---|---|
| **Store** | La tienda. |
| **Name** | Nombre admin (ej. "Pantalla Parrilla"). |
| **Device identifier** | El ID que la app fire-kds usa para registrarse. **No se puede cambiar** después de crear. Debe coincidir exactamente con el dispositivo. |
| **Location** | Ubicación física opcional (referencia operativa). |
| **Active** | Si está deshabilitada, no debería usarse en producción. |
| **Dark mode** | Tema claro/oscuro por defecto en fire-kds. |

<Warning>
  El **device identifier** no se puede cambiar después de crear la pantalla. Acuérdalo con el equipo de hardware antes de guardar.
</Warning>

## Crear una pantalla

<Steps>
  <Step title="Abre el formulario de pantalla">
    **KDS → Screens → Create** (`/kds/admin/screens/new`).
  </Step>
  <Step title="Completa tienda, nombre y device identifier">
    Por ejemplo, device identifier `KDS-GRILL-01`.
  </Step>
  <Step title="Guarda">
    El sistema redirige a **Assign stations**.
  </Step>
  <Step title="Asigna estaciones">
    - Agrega las estaciones que esta pantalla debe mostrar (ej. `GRILL` y `FRY`).
    - Define el **sort order** (orden de columnas en la UI).

    <Frame>
      <img src="/images/manuals/kds/screens/02-assign-stations.png" alt="Pantalla Assign stations con sort order" />
    </Frame>
  </Step>
  <Step title="Guarda la asignación" />
</Steps>

<Note>
  Relación clave: una pantalla puede mostrar **varias estaciones**, y una estación puede aparecer en **varias pantallas** (ej. armado visible tanto en el monitor de expo como en el de despacho).
</Note>
