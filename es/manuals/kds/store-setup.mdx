---

Hay dos formas de configurar una tienda KDS: aplicar una **plantilla** (recomendado cuando repites el mismo layout) o configurar todo **desde cero**.

## Opción A — Usar una plantilla

Ideal cuando ya tienes un layout probado (misma cadena, mismo tipo de cocina).

<Steps>
  <Step title="Abre Setup templates">
    Ve a **KDS → Setup templates** (`/kds/admin/setup-templates`).
  </Step>
  <Step title="Crea una plantilla">
    Elige una **plantilla vacía** o **Seed from store** (copiar la config de una tienda que ya funciona).

    <Frame>
      <img src="/images/manuals/kds/store-setup/01-setup-templates.png" alt="Pantalla de plantillas de configuración del KDS" />
    </Frame>
  </Step>
  <Step title="Completa las secciones en orden">
    En el editor, completa las secciones en este orden lógico:

    - Estaciones
    - Pantallas + vínculos pantalla ↔ estación
    - Ruteo
    - (Opcional) badges de canal/servicio
    - (Opcional) impresión listo-para-retiro por pantalla
    - (Opcional) teclado por pantalla
  </Step>
  <Step title="Guarda la plantilla" />
</Steps>

### Aplicar una plantilla a una tienda nueva (wizard inicial)

<Steps>
  <Step title="Crea la tienda">
    **KDS → All Stores → Create**.
  </Step>
  <Step title="Abre la configuración inicial">
    Si la tienda está vacía (sin estaciones, pantallas ni ruteo), abre `/kds/admin/stores/initial-setup/{storeId}`.
  </Step>
  <Step title="Usa un blueprint">
    Elige **Use a blueprint** → selecciona la plantilla → revisa/edita → **Apply to store**.

    <Frame>
      <img src="/images/manuals/kds/store-setup/02-initial-setup-wizard.png" alt="Asistente de configuración inicial aplicando un blueprint" />
    </Frame>
  </Step>
  <Step title="Revisa el progreso">
    El asistente muestra el progreso por fases (estaciones, pantallas, vínculos, ruteo, etc.).
  </Step>
</Steps>

<Tip>
  También puedes **guardar una tienda existente como plantilla** desde **Store settings** de esa tienda ("Save as template").
</Tip>

## Opción B — Configurar manualmente (desde cero)

Orden recomendado si no usas plantilla:

| Paso | Menú del backoffice | Ruta |
|---|---|---|
| 1 | All Stores → crear tienda | `/kds/admin/stores/new` |
| 2 | Stations → crear estaciones | `/kds/admin/stations/new` |
| 3 | Screens → crear pantallas | `/kds/admin/screens/new` |
| 4 | Asignar estaciones a cada pantalla | `/kds/admin/screens/{id}/assign-stations` |
| 5 | Routing → estrategia activa | `/kds/admin/routing/new` |
| 6 | (Opcional) Input devices + Keyboard layouts | `/kds/admin/devices`, `/kds/admin/keyboard-layouts` |
| 7 | Validar en el **KDS Map** de la tienda | `/kds/admin/stores/{storeId}/kds-map` |

El asistente de **configuración inicial** también ofrece **Create from scratch**: abre el mismo editor que las plantillas, pero aplicado directo a la tienda vacía.

<Note>
  Cada paso tiene su propia página en esta sección: [Estaciones](/es/manuals/kds/stations), [Pantallas](/es/manuals/kds/screens), [Ruteo](/es/manuals/kds/routing) y [Periféricos, impresión y validación](/es/manuals/kds/peripherals-printing).
</Note>
