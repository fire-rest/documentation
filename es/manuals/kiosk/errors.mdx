<Warning>

</Warning>

Cuando algo falla, el kiosco muestra un mensaje corto para el cliente, una referencia y un botón **Ver detalles** con el texto técnico. Debajo va una línea con la versión de la app, la tienda, el totem y la hora del error, y el pedido si ya se envió: con una captura de pantalla alcanza para encontrar el caso en los logs.

```text
              Este produto não está disponível
   Não conseguimos carregar este produto. Tente novamente em alguns minutos.

            Ref.: T153 · T102 · 500        Ver detalhes ▾

        P 1.2.12-fire · K066 · 98051774 · 05/10 15:58:56
```

## Cómo leer el código

La letra dice de quién es el error, es decir, a quién hay que avisar. Donde dos responsables comparten inicial, el prefijo lleva dos letras.

| Prefijo | Responsable | A quién avisar |
|---|---|---|
| **T** | TRD | Equipo de TRD (kiosco, Fire, Firebase, PayBridge, Masivo) |
| **K** | KFC | KFC: Maxpoint y la infraestructura de la tienda |
| **B** | CliSiTef | Software Express / Fiserv (SiTef Brasil) |
| **D** | DeUna | DeUna |
| **DF** | Datafast | Datafast (pinpad Ecuador) |
| **M** | Medianet | Medianet (pinpad Ecuador) |
| **R** | Redeban | Redeban (datáfono Colombia) |
| **PC** | Pinpad Colombia | Proveedor del pinpad de Colombia |
| **TB** | Transbank | Transbank (Chile) |
| **H** | Hasar | Hasar (Chile) |
| **PN** | POSNET | POSNET (Argentina) |
| **S** | Sitef | Sitef Venezuela (pago móvil) |
| **I** | Impresora | Personal de la tienda: revisar la impresora |

En TRD el número dice además en qué parte del flujo pasó:

| Rango | Parte del flujo |
|---|---|
| T001–T049 | Vinculación y Firebase |
| T050–T099 | Dispositivo y configuración |
| T100–T149 | Conexión |
| T150–T199 | Menú y productos |
| T200–T249 | Carrito, cupones y fidelidad |
| T250–T299 | Pagos |
| T300–T349 | Pedido |
| T350–T399 | Anulaciones |
| T900–T999 | Solo logs |

## Cómo leer la referencia y la línea técnica

- **Primer código:** el error del servicio, por ejemplo `T153` (no se pudo cargar el producto).
- **Segundo código:** qué pasó con la conexión, por ejemplo `T102` (el servidor respondió con error).
- **Número final:** el status HTTP que devolvió el servidor, por ejemplo `500`.
- **En CliSiTef:** el código de retorno de la biblioteca y el cupom fiscal, por ejemplo `Ref.: B006 rc=-5 · cp=1790342446698`.
- **Línea técnica:** versión de la app · tienda · totem (8 caracteres del deviceId, igual que en los logs) · fecha y hora del totem · pedido.
