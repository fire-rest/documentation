---
title: 'Ajustes globales'
description: 'Mintlify te da control total sobre el aspecto de tu documentación con el archivo docs.json'
icon: 'gear'
---

Cada sitio Mintlify necesita un archivo `docs.json` con la configuración principal. Más información sobre las [propiedades](#properties) abajo.

## Propiedades

<ResponseField name="name" type="string" required>
Nombre del proyecto. Se usa como título global.

Ejemplo: `mintlify`

</ResponseField>

<ResponseField name="navigation" type="Navigation[]" required>
  Lista de grupos con las páginas de cada grupo
  <Expandable title="Navigation">
    <ResponseField name="group" type="string">
    Nombre del grupo.

    Ejemplo: `Settings`

    </ResponseField>
    <ResponseField name="pages" type="string[]">
    Rutas relativas a los archivos markdown que serán páginas.

    Ejemplo: `["customization", "page"]`

    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="logo" type="string or object">
  Ruta al logo u objeto con rutas para modo claro y oscuro
  <Expandable title="Logo">
    <ResponseField name="light" type="string">
      Ruta al logo en modo claro
    </ResponseField>
    <ResponseField name="dark" type="string">
      Ruta al logo en modo oscuro
    </ResponseField>
    <ResponseField name="href" type="string" default="/">
      Destino al hacer clic en el logo
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="favicon" type="string">
  Ruta al favicon
</ResponseField>

<ResponseField name="colors" type="Colors">
  Colores hex del tema global
  <Expandable title="Colors">
    <ResponseField name="primary" type="string" required>
      Color primario: contenido destacado, cabeceras de sección, acentos en modo claro
    </ResponseField>
    <ResponseField name="light" type="string">
      Color primario en modo oscuro: contenido destacado, cabeceras, acentos
    </ResponseField>
    <ResponseField name="dark" type="string">
      Color primario para botones importantes
    </ResponseField>
    <ResponseField name="background" type="object">
      Color de fondo en modo claro y oscuro
      <Expandable title="Object">
        <ResponseField name="light" type="string" required>
          Código hex del fondo en modo claro
        </ResponseField>
        <ResponseField name="dark" type="string" required>
          Código hex del fondo en modo oscuro
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="topbarLinks" type="TopbarLink[]">
  Lista de `name` y `url` de enlaces en la barra superior
  <Expandable title="TopbarLink">
    <ResponseField name="name" type="string">
    Texto del botón.

    Ejemplo: `Contact us`
    </ResponseField>
    <ResponseField name="url" type="string">
    URL al hacer clic. Ejemplo: `https://mintlify.com/docs`
    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="topbarCtaButton" type="Call to Action">
  <Expandable title="Topbar Call to Action">
    <ResponseField name="type" type={'"link" or "github"'} default="link">
    Con `link` muestra un botón. Con `github` muestra información del repositorio y estrellas.
    </ResponseField>
    <ResponseField name="url" type="string">
    Si es `link`: destino del botón.
    
    Si es `github`: URL del repositorio para cargar datos de GitHub.
    </ResponseField>
    <ResponseField name="name" type="string">
    Texto del botón. Solo obligatorio si `type` es `link`.
    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="versions" type="string[]">
  Nombres de versión. Úsalo solo si quieres varias versiones de la documentación con selector en la barra de navegación.
</ResponseField>

<ResponseField name="anchors" type="Anchor[]">
  Lista de anclas con `icon`, `color` y `url`.
  <Expandable title="Anchor">
    <ResponseField name="icon" type="string">
    Icono de [Font Awesome](https://fontawesome.com/search?q=heart) para la ancla.

    Ejemplo: `comments`
    </ResponseField>
    <ResponseField name="name" type="string">
    Etiqueta de la ancla.

    Ejemplo: `Community`
    </ResponseField>
    <ResponseField name="url" type="string">
      Prefijo de URL de las páginas de esta ancla. Suele coincidir con el nombre de la carpeta de páginas.
    </ResponseField>
    <ResponseField name="color" type="string">
      Color hex del fondo del icono. También puede ser un degradado con `from` y `to` en hex.
    </ResponseField>
    <ResponseField name="version" type="string">
      Si quieres ocultar la ancla hasta que se seleccione la versión correcta de la documentación.
    </ResponseField>
    <ResponseField name="isDefaultHidden" type="boolean" default="false">
      `true` para ocultar la ancla hasta que alguien enlace directamente a documentación dentro de ella.
    </ResponseField>
    <ResponseField name="iconType" default="duotone" type="string">
      Uno de: "brands", "duotone", "light", "sharp-solid", "solid" o "thin"
    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="topAnchor" type="Object">
  Sobrescribe la configuración de la ancla superior.
  <Expandable title="Object">
    <ResponseField name="name" default="Documentation" type="string">
      Nombre de la ancla superior
    </ResponseField>
    <ResponseField name="icon" default="book-open" type="string">
      Icono de Font Awesome.
    </ResponseField>
    <ResponseField name="iconType" default="duotone" type="string">
      Uno de: "brands", "duotone", "light", "sharp-solid", "solid" o "thin"
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tabs" type="Tabs[]">
  Pestañas de navegación principales.
  <Expandable title="Tabs">
    <ResponseField name="name" type="string">
      Etiqueta de la pestaña.
    </ResponseField>
    <ResponseField name="url" type="string">
      Prefijo de URL de las páginas de esta pestaña. Suele coincidir con el nombre de la carpeta.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="api" type="API">
  Configuración de la API. Más información en [componentes de API](https://mintlify.com/docs/api-playground/mdx/configuration).
  <Expandable title="API">
    <ResponseField name="baseUrl" type="string">
      URL base de los endpoints. Si `baseUrl` es un array, el usuario puede alternar entre varias bases.
    </ResponseField>

    <ResponseField name="auth" type="Auth">
      <Expandable title="Auth">
        <ResponseField name="method" type='"bearer" | "basic" | "key"'>
          Estrategia de autenticación para todos los endpoints.
        </ResponseField>
        <ResponseField name="name" type="string">
        Nombre del parámetro de autenticación en el playground.

        Si el método es `basic`, el formato debe ser `[usuario]:[contraseña]`
        </ResponseField>
        <ResponseField name="inputPrefix" type="string">
        Prefijo por defecto del campo de autenticación.

        Ej.: con `inputPrefix` `AuthKey`, el valor por defecto del campo será `AuthKey`.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="playground" type="Playground">
      Opciones del playground de API

      <Expandable title="Playground">
        <ResponseField name="mode" default="show" type='"show" | "simple" | "hide"'>
          Si el playground está visible, oculto o en modo `simple` (solo el endpoint, sin interacción).

          Más en las [guías del playground](https://mintlify.com/docs/api-playground/overview)
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="maintainOrder" type="boolean">
      Activa el orden de claves de las páginas OpenAPI igual al del archivo OpenAPI.

      <Warning>Pronto será el comportamiento por defecto y este campo quedará obsoleto.</Warning>
    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="openapi" type="string | string[]">
  Cadena o lista de URLs o rutas relativas al archivo OpenAPI.
  
  Ejemplos:
  <CodeGroup>
    ```json Absolute
    "openapi": "https://example.com/openapi.json"
    ```
    ```json Relative
    "openapi": "/openapi.json"
    ```
    ```json Multiple
    "openapi": ["https://example.com/openapi1.json", "/openapi2.json", "/openapi3.json"]
    ```
  </CodeGroup>

</ResponseField>

<ResponseField name="footerSocials" type="FooterSocials">
  Objeto de redes: cada clave es la plataforma y el valor la URL.
  
  Ejemplo: 
  ```json
  {
    "x": "https://x.com/mintlify",
    "website": "https://mintlify.com"
  }
  ```
  <Expandable title="FooterSocials">
    <ResponseField name="[key]" type="string">
    Una de: `website`, `facebook`, `x`, `discord`, `slack`, `github`, `linkedin`, `instagram`, `hacker-news`
    
    Ejemplo: `x`
    </ResponseField>
    <ResponseField name="property" type="string">
    URL del perfil o página.
    
    Ejemplo: `https://x.com/mintlify`
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="feedback" type="Feedback">
  Botones de retroalimentación

  <Expandable title="Feedback">
    <ResponseField name="suggestEdit" type="boolean" default="false">
    Botón para sugerir ediciones mediante pull requests
    </ResponseField>
    <ResponseField name="raiseIssue" type="boolean" default="false">
    Botón para abrir un issue sobre la documentación
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="modeToggle" type="ModeToggle">
  Personaliza el interruptor claro/oscuro.
  <Expandable title="ModeToggle">
    <ResponseField name="default" type={'"light" or "dark"'}>
      Fuerza modo claro u oscuro para usuarios nuevos. Si no se define, se usa la preferencia del sistema.
    </ResponseField>
    <ResponseField name="isHidden" type="boolean" default="false">
      `true` para ocultar el interruptor. Combínalo con `default` para forzar solo claro u oscuro. Por ejemplo:
      
      <CodeGroup>
      ```json Only Dark Mode
      "modeToggle": {
        "default": "dark",
        "isHidden": true
      }
      ```

      ```json Only Light Mode
      "modeToggle": {
        "default": "light",
        "isHidden": true
      }
      ```
      </CodeGroup>

    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="backgroundImage" type="string">
  Imagen de fondo detrás de todas las páginas. Ejemplos:
  [Infisical](https://infisical.com/docs) y [FRPC](https://frpc.io).
</ResponseField>
