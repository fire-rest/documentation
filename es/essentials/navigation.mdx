El menú de navegación es la lista de enlaces del sitio.

Actualizarás `docs.json` cada vez que añadas una página. Las páginas no aparecen solas.

## Sintaxis de navegación

La sintaxis es recursiva: puedes anidar grupos. No hace falta incluir `.mdx` en los nombres.

<CodeGroup>

```json Navegación simple
"navigation": {
  "tabs": [
    {
      "tab": "Docs",
      "groups": [
        {
          "group": "Getting Started",
          "pages": ["quickstart"]
        }
      ]
    }
  ]
}
```

```json Navegación anidada
"navigation": {
  "tabs": [
    {
      "tab": "Docs",
      "groups": [
        {
          "group": "Getting Started",
          "pages": [
            "quickstart",
            {
              "group": "Nested Reference Pages",
              "pages": ["nested-reference-page"]
            }
          ]
        }
      ]
    }
  ]
}
```

</CodeGroup>

## Carpetas

Coloca tus archivos MDX en carpetas y actualiza las rutas en `docs.json`.

Por ejemplo, para `https://yoursite.com/your-folder/your-page` crea la carpeta `your-folder` con `your-page.mdx`.

<Warning>

No puedes usar `api` como nombre de carpeta en la raíz salvo que esté anidada. Mintlify usa Next.js, que reserva `api` para llamadas internas. Un nombre como `api-reference` sí es válido.

</Warning>

```json Navegación con carpeta
"navigation": {
  "tabs": [
    {
      "tab": "Docs",
      "groups": [
        {
          "group": "Group Name",
          "pages": ["your-folder/your-page"]
        }
      ]
    }
  ]
}
```

## Páginas ocultas

Los MDX que no estén en `docs.json` no aparecen en la barra lateral, pero siguen en el buscador y enlazándolos directamente.
