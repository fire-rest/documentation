## Código en línea

Para marcar una `palabra` o `frase` como código, usa acentos graves (\`).

```
Para marcar una `palabra` o `frase` como código, enciérrala en acentos graves (`).
```

## Bloques de código

Usa [bloques con cercado](https://www.markdownguide.org/extended-syntax/#fenced-code-blocks) con tres acentos graves y el lenguaje para resaltado de sintaxis. Opcionalmente puedes poner un nombre después del lenguaje.

```java HelloWorld.java
class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

class HelloWorld {
