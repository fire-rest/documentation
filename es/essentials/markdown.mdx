## Títulos

Para encabezados de sección.

```md
## Títulos
```

### Subtítulos

Para subsecciones.

```md
### Subtítulos
```

<Tip>

Cada **título** y **subtítulo** crea un ancla y aparece en la tabla de contenidos a la derecha.

</Tip>

## Formato de texto

Soportamos la mayor parte del formato Markdown: `**`, `_` o `~` alrededor del texto.

| Estilo        | Cómo escribirlo   | Resultado       |
| ------------- | ----------------- | --------------- |
| Negrita       | `**negrita**`     | **negrita**     |
| Cursiva       | `_cursiva_`       | _cursiva_       |
| Tachado       | `~tachado~`       | ~tachado~       |

Puedes combinarlos. Por ejemplo, `**_negrita y cursiva_**` da **_negrita y cursiva_**.

Para superíndice y subíndice usa HTML: `<sup>` o `<sub>`.

| Tamaño      | Cómo escribirlo          | Resultado                 |
| ----------- | ------------------------ | ------------------------- |
| Superíndice | `<sup>super</sup>`       | <sup>super</sup>          |
| Subíndice   | `<sub>sub</sub>`         | <sub>sub</sub>            |

## Enlaces a páginas

Añade enlaces con `[]()`. Por ejemplo `[Google](https://google.com)`.

Los enlaces internos deben ser relativos a la raíz del sitio, con la ruta completa de carpeta: `[texto](/writing-content/text)`.

Los enlaces relativos como `[texto](../text)` pueden cargar más despacio.

## Citas en bloque

### Una línea

Añade `>` delante del párrafo.

> Dorothy siguió a la bruja por muchas habitaciones del castillo.

```md
> Dorothy siguió a la bruja por muchas habitaciones del castillo.
```

### Varias líneas

> Dorothy siguió a la bruja por muchas habitaciones del castillo.
>
> La bruja le ordenó fregar ollas y barrer el suelo.

```md
> Dorothy siguió a la bruja por muchas habitaciones del castillo.
>
> La bruja le ordenó fregar ollas y barrer el suelo.
```

### LaTeX

Mintlify admite [LaTeX](https://www.latex-project.org) con el componente Latex.

<Latex>8 x (vk x H1 - H2) = (0,1)</Latex>

```md
<Latex>8 x (vk x H1 - H2) = (0,1)</Latex>
```
