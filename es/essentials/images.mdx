## Imagen

### Con Markdown

La [sintaxis Markdown](https://www.markdownguide.org/basic-syntax/#images) permite añadir imágenes así:

```md
![título](/path/image.jpg)
```

El tamaño debe ser menor de 5 MB. Si no, aloja en [Cloudinary](https://cloudinary.com/) o [S3](https://aws.amazon.com/s3/) y usa la URL.

### Con embeds

Para más control, puedes usar [embeds](https://mintlify.com/docs) para imágenes.

```html
<img height="200" src="/path/image.jpg" />
```

### iFrames

Carga otra página HTML dentro del documento. Sobre todo para vídeos incrustados.

```html
<iframe src="https://www.youtube.com/embed/4KzFe50RQkQ"> </iframe>
```
