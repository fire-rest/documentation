<Warning>
  **Propuesta — todavía no implementada en XMART_BACKOFFICE.** Ver [Entrega
  híbrida](/es/hybrid-delivery/overview) para contexto. Esta página muestra la forma
  prevista del evento, no un contrato en vivo.
</Warning>

`menu.list_ready` es la mitad de notificación de la [entrega
híbrida](/es/hybrid-delivery/overview): le dice a tu sistema que un menú está listo
para una tienda y canal específicos, sin llevar ningún dato de catálogo. Llamá a
[`GET /v1/menus/{listId}`](/es/hybrid-delivery/get-menu) con el `listId` de este
evento para traer el menú real.

## Payload

```json
{
  "event": {
    "id": "evt_ghi789",
    "type": "menu.list_ready",
    "executionId": "exec_def456",
    "createdAt": "2025-01-15T14:31:00.000Z"
  },
  "data": {
    "account": "1",
    "country": "EC",
    "groupId": "a3f7c2d1-84be-4e10-9b3a-2c5d6e7f8091",
    "listId": "805-iFood-delivery",
    "storeId": "b3d2a1f0-6e21-4c3a-9f5d-7a8b9c0d1e2f",
    "channelId": "0E049503-85CF-E511-80C6-000D3A3261F3"
  }
}
```

## Campos

### `data`

| Campo | Tipo | Descripción |
|---|---|---|
| `account` | string | Identificador de la cuenta |
| `country` | string | Código de país ISO 3166-1 alpha-2 (p. ej. `EC`, `BR`, `CO`) |
| `groupId` | string | UUID que correlaciona eventos del mismo batch de publicación o sincronización |
| `listId` | string | Identificador del menú. Pasalo a [`GET /v1/menus/{listId}`](/es/hybrid-delivery/get-menu) para traer el menú |
| `storeId` | string | UUID interno de la tienda (PK `stores.id`) — misma convención que `list.storeId` en [`menu.updated`](/es/webhook-reference/menu-updated) |
| `channelId` | string | UUID interno del canal de ventas (PK `channels.id`) — misma convención que `list.channelId` en [`menu.updated`](/es/webhook-reference/menu-updated) |

## Notas

- Este evento no lleva datos de catálogo. Si necesitás categorías, productos o
  grupos de modificadores, llamá a
  [`GET /v1/menus/{listId}`](/es/hybrid-delivery/get-menu).
- `listId` es la llave de correlación entre este evento y el endpoint de fetch —
  mismo identificador usado en los demás eventos de menú (`list.listId` en
  `menu.updated`).
