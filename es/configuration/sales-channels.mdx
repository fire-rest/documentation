Los canales de venta representan los agregadores de delivery (iFood, Keeta, 99, Rappi, etc.) configurados dentro de Fire para cada tienda. Si tu integración publica menús a agregadores o inyecta órdenes, necesitas mapear los IDs de canal de Fire a los IDs del agregador correspondiente.

## Obtener canales

```http
GET /v1/sales-channels
Authorization: Bearer <your_api_key>
```

```json
      "store_id": "store_xyz"
    }
  ]
}
```

## Mapeo de canales

Cuando Fire emite un evento de publicación, el payload incluye un array `channels` con los IDs de canal de Fire. Usa tu mapeo guardado para resolver a qué agregador corresponde cada ID.

```json
{
  "event": "menu.updated",
  "data": {
    "channels": ["channel_abc123", "channel_def456"],
    ...
  }
}
```

Guarda el mapeo al iniciar y refréscalo cuando haga falta.

## Cuándo re-obtener

Re-obtén la lista de canales:

- Al iniciar
- Cuando encuentres un `channel_id` desconocido en un evento webhook
- En un intervalo programado (recomendado: cada 24 horas)
