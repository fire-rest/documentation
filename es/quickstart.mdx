Esta guía te lleva por los pasos mínimos para tener una integración funcionando con Fire: recibir eventos de orden a través de un Integration Flow e inyectar órdenes vía la API REST.

## Prerrequisitos

- Credenciales de API desde el dashboard de Fire (consulta [Autenticación](/es/authentication))
- Un endpoint HTTPS accesible públicamente
- Acceso al dashboard en **Settings → Integration Flows**

## Paso 1: Configurar un Integration Flow

En el dashboard de Fire, ve a **Settings → Integration Flows → New flow**, luego:

- **Trigger:** elige `order.completed`
- **Scope:** account, vendor y opcionalmente tiendas específicas
- **Nodo HTTP:** agrega uno y configura
  - Método: `POST`
  - URL: tu endpoint HTTPS
  - Headers: `Content-Type: application/json` (más cualquier header de auth — Bearer token / API key)
  - Body: pega el template canónico de ejemplo que el dashboard incluye (produce `{ event, data, _meta }`)
- **Activa** el flow

Para un walkthrough de 10 minutos con detalle paso a paso, consulta [Manejar eventos de orden](/es/guides/handle-order-events).

<Tip>
  Durante el desarrollo puedes usar una herramienta como [ngrok](https://ngrok.com) para exponer un servidor local a internet. Pega la URL HTTPS de ngrok como URL del nodo HTTP del flow.
</Tip>

## Paso 2: Identificadores de canal y servicio para órdenes

Si inyectas órdenes, los objetos `channel` y `service` necesitan valores `uid` de Fire (y campos relacionados). Obtén esos identificadores desde los payloads de webhooks de publicación — por ejemplo [`channel.updated`](/es/webhook-reference/channel-updated) y eventos relacionados — o desde la configuración de integración y canales que gestionas en el panel de Fire (consulta [Integraciones de agregadores](/es/configuration/backoffice-integrations)).

## Paso 3: Manejar el evento

Tu endpoint recibirá peticiones `POST` desde tu flow cada vez que una orden se complete. La forma del body es la que el template del body de tu flow renderiza. Con el template canónico, eso es:

```json
{
  "event": {
    "id": "0d6e8a1c-1e7a-4b4f-8a3a-74ab0e9a9b21",
    "type": "order.completed",
    "emittedAt": "2026-05-06T01:22:45.602Z",
    "createdAt": "2026-05-06T01:22:59.902Z"
  },
  "data": {
    "orderId": "21ec1f6c-c301-4528-b999-7836c1d21c6c",
    "orderCode": "OC-br-001",
    "status": "COMPLETED",
    "paymentStatus": "SUCCEEDED",
    "store": { /* ... */ },
    "client": { /* ... */ },
    "payments": { /* ... */ },
    "orderLines": [ /* ... */ ],
    "fulfillment": { /* ... */ }
  },
  "_meta": { "executionId": "...", "flowId": "...", "attempt": "1" }
}
```

Un handler mínimo:

```js
import express from "express";

const app = express();
const seen = new Map(); // reemplaza por Redis/DB en producción

app.post("/fire/events", express.json(), async (req, res) => {
  const { event, data } = req.body ?? {};
  if (!event?.id) return res.status(400).end();

  // 1. Confirma rápido (Fire hace timeout a los 30s)
  res.status(200).end();

  // 2. Deduplica por una llave de dominio (event.id cambia en cada reencolado)
  const key = `${data.orderId}:${event.type}:${event.emittedAt}`;
  if (seen.has(key)) return;
  seen.set(key, Date.now());

  // 3. Despacha por type
  switch (event.type) {
    case "order.completed":      return onOrderCompleted(data);
    case "order.cancelled":      return onOrderCancelled(data);
    case "order.invoiced": return onFiscalAuthorized(data);
    case "order.reversed":  return onFiscalCancelled(data);
  }
});

app.listen(8080);
```

Consulta [`order.completed`](/es/events/order-completed) para la referencia campo por campo del payload.

## Paso 4: Inyectar órdenes

Cuando tu sistema recibe una orden (de un agregador o cualquier otra fuente), inyéctala en Fire. El endpoint depende del formato que envía tu sistema: ver [Inyección de órdenes](/es/guides/order-injection). Para un partner que envía órdenes en formato Fire, un cuerpo mínimo de kiosco en Brasil es:

```bash
curl -X POST https://app.fire.rest/api/v1/adapters/xmart/stores/orders \
  -H "x-api-key: $FIRE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "orderId": "7805610b-97cf-461f-a2d6-d86f63a80833",
    "orderCode": "OC-br-001",
    "accountId": 100,
    "account": "KFC Brasil",
    "createdAt": "2026-04-17T15:41:55.000Z",
    "selectedShippingMethod": "pickup",
    "store": { "id": "a4019cad-bbac-4269-9f8d-f29654e92c45", "code": "BR-SP-001", "vendorId": "100.2.1" },
    "client": { "uid": "", "name": "CONSUMIDOR", "lastName": "FINAL", "govIdType": "FINAL_CONSUMER", "govIdNumber": "00000000000" },
    "channel": { "code": "KIOSK" },
    "service": { "code": "DINE_IN" },
    "device": { "uid": "38e17b63dead6d59" },
    "additionalInfo": { "orderCode": "21K" },
    "order": {
      "products": [{
        "productId": "39d1bd7fcd45c52f0c824364c2c0cfc402bd72b046cfaaec276a0131908dbf20",
        "product": "Crunch Salad + Batata Pequena + Refri",
        "quantity": 1,
        "price": {
          "unitPrice":  { "currencyCode": "BRL", "total": 22.9 },
          "totalPrice": { "currencyCode": "BRL", "total": 22.9 }
        },
        "modifierGroups": []
      }]
    },
    "payments": {
      "totals": [{ "currencyCode": "BRL", "total": 22.9 }],
      "paymentMethods": [{ "method": "DIGITAL", "processor": "PIX", "currencyCode": "BRL", "transactionStatus": "APPROVED", "totalBill": 22.9, "changeAmount": 0 }]
    }
  }'
```

En Brasil no mandas impuestos: Fire los calcula con el grupo fiscal de la tienda y el NCM del catálogo.

Una vez que la orden alcance `status=COMPLETED` y `paymentStatus=SUCCEEDED`, tu flow se dispara y tu handler corre. Si la orden se cancela después, recibirás `order.cancelled`.

Consulta [Inyectar orden (partners)](/es/api-reference/inject-order-partners) para la referencia completa del payload.

## Paso 5: Agregar eventos fiscales

Si tienes emisión fiscal habilitada para una tienda, en cualquier país, agrega un segundo flow con trigger `order.invoiced` (y otro con `order.reversed`) para recibir el contexto del documento fiscal. Usa el mismo endpoint HTTPS y el mismo template; el país viaja en `fiscal.countryCode`.
