<Info>
  **Requisitos**:
  - Node.js 19 o superior
  - Un repositorio de documentación con un archivo `docs.json`
</Info>

Sigue estos pasos para instalar y ejecutar Mintlify en tu sistema.

<Steps>
<Step title="Instalar la CLI de Mintlify">

```bash
npm i -g mint
```
</Step>

<Step title="Previsualizar en local">

En el directorio de documentación donde está `docs.json`, ejecuta:

```bash
mint dev
```

La previsualización estará disponible en `http://localhost:3000`.

</Step>
</Steps>

## Puertos personalizados

Por defecto Mintlify usa el puerto 3000. Puedes cambiarlo con la opción `--port`. Por ejemplo, para el puerto 3333:

```bash
mint dev --port 3333
```

Si el puerto está en uso, se usará el siguiente disponible:

```md
Port 3000 is already in use. Trying 3001 instead.
```

## Versiones de Mintlify

Cada versión de la CLI corresponde a una versión concreta de Mintlify. Si la previsualización no coincide con producción, actualiza la CLI:

```bash
npm mint update
```

## Validar enlaces

Para detectar enlaces rotos:

```bash
mint broken-links
```

## Formato de código

Recomendamos extensiones en el IDE para reconocer y formatear MDX. En VS Code: [extensión MDX](https://marketplace.visualstudio.com/items?itemName=unifiedjs.vscode-mdx) y [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode).

## Solución de problemas

<AccordionGroup>
  <Accordion title='Error: Could not load the "sharp" module using the darwin-arm64 runtime'>

    Puede deberse a una versión antigua de Node. Prueba:
    1. Desinstalar la CLI: `npm remove -g mint`
    2. Actualizar a Node v19 o superior.
    3. Reinstalar: `npm i -g mint`
  </Accordion>

  <Accordion title="Problema: error desconocido">
  
    Solución: en la raíz del usuario, elimina la carpeta `~/.mintlify` y ejecuta `mint dev` de nuevo.
  </Accordion>
</AccordionGroup>

¿Quieres ver los cambios recientes de la CLI? Consulta el [changelog en npm](https://www.npmjs.com/package/mintlify?activeTab=versions).
