---
title: "Listar webhooks"
api: "GET https://boh.api.fire.rest/api/v1/public/admin/webhooks"
description: "Devuelve todos los endpoints webhook registrados para la cuenta."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key de BOH con scope `admin:webhooks`.
</ParamField>

<ResponseField name="webhooks" type="object[]">
  Array de endpoints webhook: `id`, `url`, `events`, `status`, `created_at`.
</ResponseField>

<ResponseExample>
```json 200
{
  "webhooks": [
    {
      "id": "wep_01j5k...",
      "url": "https://mi-sistema.com/webhooks/boh",
      "events": ["inventory_transaction.completed"],
      "status": "ACTIVE",
      "created_at": "2026-01-01T00:00:00.000Z"
    }
  ]
}
```
</ResponseExample>
