title: "Identidad"
description: "Resuelve tu cuenta, lista vendors, establecimientos y proveedores. Comienza aquí para descubrir los IDs que necesitarás en el resto de las llamadas."
---

Los endpoints de identidad son tu punto de partida. Permiten confirmar a qué cuenta está vinculada tu API key, descubrir tus vendors y enumerar los establecimientos y proveedores que referenciarás en las llamadas de catálogo y operaciones.

**Scopes requeridos:** `catalog:read` para la mayoría de lecturas; `catalog:write` para creaciones y actualizaciones.

---

## Me

### Obtener mi contexto de cuenta

<api>GET https://boh.api.fire.rest/api/v1/public/identity/me</api>

Devuelve la cuenta y la información de la API key derivada del header `x-api-key`. Úsalo para verificar la conectividad y descubrir tu `account_id` antes de hacer escrituras.

<ParamField header="x-api-key" type="string" required>API key de BOH.</ParamField>

<ResponseField name="account_id" type="string">UUID de la cuenta asociada a esta key.</ResponseField>
<ResponseField name="api_key" type="object">
  `{ id, key_prefix }` — UUID de la key y el prefijo no secreto para visualización.
</ResponseField>
<ResponseField name="currency_id" type="string">UUID de la moneda configurada en la cuenta (o `null` si no está configurada).</ResponseField>
<ResponseField name="currency" type="object">
  `{ id, code, name, symbol, decimal_places }` — detalle completo de la moneda, o `null`.
</ResponseField>

<ResponseExample>
```json 200
{
  "account_id": "acc_01j5k...",
  "api_key": {
    "id": "key_01j5k...",
    "key_prefix": "boh_live_xxxx"
  },
  "currency_id": "cur_01...",
  "currency": {
    "id": "cur_01...",
    "code": "MXN",
    "name": "Mexican Peso",
    "symbol": "$",
    "decimal_places": 2
  }
}
```
</ResponseExample>

## Vendors

Un **vendor** representa una entidad operativa configurada en BOH (una marca de restaurante o sucursal). La mayoría de los endpoints incluyen un parámetro de ruta `{vendorId}` que debe ser un UUID de vendor válido para tu cuenta.

### Listar vendors

<api>GET https://boh.api.fire.rest/api/v1/public/identity/vendors</api>

Devuelve todos los vendors de tu cuenta. Úsalo para descubrir los IDs de vendor.

<ResponseField name="vendors" type="object[]">
  Array de objetos vendor: `id`, `account_id`, `external_vendor_id`, `name`, `status`, `metadata`, `created_at`, `updated_at`.
</ResponseField>

<ResponseExample>
```json 200
{
  "vendors": [
    {
      "id": "vnd_01j5k...",
      "account_id": "acc_01j5k...",
      "external_vendor_id": "marca-principal",
      "name": "Mi Marca de Restaurante",
      "status": "ACTIVE",
      "metadata": {},
      "created_at": "2026-01-01T00:00:00.000Z",
      "updated_at": "2026-01-01T00:00:00.000Z"
    }
  ]
}
```
</ResponseExample>

---

### Obtener un vendor

<api>GET https://boh.api.fire.rest/api/v1/public/identity/vendors/{vendorId}</api>

Devuelve un único vendor por UUID.

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>

---

## Establecimientos

Los establecimientos representan ubicaciones físicas (cocinas, bodegas, sucursales). Las operaciones como recepciones de mercancía, conteos y transferencias apuntan a un establecimiento específico.

### Listar establecimientos

<api>GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/stores</api>

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>
<ParamField query="limit" type="number">Resultados por página (1–200, default 50).</ParamField>
<ParamField query="offset" type="number">Offset de paginación (default 0).</ParamField>
<ParamField query="status" type="string">Filtrar por `ACTIVE` o `INACTIVE`.</ParamField>

<ResponseField name="items" type="object[]">
  Array de objetos de establecimiento: `id`, `account_id`, `code`, `name`, `timezone`, `status`, `external_store_id`, `created_at`, `updated_at`.
</ResponseField>
<ResponseField name="total" type="number">Total de registros coincidentes.</ResponseField>
<ResponseField name="limit" type="number">Tamaño de página actual.</ResponseField>
<ResponseField name="offset" type="number">Offset actual.</ResponseField>

<ResponseExample>
```json 200
{
  "items": [
    {
      "id": "str_principal_01...",
      "account_id": "acc_01j5k...",
      "code": "EST-001",
      "name": "Cocina Principal",
      "timezone": "America/Mexico_City",
      "status": "ACTIVE",
      "external_store_id": "tienda-principal",
      "created_at": "2026-01-01T00:00:00.000Z",
      "updated_at": "2026-01-01T00:00:00.000Z"
    }
  ],
  "total": 1,
  "limit": 50,
  "offset": 0
}
```
</ResponseExample>

---

### Obtener un establecimiento

<api>GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/stores/{storeId}</api>

Devuelve un único establecimiento con detalle completo (incluye `metadata`).

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>
<ParamField path="storeId" type="string" required>UUID del establecimiento.</ParamField>

---

### Crear un establecimiento

<api>POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/stores</api>

<ParamField body="name" type="string" required>Nombre de visualización (máx. 200 chars).</ParamField>
<ParamField body="code" type="string">Código alfanumérico corto.</ParamField>
<ParamField body="timezone" type="string" required>Identificador de zona horaria IANA (ej. `America/Mexico_City`).</ParamField>
<ParamField body="external_store_id" type="string">Identificador del establecimiento en tu sistema (usado en payloads de operaciones en lugar del UUID).</ParamField>
<ParamField body="metadata" type="object">Datos adicionales libres.</ParamField>
<ParamField body="external_user_id" type="string">Actor para auditoría.</ParamField>

---

### Actualizar un establecimiento

<api>PATCH https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/stores/{storeId}</api>

Actualización parcial — incluye solo los campos que quieres cambiar.

---

### Archivar / Desarchivar un establecimiento

<api>POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/stores/{storeId}/archive</api>
<api>POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/stores/{storeId}/unarchive</api>

---

## Proveedores

Los proveedores son las empresas a las que compras. Se referencian en recepciones de mercancía y órdenes de compra.

### Listar proveedores

<api>GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers</api>

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>
<ParamField query="limit" type="number">Resultados por página (1–200, default 50).</ParamField>
<ParamField query="offset" type="number">Offset de paginación.</ParamField>
<ParamField query="include_archived" type="boolean">Default `false`.</ParamField>

<ResponseField name="items" type="object[]">
  Array de objetos de proveedor: `id`, `account_id`, `external_supplier_id`, `code`, `name`, `email`, `phone`, `tax_id`, `is_active`, `created_at`, `updated_at`.
</ResponseField>

---

### Obtener un proveedor

<api>GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers/{supplierId}</api>

Devuelve un único proveedor con `metadata`.

---

### Crear un proveedor

<api>POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers</api>

<ParamField body="name" type="string" required>Nombre del proveedor.</ParamField>
<ParamField body="code" type="string">Código alfanumérico corto.</ParamField>
<ParamField body="external_supplier_id" type="string">Identificador del proveedor en tu sistema. Debe ser único dentro de la cuenta.</ParamField>
<ParamField body="email" type="string">Correo de contacto.</ParamField>
<ParamField body="phone" type="string">Teléfono de contacto.</ParamField>
<ParamField body="tax_id" type="string">Identificador fiscal.</ParamField>
<ParamField body="metadata" type="object">Datos adicionales libres.</ParamField>
<ParamField body="external_user_id" type="string">Actor para auditoría.</ParamField>

---

### Actualizar un proveedor

<api>PATCH https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers/{supplierId}</api>

Actualización parcial — incluye solo los campos que quieres cambiar.

---

### Archivar / Desarchivar un proveedor

<api>POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers/{supplierId}/archive</api>
<api>POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers/{supplierId}/unarchive</api>

---

### Sincronización masiva de proveedores

<api>PUT https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers</api>

Ver [Catálogo: Sincronización masiva → Sincronizar proveedores](/es/boh-api/catalog-sync#sincronizar-proveedores) para la referencia completa.
