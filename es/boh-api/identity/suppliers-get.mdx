---
title: "Obtener un proveedor"
api: "GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers/{supplierId}"
description: "Devuelve detalle completo de un único proveedor incluyendo metadata."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key de BOH con scope `catalog:read`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>
<ParamField path="supplierId" type="string" required>UUID del proveedor.</ParamField>

<ResponseField name="id" type="string">UUID del proveedor.</ResponseField>
<ResponseField name="account_id" type="string">UUID de la cuenta.</ResponseField>
<ResponseField name="name" type="string">Nombre del proveedor.</ResponseField>
<ResponseField name="external_supplier_id" type="string">Identificador en tu sistema.</ResponseField>
<ResponseField name="status" type="string">`ACTIVE` o `INACTIVE`.</ResponseField>
<ResponseField name="metadata" type="object">Datos adicionales libres.</ResponseField>

<ResponseExample>
```json 200
{
  "id": "sup_01j5k...",
  "account_id": "acc_01j5k...",
  "name": "Proveedor Fresco S.A.",
  "external_supplier_id": "proveedor-fresco",
  "status": "ACTIVE",
  "metadata": {}
}
```

```json 404
{
  "error": {
    "kind": "supplier_not_found",
    "message": "Supplier not found"
  }
}
```
</ResponseExample>
