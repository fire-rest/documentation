---
title: "Obtener contexto de cuenta"
api: "GET https://boh.api.fire.rest/api/v1/public/identity/me"
description: "Devuelve la cuenta y la información de la API key derivada del header x-api-key. Úsalo para verificar conectividad y descubrir tu account_id."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key de BOH.
</ParamField>

<ResponseField name="account_id" type="string">
  UUID de la cuenta asociada a esta key.
</ResponseField>

<ResponseField name="api_key" type="object">
  `{ id, key_prefix }` — UUID de la key y el prefijo no secreto para visualización.
</ResponseField>

<ResponseField name="currency_id" type="string">
  UUID de la moneda configurada en la cuenta (o `null` si no está configurada).
</ResponseField>

<ResponseField name="currency" type="object">
  `{ id, code, name, symbol, decimal_places }` — detalle completo de la moneda, o `null`.
</ResponseField>

<ResponseExample>
```json 200
{
  "account_id": "acc_01j5k...",
  "api_key": {
    "id": "key_01j5k...",
    "key_prefix": "boh_live_xxxx"
  },
  "currency_id": "cur_01...",
  "currency": {
    "id": "cur_01...",
    "code": "MXN",
    "name": "Mexican Peso",
    "symbol": "$",
    "decimal_places": 2
  }
}
```
</ResponseExample>
