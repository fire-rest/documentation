---
title: "Buscar receta publicada por producto"
api: "GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/recipes/lookup"
description: "Devuelve la receta publicada vinculada a un producto del menú. Útil para determinar qué artículos descontar al vender un producto."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key de BOH con scope `recipes:read`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>

<ParamField query="product_id" type="string">UUID del producto del menú.</ParamField>
<ParamField query="external_product_id" type="string">ID externo del producto del menú. Se requiere `product_id` o `external_product_id`.</ParamField>

<ResponseField name="recipe" type="object">
  Receta publicada con ingredientes completos, o `null` si no hay receta vinculada.
</ResponseField>

<ResponseExample>
```json 200
{
  "recipe": {
    "id": "rec_01...",
    "name": "Salsa de Tomate",
    "status": "PUBLISHED",
    "yield_quantity": 1,
    "yield_unit_id": "unit_lt_01...",
    "ingredients": []
  }
}
```
</ResponseExample>
