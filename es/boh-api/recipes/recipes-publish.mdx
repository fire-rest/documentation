---
title: "Publicar receta"
api: "POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/recipes/{recipeId}/publish"
description: "Cambia el estado de la receta de DRAFT a PUBLISHED. Las recetas publicadas se usan en transacciones de inventario."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key de BOH con scope `recipes:write`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>
<ParamField path="recipeId" type="string" required>UUID de la receta.</ParamField>
<ParamField body="external_user_id" type="string">Actor para auditoría.</ParamField>

<RequestExample>
```json
{ "external_user_id": "chef_01" }
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "rec_01...",
  "status": "PUBLISHED"
}
```

```json 422
{
  "error": {
    "kind": "recipe_has_no_ingredients",
    "message": "Cannot publish a recipe with no ingredients"
  }
}
```
</ResponseExample>
