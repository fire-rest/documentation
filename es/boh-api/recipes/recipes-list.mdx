---
title: "Listar recetas"
api: "GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/recipes"
description: "Devuelve todas las recetas del vendor con filtros opcionales."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key de BOH con scope `recipes:read`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>

<ParamField query="limit" type="number">Resultados por página (1–200, default 50).</ParamField>
<ParamField query="offset" type="number">Offset de paginación.</ParamField>
<ParamField query="status" type="string">Filtrar por `DRAFT`, `PUBLISHED`, o `ARCHIVED`.</ParamField>

<ResponseField name="items" type="object[]">
  Array de cabeceras de receta.
</ResponseField>
<ResponseField name="total" type="number">Total de registros.</ResponseField>
