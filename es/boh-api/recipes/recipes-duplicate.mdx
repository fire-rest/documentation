---
title: "Duplicar receta como borrador"
api: "POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/recipes/{recipeId}/duplicate"
description: "Crea una copia de la receta en estado DRAFT. Los ingredientes se copian; el vínculo con el producto se limpia para poder reasignarlo."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key de BOH con scope `recipes:write`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>
<ParamField path="recipeId" type="string" required>UUID de la receta a duplicar.</ParamField>
<ParamField body="name" type="string">Nombre para la nueva receta. Por defecto: "Copia de &lt;nombre original&gt;".</ParamField>
<ParamField body="external_user_id" type="string">Actor para auditoría.</ParamField>

<RequestExample>
```json
{
  "name": "Salsa de Tomate v2",
  "external_user_id": "chef_01"
}
```
</RequestExample>

<ResponseExample>
```json 201
{
  "id": "rec_02...",
  "name": "Salsa de Tomate v2",
  "status": "DRAFT"
}
```
</ResponseExample>
