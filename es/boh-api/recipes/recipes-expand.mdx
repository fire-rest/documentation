---
title: "Expandir receta (resolución de ingredientes)"
api: "GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/recipes/{recipeId}/expand"
description: "Resuelve recursivamente todos los ingredientes de la receta (incluyendo sub-recetas) hasta los artículos base. Útil para calcular el costo total de materiales."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key de BOH con scope `recipes:read`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>
<ParamField path="recipeId" type="string" required>UUID de la receta.</ParamField>

<ParamField query="yield_multiplier" type="number">Factor para escalar los ingredientes (default 1).</ParamField>

<ResponseField name="expanded_ingredients" type="object[]">
  Lista de ingredientes base con cantidades consolidadas y ajustadas por merma.
</ResponseField>

<ResponseExample>
```json 200
{
  "expanded_ingredients": [
    {
      "item_id": "itm_01...",
      "item_name": "Tomate Bola",
      "quantity_needed": 0.84,
      "unit_id": "unit_kg_01...",
      "unit_abbreviation": "kg"
    }
  ]
}
```
</ResponseExample>
