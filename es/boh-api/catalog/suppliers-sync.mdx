---
title: "Sincronizar proveedores (bulk upsert)"
api: "PUT https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/identity/suppliers"
description: "Inserta o actualiza múltiples proveedores en una sola llamada. La reconciliación se hace por `external_supplier_id`."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key de BOH con scope `catalog:write`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>

<ParamField body="suppliers" type="object[]" required>
  Array de proveedores a sincronizar.
  <Expandable title="campos del proveedor">
    <ParamField body="external_supplier_id" type="string" required>Clave de reconciliación.</ParamField>
    <ParamField body="name" type="string" required>Nombre del proveedor.</ParamField>
    <ParamField body="metadata" type="object">Datos adicionales libres.</ParamField>
  </Expandable>
</ParamField>

<RequestExample>
```json
{
  "suppliers": [
    {
      "external_supplier_id": "proveedor-fresco",
      "name": "Proveedor Fresco S.A."
    }
  ]
}
```
</RequestExample>

<ResponseExample>
```json 200
{
  "synced": 1,
  "created": 1,
  "updated": 0
}
```
</ResponseExample>
