---
title: "Sincronizar clasificaciones (asignaciones)"
api: "PUT https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/catalog/classifications/assignments"
description: "Reemplaza el conjunto completo de asignaciones de clasificación para los artículos especificados."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key de BOH con scope `catalog:write`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>

<ParamField body="assignments" type="object[]" required>
  Array de asignaciones.
  <Expandable title="campos de asignación">
    <ParamField body="item_id" type="string">UUID del artículo (se requiere `item_id` o `external_item_id`).</ParamField>
    <ParamField body="external_item_id" type="string">ID externo del artículo (alternativa a `item_id`).</ParamField>
    <ParamField body="classification_values" type="string[]" required>Array de IDs de valores de clasificación a asignar.</ParamField>
  </Expandable>
</ParamField>

<RequestExample>
```json
{
  "assignments": [
    {
      "external_item_id": "tomate-bola",
      "classification_values": ["cls_val_verdura_01", "cls_val_fresco_01"]
    }
  ]
}
```
</RequestExample>

<ResponseExample>
```json 200
{
  "synced": 1
}
```
</ResponseExample>
