---
title: "Crear lote de producción"
api: "POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/operations/production-batches"
description: "Registra la producción de una receta. Descuenta ingredientes del almacén y registra el output producido."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key de BOH con scope `inventory:write`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>

<ParamField body="store_id" type="string">UUID del establecimiento. Se requiere `store_id` o `external_store_id`.</ParamField>
<ParamField body="external_store_id" type="string">ID externo del establecimiento.</ParamField>
<ParamField body="recipe_id" type="string" required>UUID de la receta a producir.</ParamField>
<ParamField body="quantity_produced" type="number" required>Cantidad producida (en la unidad de producción de la receta).</ParamField>
<ParamField body="occurred_at" type="string">Cuándo se produjo (ISO 8601).</ParamField>
<ParamField body="notes" type="string">Notas adicionales.</ParamField>
<ParamField body="external_user_id" type="string" required>Actor responsable.</ParamField>
<ParamField body="idempotency_key" type="string">Clave de idempotencia.</ParamField>

<RequestExample>
```json
{
  "external_store_id": "cocina-principal",
  "recipe_id": "rec_01...",
  "quantity_produced": 5,
  "external_user_id": "chef_01"
}
```
</RequestExample>

<ResponseExample>
```json 201
{
  "id": "pb_01...",
  "status": "COMPLETED",
  "recipe_id": "rec_01...",
  "quantity_produced": 5,
  "store_id": "str_cocina_01..."
}
```

```json 422
{
  "error": {
    "kind": "recipe_not_published",
    "message": "Recipe must be PUBLISHED to produce"
  }
}
```
</ResponseExample>
