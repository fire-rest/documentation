---
title: "Cerrar orden de compra"
api: "POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/procurement/orders/{orderId}?action=close"
description: "Cierra la orden marcándola como CLOSED. Úsalo cuando hayas recibido todos los artículos o quieras finalizar la orden independientemente del estado de cumplimiento."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key de BOH con scope `inventory:write`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>
<ParamField path="orderId" type="string" required>UUID de la orden de compra.</ParamField>
<ParamField body="external_user_id" type="string" required>Actor que cierra la orden.</ParamField>

<RequestExample>
```json
{ "external_user_id": "compras_01" }
```
</RequestExample>

<ResponseExample>
```json 200
{
  "purchase_order": {
    "id": "po_01...",
    "status": "CLOSED"
  }
}
```
</ResponseExample>
