---
title: "Crear orden de compra"
api: "POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/procurement/orders"
description: "Crea una nueva orden de compra en estado DRAFT, opcionalmente con líneas iniciales."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key de BOH con scope `inventory:write`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>

<ParamField body="supplier_id" type="string">UUID del proveedor. Se requiere `supplier_id` o `external_supplier_id`.</ParamField>
<ParamField body="external_supplier_id" type="string">ID externo del proveedor.</ParamField>
<ParamField body="store_id" type="string">UUID del establecimiento receptor. Exactamente uno de `store_id`, `external_store_id` o `store_tax_id` debe ser enviado.</ParamField>
<ParamField body="external_store_id" type="string">Identificador cruzado del establecimiento. Mutuamente exclusivo con `store_id` y `store_tax_id`.</ParamField>
<ParamField body="store_tax_id" type="string">Identificador fiscal del establecimiento (RUC, CNPJ, CUIT, NIT…). Devuelve `422` si varios establecimientos activos comparten el mismo valor — usa `store_id` o `external_store_id` para desambiguar. Mutuamente exclusivo con `store_id` y `external_store_id`.</ParamField>
<ParamField body="expected_delivery_date" type="string">Fecha esperada de entrega (ISO 8601).</ParamField>
<ParamField body="reference" type="string">Número de referencia externo.</ParamField>
<ParamField body="notes" type="string">Notas para el proveedor.</ParamField>
<ParamField body="lines" type="object[]">
  Líneas iniciales (opcional).
  <Expandable title="campos de línea">
    <ParamField body="item_id" type="string">UUID del artículo.</ParamField>
    <ParamField body="external_item_id" type="string">ID externo del artículo.</ParamField>
    <ParamField body="quantity" type="number" required>Cantidad a pedir.</ParamField>
    <ParamField body="unit_id" type="string" required>UUID de la unidad.</ParamField>
    <ParamField body="unit_cost" type="number">Costo unitario acordado.</ParamField>
  </Expandable>
</ParamField>
<ParamField body="external_user_id" type="string" required>Actor que crea la orden.</ParamField>
<ParamField body="idempotency_key" type="string">Clave de idempotencia.</ParamField>

<RequestExample>
```json
{
  "external_supplier_id": "proveedor-fresco",
  "external_store_id": "tienda-principal",
  "expected_delivery_date": "2026-08-10",
  "lines": [
    {
      "external_item_id": "tomate-bola",
      "quantity": 20,
      "unit_id": "unit_kg_01...",
      "unit_cost": 25.00
    }
  ],
  "external_user_id": "compras_01"
}
```
</RequestExample>

<ResponseExample>

```json 201
    "id": "po_01...",
    "status": "DRAFT",
    "supplier_id": "sup_01...",
    "store_id": "str_principal_01...",
    "expected_delivery_date": "2026-08-10",
    "lines": [
      {
        "id": "pol_01...",
        "item_id": "itm_01...",
        "quantity": 20,
        "unit_id": "unit_kg_01...",
        "unit_cost": 25.00
      }
    ]
  }

```

```json 404
{
  "error": {
    "kind": "supplier_not_found",
    "message": "Supplier not found"
  }
```

```json 404 (establecimiento no encontrado por external_store_id)
{
  "error": {
    "kind": "purchase_order_store_external_id_not_found",
    "message": "No active store matches the provided external_store_id"
  }
}
```

```json 404 (establecimiento no encontrado por store_tax_id)
{
  "error": {
    "kind": "purchase_order_store_tax_id_not_found",
    "message": "No active store matches the provided store_tax_id"
  }
}
```

```json 422 (store_tax_id ambiguo)
{
  "error": {
    "kind": "purchase_order_store_tax_id_ambiguous",
    "message": "Multiple active stores share the same tax_id — use store_id or external_store_id to disambiguate",

  }
```
