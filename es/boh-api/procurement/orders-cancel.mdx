---
title: "Cancelar orden de compra"
api: "DELETE https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/procurement/orders/{orderId}"
description: "Cancela una orden de compra en estado DRAFT o SUBMITTED."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key de BOH con scope `inventory:write`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>
<ParamField path="orderId" type="string" required>UUID de la orden de compra.</ParamField>
<ParamField body="external_user_id" type="string" required>Actor que cancela.</ParamField>
<ParamField body="reason" type="string">Motivo de cancelación.</ParamField>

<RequestExample>
```json
{
  "external_user_id": "compras_01",
  "reason": "Pedido duplicado"
}
```
</RequestExample>

<ResponseExample>
```json 200
{
  "purchase_order": {
    "id": "po_01...",
    "status": "CANCELLED"
  }
}
```

```json 422
{
  "error": {
    "kind": "purchase_order_cannot_be_cancelled",
    "message": "Only DRAFT or SUBMITTED orders can be cancelled"
  }
}
```
</ResponseExample>
