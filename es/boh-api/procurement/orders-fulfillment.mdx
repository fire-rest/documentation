---
title: "Obtener estado de cumplimiento"
api: "GET https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/procurement/orders/{orderId}/fulfillment"
description: "Devuelve el estado de cumplimiento de la orden mostrando la cantidad pedida vs. recibida para cada línea."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key de BOH con scope `inventory:read`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>
<ParamField path="orderId" type="string" required>UUID de la orden de compra.</ParamField>

<ResponseField name="order_id" type="string">UUID de la orden.</ResponseField>
<ResponseField name="status" type="string">Estado actual de la orden.</ResponseField>
<ResponseField name="lines" type="object[]">
  <Expandable title="campos de línea">
    <ResponseField name="line_id" type="string">UUID de la línea.</ResponseField>
    <ResponseField name="item_id" type="string">UUID del artículo.</ResponseField>
    <ResponseField name="quantity_ordered" type="number">Cantidad pedida.</ResponseField>
    <ResponseField name="quantity_received" type="number">Cantidad recibida hasta ahora.</ResponseField>
    <ResponseField name="unit_id" type="string">UUID de la unidad.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseExample>
```json 200
{
  "order_id": "po_01...",
  "status": "PARTIALLY_RECEIVED",
  "lines": [
    {
      "line_id": "pol_01...",
      "item_id": "itm_01...",
      "quantity_ordered": 20,
      "quantity_received": 12,
      "unit_id": "unit_kg_01..."
    }
  ]
}
```
</ResponseExample>
