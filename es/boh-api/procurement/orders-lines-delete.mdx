</ParamField>

<ParamField path="orderId" type="string" required>UUID de la orden de compra.</ParamField>
<ParamField path="lineId" type="string" required>UUID de la línea a eliminar.</ParamField>
<ParamField body="external_user_id" type="string" required>Actor que elimina.</ParamField>

<RequestExample>
```json
{ "external_user_id": "compras_01" }
```
</RequestExample>


