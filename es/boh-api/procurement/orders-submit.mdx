---
title: "Enviar orden de compra"
api: "POST https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/procurement/orders/{orderId}?action=submit"
description: "Cambia el estado de la orden de DRAFT a SUBMITTED. Úsalo cuando estés listo para enviarla al proveedor."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key de BOH con scope `inventory:write`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>
<ParamField path="orderId" type="string" required>UUID de la orden de compra.</ParamField>
<ParamField body="external_user_id" type="string" required>Actor que envía la orden.</ParamField>

<RequestExample>
```json
{ "external_user_id": "compras_01" }
```
</RequestExample>

<ResponseExample>
```json 200
{
  "purchase_order": {
    "id": "po_01...",
    "status": "SUBMITTED"
  }
}
```

```json 422
{
  "error": {
    "kind": "purchase_order_has_no_lines",
    "message": "Cannot submit an order with no lines"
  }
}
```
</ResponseExample>
