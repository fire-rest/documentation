---
title: "Actualizar una línea de OC"
api: "PATCH https://boh.api.fire.rest/api/v1/public/vendors/{vendorId}/procurement/orders/{orderId}/lines/{lineId}"
description: "Actualiza la cantidad o el costo de una línea de la orden de compra. Solo se permite en órdenes DRAFT."
authMethod: "none"
---

<ParamField header="x-api-key" type="string" required>
  API key de BOH con scope `inventory:write`.
</ParamField>

<ParamField path="vendorId" type="string" required>UUID del vendor.</ParamField>
<ParamField path="orderId" type="string" required>UUID de la orden de compra.</ParamField>
<ParamField path="lineId" type="string" required>UUID de la línea.</ParamField>

<ParamField body="qty" type="number" required>Nueva cantidad pedida en la unidad de entrada.</ParamField>
<ParamField body="qty_base" type="number">Nueva cantidad en la unidad base. Opcional cuando la línea referencia `unit_code` o `item_unit_id` — el servidor la deriva como `qty × factor_to_base`.</ParamField>
<ParamField body="unit_cost" type="number">Nuevo costo unitario.</ParamField>
<ParamField body="unit_label" type="string">Nueva etiqueta de unidad.</ParamField>
<ParamField body="tax_amount" type="number">Nuevo monto de impuestos.</ParamField>
<ParamField body="delivery_amount" type="number">Nuevo monto de entrega.</ParamField>
<ParamField body="total_amount" type="number">Nuevo monto total.</ParamField>
<ParamField body="markup_amount" type="number">Nuevo monto de markup.</ParamField>
<ParamField body="notes" type="string">Nuevas notas de línea.</ParamField>
<ParamField body="metadata" type="object">Nuevos datos adicionales.</ParamField>

<RequestExample>
```json
{
  "qty": 15,
  "qty_base": 15000,
  "unit_cost": 4.3
}
```
</RequestExample>

<ResponseExample>
```json 200
{
  "line": {
    "id": "pol_01...",
    "purchase_order_id": "po_01j5k...",
    "item_id": "itm_pollo_01...",
    "qty": 15,
    "qty_base": 15000,
    "unit_cost": 4.3
  }
}
```
</ResponseExample>
