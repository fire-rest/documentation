---
title: "channel.deleted"
description: "Se dispara cuando un canal de venta es removido de Fire."
---

Fire emite este evento cuando un canal es removido permanentemente. Tu sistema debe desactivar o eliminar el canal de su mapeo local y dejar de enrutar eventos u órdenes hacia él.

## Payload

```json
{
  "event": "channel.deleted",
  "id": "evt_abc201",
  "createdAt": "2025-01-21T09:00:00Z",
  "data": {
    "account": "1",
    "country": "6",
    "vendorId": 16,
    "channelId": "CH-IFOOD-001",
    "code": "IFOOD"
  }
}
```

## Campos

### `data`

| Campo | Tipo | Descripción |
|---|---|---|
| `account` | string | Identificador de cuenta — requerido por sistemas downstream |
| `country` | string | Identificador de país — requerido por sistemas downstream |
| `vendorId` | integer | Identificador de la marca |
| `channelId` | string | ID del canal eliminado |
| `code` | string | Código corto del canal eliminado |

## Uso

Cuando tu sistema reciba este evento, elimina el canal de tu mapeo local y deja de enrutar eventos de publicación o inyecciones de orden hacia él. Las órdenes en curso asociadas con este canal deben completarse pero no debe inyectarse ninguna orden nueva.

A diferencia de [`channel.updated`](/es/webhook-reference/channel-updated) con `active: "INACTIVE"`, este evento es explícito — el canal ya no existe en Fire.
