---
title: "menu.deleted"
description: "Se emite cuando un menú (list) es eliminado de Fire."
---

<Warning>
  **Todavía no se emite.** Fire no envía este evento hoy. Actualmente, eliminar un
  menú en un sistema externo se señaliza mediante
  [`menu.updated`](/es/webhook-reference/menu-updated) con `categories`, `products` y
  `modifierGroups` como arrays vacíos — ver
  [Eliminar un menú externamente](/es/webhook-reference/menu-updated#eliminar-un-menú-externamente).
  Esta página documenta un evento de borrado dedicado planeado, como referencia a
  futuro; no está en el índice de eventos y no deberías construir contra él todavía.
</Warning>

## Payload

```json
{
  "event": {
    "id": "evt_def457",
    "type": "menu.deleted",
    "createdAt": "2025-01-15T15:10:00Z",
    "timezone": "America/Guayaquil"
  },
  "data": {
    "listId": "pickup-menu-t005",
    "vendorId": "16",
    "storeId": "805",
    "channelId": "0E049503-85CF-E511-80C6-000D3A3261F3"
  }
}
```

## Campos

### `data`

| Campo | Tipo | Descripción |
|---|---|---|
| `listId` | string | Identificador del menú eliminado |
| `vendorId` | string | Identificador de marca |
| `storeId` | string | Tienda a la que pertenecía el menú |
| `channelId` | string | UUID del canal al que estaba asignado el menú |

## Uso

Cuando tu sistema recibe este evento, elimina o desactiva el menú en tus sistemas externos para la tienda y canal identificados.

A diferencia de [`menu.updated`](/es/webhook-reference/menu-updated), este evento es explícito — no hay ambigüedad sobre si el menú debería seguir existiendo externamente.
