---
title: "menus.sync"
description: "Se dispara cuando Fire necesita propagar menús de varias tiendas a la vez."
---

`menus.sync` es la contraparte por lotes de [`menu.updated`](/es/webhook-reference/menu-updated). Fire lo emite cuando hay que propagar menús de varias tiendas a la vez — por ejemplo, durante el onboarding inicial o tras un cambio global de menú que afecta a muchas tiendas.

Fire divide automáticamente las sincronizaciones grandes y emite varios eventos `menus.sync`. Cada evento incluye un solo menú en `data.menu`. Usa `batchIndex` y `batchTotal` para seguir el progreso de la sincronización. Cada evento se entrega y reintenta de forma independiente.

## Campos

### `data`

| Campo | Tipo | Descripción |
|---|---|---|
| `account` | string | Identificador de cuenta — requerido por sistemas downstream |
| `country` | string | Código de país ISO 3166-1 alpha-2 (p. ej. `EC`, `BR`, `CO`) — requerido por sistemas downstream |
| `batchIndex` | integer | Posición de este lote (1-based) |
| `batchTotal` | integer | Número total de lotes en esta sincronización |
| `menu` | object | Payload de menú completo — misma estructura que `data.menu` en [`menu.updated`](/es/webhook-reference/menu-updated) |

### `data.menu`

| Campo | Tipo | Descripción |
|---|---|---|
| `list` | object | Metadata del menú y asociación canal/tienda |
| `categories` | object[] | Árbol de categorías |
| `products` | object[] | Catálogo de productos |
| `modifierGroups` | object[] | Grupos de modificadores y opciones |
| `scheduledActivities` | object[] | Ventanas futuras de activación/desactivación |

Los objetos anidados usan las mismas definiciones de campo que [`menu.updated`](/es/webhook-reference/menu-updated#datamenu).

## Procesamiento

Procesa cada evento `menus.sync` de forma independiente. Aplica `data.menu` al sistema downstream identificado por `menu.list.storeId` y `menu.list.channelId`.

El menú es un **reemplazo completo** — misma semántica de reemplazo total que [`menu.updated`](/es/webhook-reference/menu-updated).

Usa `batchIndex` y `batchTotal` para hacer seguimiento del progreso si tu sistema necesita saber cuándo termina una sincronización completa.

<Note>
  Cada evento de lote se reintenta de forma independiente en caso de fallo — no toda la sincronización.
</Note>

## ¿Cuándo emite Fire este evento?

- Durante el onboarding inicial del cliente
- Tras un cambio global de menú que afecta a muchas tiendas
- En solicitudes de sync explícitas desde el panel de Fire

Para cambios individuales de menú en operación normal, Fire emite [`menu.updated`](/es/webhook-reference/menu-updated).
