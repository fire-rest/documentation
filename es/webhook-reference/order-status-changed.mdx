---
title: "order.status_changed"
description: "Se dispara cuando cambia el estado de un pedido dentro de Fire."
---

## Payload

```json
{
  "event": {
    "id": "evt_jkl012",
    "type": "order.status_changed",
    "createdAt": "2025-01-15T14:35:00Z",
    "timezone": "America/Guayaquil"
  },
  "data": {
    "account": "1",
    "country": "6",
    "fire_order_id": "fire_order_abc",
    "external_order_id": "uber_order_9876",
    "channel_id": "channel_abc123",
    "status": "in_preparation",
    "previous_status": "accepted",
    "updated_at": "2025-01-15T14:35:00Z"
  }
}
```

## Campos

### `data`

| Campo | Tipo | Descripción |
|---|---|---|
| `account` | string | Identificador de la cuenta |
| `country` | string | Identificador del país |
| `fire_order_id` | string | ID interno del pedido en Fire |
| `external_order_id` | string | ID del pedido en el agregador (el que enviaste al inyectarlo) |
| `channel_id` | string | ID del canal de Fire al que pertenece el pedido |
| `status` | string | Nuevo estado del pedido |
| `previous_status` | string | Estado anterior del pedido |
| `updated_at` | string | Marca de tiempo ISO 8601 del cambio de estado |

## Valores de estado

| Estado | Descripción |
|---|---|
| `received` | Fire recibió el pedido |
| `accepted` | El restaurante aceptó el pedido |
| `in_preparation` | La cocina empezó a prepararlo |
| `ready` | El pedido está listo para retirar o despachar |
| `dispatched` | Entregado al repartidor |
| `delivered` | Entregado al cliente |
| `cancelled` | El pedido se canceló |
