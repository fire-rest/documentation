---
title: "product.updated"
description: "Se emite cuando uno o más productos cambian. Aplica a todos los menús y tiendas donde aparecen los productos afectados."
---

`product.updated` es un evento **incremental**. Los productos del payload se crean o actualizan en cada sistema externo destino — los productos existentes que no estén incluidos en el payload quedan sin modificar. Para eliminar un producto, envía un evento [`menu.updated`](/es/webhook-reference/menu-updated) con el menú completo excluyendo ese producto.

Cuando un cambio de producto afecta a múltiples tiendas, Fire emite un **único evento** con todas las tiendas afectadas listadas en `targets`. Tu sistema itera los targets y aplica los mismos datos de producto a cada uno.

## Campos

### `data`

| Campo | Tipo | Descripción |
|---|---|---|
| `account` | string | Identificador de la cuenta — requerido por sistemas externos |
| `country` | string | Código de país ISO 3166-1 alpha-2 (p. ej. `EC`, `BR`, `CO`) — requerido por sistemas externos |
| `groupId` | string | UUID que correlaciona eventos del mismo batch de publicación o sincronización |
| `targets` | object[] | Tiendas donde los productos deben actualizarse |
| `products` | object[] | Productos a crear o actualizar |
| `modifierGroups` | object[] | Grupos de modificadores referenciados por los productos |
| `categories` | object[] | Categorías afectadas por los cambios de producto |

### `data.targets[n]`

| Campo | Tipo | Descripción |
|---|---|---|
| `storeId` | string | UUID interno de la tienda (PK `stores.id`) — no es el `store_number` |
| `storeName` | string | Nombre operativo de la tienda |
| `vendorId` | string | Identificador de marca de la tienda |
| `timezone` | string | Zona horaria IANA de la tienda (p. ej. `America/Sao_Paulo`) |
| `channels` | object[] | Canales de venta donde los productos deben actualizarse |

### `data.targets[n].channels[n]`

| Campo | Tipo | Descripción |
|---|---|---|
| `channelId` | string | UUID interno del canal de ventas (PK `channels.id`) — no es el `channel_id` externo del agregador |
| `channelReferenceName` | string | Nombre de referencia del fulfillment (p. ej. `iFood`, `Rappi`) |
| `listName` | string | Nombre del menú en esa tienda/canal |

### `data.products[n]`

| Campo | Tipo | Descripción |
|---|---|---|
| `productId` | string | Identificador del producto |
| `name` | string | Nombre del producto |
| `description` | string | Descripción del producto |
| `standardTime` | boolean | Si aplica el tiempo de preparación estándar |
| `featured` | boolean | Si el producto está destacado |
| `type` | string | `PRODUCT`, `MODIFIER` o `COMPLEMENT` |
| `priceInfo` | object | Información de precios |
| `priceInfo.price` | number | Precio regular |
| `priceInfo.salePrice` | number | Precio con descuento |
| `priceInfo.suggestedPrice` | number | Precio regular sugerido |
| `priceInfo.suggestedPointPrice` | number | Precio en puntos sugerido |
| `taxesInfo` | object[] | Configuración de impuestos |
| `productModifiers` | object[] | Referencias de grupos de modificadores con posiciones |
| `schedules` | object[] | Disponibilidad por horario |
| `images` | object[] | Imágenes del producto |
| `upselling` | string[] | IDs de productos sugeridos como upsell |
| `crossSelling` | string[] | IDs de productos sugeridos como cross-sell |
| `tags` | string[] | Etiquetas del producto |
| `additionalInfo` | object | Metadata adicional |

### `data.modifierGroups[n]`

Misma estructura que en [`menu.updated`](/es/webhook-reference/menu-updated#datamenucategoriesn).

### `data.categories[n]`

Misma estructura que en [`menu.updated`](/es/webhook-reference/menu-updated#datamenumodifiergroupsn).

## Comportamiento incremental

| Situación | Resultado |
|---|---|
| Producto en payload, existe en sistema externo | Actualizado |
| Producto en payload, no existe en sistema externo | Creado |
| Producto **no** en payload, existe en sistema externo | Sin cambios |
| Eliminar un producto | Envía un [`menu.updated`](/es/webhook-reference/menu-updated) completo sin ese producto |

## Uso

Consulta la guía [Publicación de producto](/es/guides/product-publication) para el flujo completo de procesamiento.
