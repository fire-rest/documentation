---
title: "product.price_updated"
description: "Se emite cuando cambia el precio de uno o más productos. Aplica a todos los menús y tiendas donde aparecen los productos afectados."
---

`product.price_updated` es un evento **acotado** — a diferencia de [`product.updated`](/es/webhook-reference/product-updated), solo transmite `priceInfo` para cada producto. El resto de los atributos del producto (nombre, descripción, imágenes, modificadores, etc.) permanece sin cambios.

Soporta múltiples productos en un solo evento. Cuando el cambio afecta a varias tiendas, Fire emite un **único evento** con todas las tiendas afectadas listadas en `targets`.

## Payload

```json
{
  "event": {
    "id": "evt_pqr678",
    "type": "product.price_updated",
    "createdAt": "2025-01-15T14:45:00Z",
    "timezone": "America/Sao_Paulo"
  },
  "data": {
    "account": "1",
    "country": "BR",
    "targets": [
      {
        "storeId": "805",
        "storeName": "Laboratorio Brasil",
        "channels": [
          {
            "channelId": "0E049503-85CF-E511-80C6-000D3A3261F3",
            "channelReferenceName": "iFood",
            "listName": "Menu App"
          }
        ]
      },
      {
        "storeId": "806",
        "storeName": "Vila Olimpia",
        "channels": [
          {
            "channelId": "0E049503-85CF-E511-80C6-000D3A3261F3",
            "channelReferenceName": "iFood",
            "listName": "Menu App"
          }
        ]
      }
    ],
    "products": [
      {
        "productId": "prod_001",
        "priceInfo": {
          "price": 1350,
          "salePrice": 1100,
          "suggestedPrice": 1350,
          "suggestedPointPrice": 0
        }
      },
      {
        "productId": "prod_size_small",
        "priceInfo": {
          "price": 0,
          "salePrice": 0,
          "suggestedPrice": 0,
          "suggestedPointPrice": 0
        }
      }
    ]
  }
}
```

## Campos

### `data`

| Campo | Tipo | Descripción |
|---|---|---|
| `account` | string | Identificador de la cuenta — requerido por sistemas externos |
| `country` | string | Código de país ISO 3166-1 alpha-2 (p. ej. `EC`, `BR`, `CO`) — requerido por sistemas externos |
| `targets` | object[] | Tiendas donde debe aplicarse el cambio de precio |
| `products` | object[] | Productos cuyo precio cambió |

### `data.targets[n]`

Misma estructura que en [`product.updated`](/es/webhook-reference/product-updated#datatargetsn).

### `data.products[n]`

| Campo | Tipo | Descripción |
|---|---|---|
| `productId` | string | Identificador del producto |
| `priceInfo` | object | Información de precios — reemplaza por completo el `priceInfo` existente |
| `priceInfo.price` | number | Precio regular |
| `priceInfo.salePrice` | number | Precio con descuento |
| `priceInfo.suggestedPrice` | number | Precio regular sugerido |
| `priceInfo.suggestedPointPrice` | number | Precio en puntos sugerido |

## Comportamiento

Este evento solo modifica `priceInfo`. Nombre, descripción, imágenes, modificadores, impuestos y demás atributos del producto permanecen sin cambios. El objeto `priceInfo` recibido reemplaza por completo al existente para ese `productId` — no es un merge campo a campo.

## Uso

Consulta la guía [Publicación de producto](/es/guides/product-publication) para el flujo completo de procesamiento.
