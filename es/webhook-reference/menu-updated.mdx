---
title: "menu.updated"
description: "Se emite cuando un menú es creado o actualizado y debe propagarse a sistemas externos."
---

Un menú en Fire es la definición completa del catálogo para una combinación específica de tienda y canal — incluye categorías, productos, grupos de modificadores y horarios. El payload es autocontenido y está listo para enviarse a sistemas externos. Trátalo como un upsert: crea el menú si no existe o reemplázalo completamente si ya existe.

## Campos

### `data`

| Campo | Tipo | Descripción |
|---|---|---|
| `account` | string | Identificador de cuenta — requerido por sistemas externos |
| `country` | string | Código de país ISO 3166-1 alpha-2 (p. ej. `EC`, `BR`, `CO`) — requerido por sistemas externos |
| `groupId` | string | UUID que identifica el grupo de sincronización. Varios eventos `menu.updated` emitidos en el mismo batch comparten el mismo `groupId`, lo que permite a los sistemas externos correlacionar todos los eventos que pertenecen a una misma sincronización. |
| `menu` | object | Definición completa del menú |

### `data.menu`

| Campo | Tipo | Descripción |
|---|---|---|
| `list` | object | Metadatos del menú y asociación canal/tienda |
| `categories` | object[] | Árbol de categorías |
| `products` | object[] | Catálogo de productos |
| `modifierGroups` | object[] | Grupos de modificadores y opciones |
| `scheduledActivities` | object[] | Ventanas futuras de activación/desactivación |

### `data.menu.list`

| Campo | Tipo | Descripción |
|---|---|---|
| `ecommerceChannelId` | integer | Identificador de canal estandarizado |
| `vendorId` | string | Identificador de marca |
| `storeId` | string | Identificador de tienda |
| `channelId` | string | UUID del canal de ventas |
| `channelReferenceName` | string | Nombre legible del canal de ventas (p. ej. `iFood`, `Rappi`) |
| `schedules` | object[] | Ventanas de tiempo en las que este menú está activo |

### `data.menu.list.schedules[n]`

| Campo | Tipo | Descripción |
|---|---|---|
| `day` | string | Día de la semana: `MONDAY`, `TUESDAY`, `WEDNESDAY`, `THURSDAY`, `FRIDAY`, `SATURDAY`, `SUNDAY` |
| `startTime` | string | Hora de apertura en formato `HH:mm` |
| `endTime` | string | Hora de cierre en formato `HH:mm` |

### `data.menu.categories[n]`

| Campo | Tipo | Descripción |
|---|---|---|
| `categoryId` | string | Identificador de categoría |
| `categoryName` | string | Nombre para mostrar |
| `displayInList` | boolean | Si la categoría es visible |
| `featured` | boolean | Si la categoría está destacada |
| `crossSellingCategory` | boolean | Si es una categoría de venta cruzada |
| `position` | integer | Orden de visualización |
| `images` | object[] | Imágenes de la categoría |
| `childCategories` | object[] | Subcategorías anidadas |
| `productListing` | object[] | Productos de esta categoría con sus posiciones |
| `schedules` | object[] | Ventanas de disponibilidad de la categoría. Misma estructura que `list.schedules`. Array vacío indica sin restricción de horario. |

### `data.menu.products[n]`

| Campo | Tipo | Descripción |
|---|---|---|
| `productId` | string | Identificador del producto |
| `name` | string | Nombre del producto |
| `description` | string | Descripción del producto |
| `standardTime` | boolean | `true` si el producto usa el horario general del menú; `false` si tiene su propio array `schedules` |
| `featured` | boolean | Si el producto está destacado |
| `priceInfo` | object | Precio y precio de oferta |
| `priceInfo.price` | number | Precio regular |
| `priceInfo.salePrice` | number | Precio descontado |
| `productModifiers` | object[] | Referencias de grupos de modificadores con posiciones |
| `schedules` | object[] | Ventanas de disponibilidad del producto. Misma estructura que `list.schedules`. Se evalúa solo cuando `standardTime` es `false`. |
| `images` | object[] | Imágenes del producto |
| `additionalInfo` | object | Metadata adicional opcional del producto |
| `additionalInfo.externalCode` | string | Código externo que identifica el producto en un sistema de terceros. Puede ser un código simple (p. ej. `11019`) o una clave compuesta con `#` como separador (p. ej. `11019#23211#231`). |
| `additionalInfo.ncm` | string | Código de clasificación fiscal NCM (Nomenclatura Común del Mercosur, p. ej. `21.00.21.32`). |

### `data.menu.modifierGroups[n]`

| Campo | Tipo | Descripción |
|---|---|---|
| `modifierId` | string | Identificador del grupo de modificadores |
| `modifier` | string | Nombre para mostrar del grupo |
| `minOptions` | integer | Número mínimo de selecciones requeridas |
| `maxOptions` | integer | Número máximo de selecciones permitidas |
| `visible` | boolean | Si el grupo de modificadores es visible |
| `position` | integer | Orden de visualización |
| `type` | string | Tipo de modificador |
| `modifierOptions` | object[] | Opciones individuales del grupo — cada `productId` debe existir en `products` |

### `data.menu.modifierGroups[n].modifierOptions[n]`

| Campo | Tipo | Descripción |
|---|---|---|
| `optionId` | string | Identificador de la opción |
| `productId` | string | Producto usado como esta opción |
| `default` | boolean | Si esta opción está seleccionada por defecto |
| `position` | integer | Orden de visualización |

### `data.menu.scheduledActivities[n]`

| Campo | Tipo | Descripción |
|---|---|---|
| `productId` | string | Identificador del producto |
| `scheduledActiveStatus` | string | Timestamp ISO 8601 en que el producto se activa |
| `scheduledInactiveStatus` | string | Timestamp ISO 8601 en que el producto se desactiva |

## Notas

- El payload es un **menú completo** — no un diff. Reemplaza el menú completo en el sistema externo.
- Cada `menu.modifierGroups[n].modifierOptions[n].productId` debe referenciar un producto definido en `menu.products`.
- `scheduledActivities` define ventanas futuras de activación/desactivación para productos específicos.
- Cuando `standardTime` es `true` en un producto, usa los `list.schedules` del menú; cuando es `false`, usa el array `schedules` propio del producto.
- Los arrays `schedules` de categorías y productos tienen la misma forma que `list.schedules` — una entrada por día de la semana.

## Eliminar un menú externamente

Fire no emite un evento de borrado separado para menús. Para eliminar un menú de un sistema externo, Fire envía un evento `menu.updated` con `menu.categories`, `menu.products`, `menu.modifierGroups` y `menu.scheduledActivities` como arrays vacíos. Tu sistema debe interpretar un menú vacío como señal para desactivar o eliminar el menú externamente.

```json
{
  "event": {
    "id": "evt_def459",
    "type": "menu.updated",
    "createdAt": "2025-01-15T14:31:00Z"
  },
  "data": {
    "account": "1",
    "country": "EC",
    "groupId": "a3f7c2d1-84be-4e10-9b3a-2c5d6e7f8091",
    "menu": {
      "list": { "..." : "..." },
      "categories": [],
      "products": [],
      "modifierGroups": [],
      "scheduledActivities": []
    }
  }
}
```
